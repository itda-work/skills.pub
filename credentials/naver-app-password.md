# 네이버 앱 비밀번호 — 발급 가이드

- 공식 사이트: <https://nid.naver.com> (네이버 내 정보·보안 설정)
- 발급하는 것: 메일·캘린더 연결용 앱 비밀번호 — itda-hyve 설정 창의 "계정" 화면에 등록합니다
- Last Verified: 2026-06-10 (email·calendar 운영 GUIDE에서 통합 — 실화면 재검증 시 갱신)

## 1. 가입 조건

- 일반 네이버 계정이면 됩니다 (비용 없음).
- 단, **2단계 인증이 켜져 있어야** 앱 비밀번호를 발급할 수 있습니다.
- 보안상 계정 비밀번호를 그대로 쓰지 않고, 메일·캘린더 같은 외부 연결 전용의 **앱 비밀번호**를 따로 발급받는 방식입니다.

## 2. 발급 절차

1. 네이버 로그인 → **내 정보 → 보안 설정 → 2단계 인증**을 켭니다
2. 같은 보안 설정의 **애플리케이션 비밀번호 관리 → 발급**
3. 발급된 비밀번호를 **그 자리에서 복사**합니다 — 한 번만 표시됩니다
4. (메일 스킬 사용 시) 네이버 메일 → 설정(톱니바퀴) → **POP3/IMAP 설정**에서 IMAP을 **사용함**으로 켭니다

## 3. itda-hyve 에 등록하기

메일·캘린더 스킬은 계정을 PC 에 설치한 **itda-hyve** 앱에 등록해 두고 그 앱을 통해서만 씁니다.
비밀번호는 itda-hyve 안에만 있고 Claude 에게 전달되지 않습니다. 설치는
[itda-hyve 내려받기](https://github.com/itda-work/itda-hyve.pub/releases/latest)에서 합니다.

1. itda-hyve 설정 창의 **계정** 화면에서 계정을 추가합니다
2. 제공자 **네이버**를 고르고, 이메일(`you@naver.com` **전체 이메일**)과 발급한 앱 비밀번호를 넣습니다 — 서버 주소는 자동으로 채워집니다
3. **연결 테스트**를 눌러 메일(과 캘린더) 줄이 성공인지 확인한 뒤 **저장**합니다

> 비밀번호를 Claude 대화창에 붙여 넣지 마세요. Claude 는 그 값을 쓰지 않습니다.

## 4. 한도·주의사항

- **하나의 앱 비밀번호를 메일·캘린더가 공용**합니다 — itda-hyve 에 한 번 등록하면 메일과 캘린더가 같은 계정을 씁니다(추가 발급 불필요).
- 발급 화면을 닫으면 다시 볼 수 없습니다. 분실 시 같은 메뉴에서 재발급하세요(기존 값은 무효화).
- "앱 비밀번호 오류"(로그인 실패)가 나면 흔한 원인 두 가지: ① 계정 본 비밀번호를 넣은 경우 ② 앱 비밀번호가 만료·삭제된 경우 — 재발급한 값으로 itda-hyve 계정 화면에서 교체하고 연결 테스트를 다시 하세요.
- 아이디는 `you` 가 아니라 `you@naver.com` **전체 이메일**을 넣어야 합니다.
