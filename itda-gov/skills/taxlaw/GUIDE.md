# taxlaw 사용 가이드

국세청 국세법령정보시스템(taxlaw.nts.go.kr)에서 세법 법령·세법해석례(예규)·판례/결정례·상담사례를 검색하고 전문(全文)까지 읽어 옵니다.
**Claude에게 말로 부탁하면 됩니다** — "양도소득세 예규 찾아줘", "부가가치세 판례 검색해줘"처럼요.

> ⚠️ 법제처 **국가법령정보센터(law.go.kr)와 다른 시스템**입니다. 이 스킬이 보는 곳은 국세청 국세법령정보시스템(taxlaw.nts.go.kr) 한 곳입니다.

**사전 준비가 없습니다.** API 키 발급도, 로그인도, 브라우저도 필요하지 않습니다.

---

## 빠른 시작

```
/taxlaw 가상자산 양도소득 관련 예규 찾아줘
/taxlaw 부가가치세 영세율 판례 검색해줘
/taxlaw 서면-2014-부가-22035 문서 찾아줘
```

기본은 핵심 4개 축(법령·세법해석례·판례/결정례·상담사례)을 축마다 10건씩 훑고, 축별 **전체 건수**와 각 결과의 원문 링크를 함께 보여줍니다.

---

## 활용 시나리오

### 쟁점 하나를 4개 축으로 한 번에 훑기

법령 조문·예규·판례·상담사례를 각각 따로 찾을 필요 없이 한 요청으로 전체 지형을 봅니다.

```
/taxlaw 가상자산 양도소득 쟁점을 법령·예규·판례·상담사례로 나눠서 정리해줘
```

### 문서번호로 바로 찾기

이미 문서번호를 알고 있다면 검색어 대신 번호를 그대로 말하면 됩니다. `부가가치세과-1196`, `서면-2014-부가-22035`, `서울고등법원-2025-누-7641` 같은 형식이 모두 됩니다.

```
/taxlaw 부가가치세과-1196 문서번호로 찾아서 전문까지 보여줘
```

### 법령 조문 확인

법 한 벌의 전 조문을 가져오거나 특정 조만 골라 볼 수 있습니다.

```
/taxlaw 국세기본법 제18조 조문 내용 보여줘
```

### 상담사례로 실무 답변 확인

국세상담센터에 올라온 유사 질의의 답변 전문을 확인합니다.

```
/taxlaw 중계무역 영세율 상담사례 찾아서 답변 전문 보여줘
```

## 조회·출력 옵션

| 옵션 | 설명 | 이렇게 말하세요 |
|------|------|-----------------|
| 검색 범위 | 법령·세법해석례·판례/결정례·상담사례(기본 4종) 외에 별표·서식, 전자도서관까지 확장 | "판례만 찾아줘", "별표·서식까지 포함해서 찾아줘" |
| 건수·페이지 | 축마다 기본 10건. 더 필요하면 다음 페이지로 이어서 | "30건씩 보여줘", "다음 페이지 더 보여줘" |
| 정렬 | 정확도순(기본) · 등록일순 · 생산일순 | "최신 등록순으로", "생산일 기준으로 정렬해서" |
| 포함어·제외어 | 결과 안에서 특정 단어를 포함하거나 걸러내기 | "결과 중 '수출' 들어간 것만", "'가산세'는 빼고" |
| 동의어 확장 | 비슷한 표현까지 넓혀서 검색 | "동의어까지 넓혀서 찾아줘" |
| 출력 형식 | 읽기 좋은 표(기본) · 구조화 JSON · 마크다운 | "JSON으로 뽑아줘", "마크다운으로 정리해줘" |

## 전문(全文) 읽기

검색으로 후보를 좁힌 뒤 문서를 고르고 이어서 요청하면 원문을 그대로 가져옵니다.

| 종류 | 가져오는 내용 |
|------|--------------|
| 판례·결정례 | 판결문 전문 |
| 세법해석례 | 질의·요지·회신 전문과 관련 법령 |
| 법령 | 법 한 벌의 전 조문 (특정 조만 골라 보기 가능) |
| 상담사례 | 답변 전문 |

```
/taxlaw 종합부동산세 위헌 관련 판례 찾고, 가장 최근 것 판결문 전문 읽어줘
```

## 팁

- **문서번호·날짜·원문 링크를 함께 남기세요.** 세무 판단의 근거는 문서 식별자가 전부입니다. Claude도 조사 보고에 이 세 가지를 함께 인용하도록 되어 있으니, 인용 전에 원문 링크로 한 번 더 확인하는 습관을 권합니다.
- **전체 건수를 먼저 보세요.** 축마다 "총 N건 중 몇 건 표시"가 나옵니다. 분모가 크면 검색어를 좁히거나 포함어·제외어를 얹는 편이 낫습니다.
- **법령 결과는 특정 시행일자 기준입니다.** 결과에 붙는 시행일자 표기를 확인하세요. 개정 전후를 비교해야 한다면 원문 링크에서 연혁을 직접 봐야 합니다.
- **문서번호를 알면 번호만 주세요.** 문서번호 검색은 별도 모드로 동작하므로, 키워드와 섞기보다 번호 하나만 그대로 주는 편이 정확합니다.
- **주제가 여러 개면 나눠서 요청하세요.** 서로 다른 주제의 조사는 각각 독립이라 따로 요청하는 편이 결과가 깔끔합니다.

## 제한사항

- ⚠️ **검색 결과는 참고자료입니다.** 사이트 안내 그대로, 개별 사안 적용은 세무 전문가 확인이 필요합니다.
- ⚠️ **별표·서식과 전자도서관은 검색까지만 됩니다.** 목록과 기본 정보는 볼 수 있지만 **첨부 파일 다운로드는 지원하지 않습니다.** 실제 서식 파일은 원문 링크에서 직접 받으세요.
- ⚠️ **세법해석례 중 '정비'(실효) 문서는 전문이 비어 있을 수 있습니다.** 검색 결과에는 나오지만 상세 조회에서 내용이 없을 수 있습니다.
- ⚠️ **대량 수집용이 아닙니다.** 조사·리서치 목적의 조회에만 사용하세요.
- ⚠️ **갑자기 오류가 반복되면 사이트 변경 신호입니다.** 응답 형식과 관련한 오류(`API status=...`, `기대와 다른 응답 형식`)가 계속 뜨면 국세법령정보시스템 내부가 바뀐 것이므로, 임의로 우회하지 말고 스킬 메인테이너에게 알려주세요.
