# fss-docs 사용 가이드

금융감독원 공통업무자료 게시판을 수집해 표로 정리합니다.
**Claude에게 자연어로 부탁하면 됩니다** — `/fss-docs 금감원 업무자료 확인해줘`, `/fss-docs 금감원에서 사모펀드 자료 찾아줘`처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

API 키·로그인이 필요 없습니다. 공개 게시판만 수집합니다.

---

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 말하세요 |
|--------------|-----------------|
| 최근 자료 확인 | `/fss-docs 금감원 공통업무자료 최근 10건 보여줘` |
| 키워드 검색 | `/fss-docs 금감원 자료 중에 사모펀드 관련만 찾아줘` |
| 기간 조회 | `/fss-docs 금감원 업무자료 이번 주 것만` |
| 엑셀 저장 | `/fss-docs 금감원 자료 목록 엑셀로 저장해줘` |

---

## 활용 시나리오

### 감독 자료 정기 확인

```
/fss-docs 금융감독원 공통업무자료 최근 10건 표로 정리해줘
```

날짜·제목·담당부서·첨부파일 수와 원문 링크가 표로 나옵니다.

### 특정 주제 자료 찾기

```
/fss-docs 금감원에서 주채무계열 관련 자료 올라온 것 있는지 확인해줘
```

### 첨부파일 확인

목록의 링크로 들어가면 상세 페이지에서 첨부(xlsx·hwp 등)를 내려받을 수 있습니다. 첨부파일명은 엑셀 저장 시 함께 기록됩니다.

---

## 결과에 포함되는 정보

날짜 · 제목 · 담당부서 · 첨부 건수(파일명은 엑셀에) · 원문 링크

## 팁

- 기본은 최근 10건, 1페이지만 요청합니다. 더 필요하면 "3페이지까지"처럼 말하세요.
- 이 게시판에는 사모펀드 현황·외국집합투자기구 등록현황·주채무계열 등 감독 실무 자료가 올라옵니다.

## 안 될 때

- "목록 행을 파싱하지 못했습니다" → 금감원 사이트가 개편됐을 수 있습니다. 스킬 업데이트가 필요합니다.
- 네트워크 오류 → 잠시 후 다시 시도해보세요 (자동으로 3회 재시도합니다).
