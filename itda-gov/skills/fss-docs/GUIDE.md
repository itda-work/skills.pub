# fss-docs 사용 가이드

금융감독원 공통업무자료 게시판을 모아 표로 정리하고, 원하면 자료의 첨부파일(엑셀·한글·PDF)까지 받아 줍니다.
아래 지침을 그대로 입력하면 바로 구동됩니다:

```
/fss-docs 금감원 공통업무자료 최근 10건 보여줘
```

"금감원 업무자료 확인해줘"처럼 자연어로 말해도 같은 스킬이 동작합니다.

---

## 사전 준비 — itda-hyve 만 있으면 됩니다

회원가입·API 키가 필요 없습니다. 금융감독원이 누구에게나 공개하는 게시판만 읽습니다.

금감원 사이트에는 **itda-hyve** 앱이 대신 요청을 보냅니다(Claude Code 와 Cowork 모두 같습니다). 아직 없다면
[itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치(0.10.4 이상)하고 Claude Desktop 에 연결하세요.

받은 게시판 화면과 첨부는 작업 폴더 아래 `fss-docs-runs/` 에 요청마다 새 폴더로 쌓입니다.
Cowork 에서는 연결한 폴더 안에 만들어집니다.

---

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 말하세요 |
|--------------|-----------------|
| 최근 자료 확인 | `/fss-docs 금감원 공통업무자료 최근 10건 보여줘` |
| 키워드 검색 | `/fss-docs 금감원 자료 중에 사모펀드 관련만 찾아줘` |
| 기간 조회 | `/fss-docs 금감원 업무자료 이번 주 것만` |
| 엑셀 저장 | `/fss-docs 금감원 자료 목록 엑셀로 저장해줘` |
| 첨부 받기 | 표를 받은 뒤 이어서 "1350번 자료 첨부파일 받아줘" |

## 활용 시나리오

### 감독 자료 정기 확인

```
/fss-docs 금융감독원 공통업무자료 최근 10건 표로 정리해줘
```

번호·날짜·제목·담당부서·첨부파일 수와 원문 링크가 표로 나옵니다.

### 특정 주제 자료 찾기

```
/fss-docs 금감원 자료 최근 30건에서 주채무계열 관련 자료 있는지 확인해줘
```

키워드와 기간은 **받아 온 목록 안에서** 찾습니다. 받은 범위가 좁으면 Claude 가 알려 주니, 더 넓게 보고 싶으면
"최근 100건에서"처럼 범위를 넓혀 다시 부탁하세요(한 번에 200건까지).

### 첨부파일까지 받기

```
/fss-docs 금감원 주채무계열 소속기업체 변동내용 자료의 첨부파일 받아줘
```

목록에 붙은 첨부(엑셀·한글·PDF)를 받은 뒤 형식이 온전한지(끝까지 받았는지) 검사합니다.
검사를 통과하지 못한 파일은 "첨부 미검증"으로 알려 드립니다. 이 게시판은 파일 크기를 표시하지 않아 크기 대조는 하지 않습니다.

---

## 결과에 포함되는 정보

번호 · 날짜 · 제목 · 담당부서 · 첨부 건수(파일명은 엑셀에) · 원문 링크. 첨부를 받으면 파일마다 검사 결과와 받은 위치.

## 빠짐없이 받았는지 확인합니다

금감원 목록에는 "전체 1351 건 · 페이지 1 / 136" 같은 표시와 게시물 번호가 있습니다. 이 스킬은 받은 쪽들이 그 표시와 번호에
**빈틈없이 맞는지** 대조한 뒤에만 결과를 냅니다. 받는 도중 새 자료가 올라와 목록이 밀리면 알아서 다시 받고,
그래도 맞지 않으면 멈춥니다 — 빠진 목록을 다 받은 것처럼 보여 주지 않습니다.

## 팁

- 기본은 최근 10건(1쪽)입니다. 더 필요하면 "3쪽까지" 또는 "최근 30건"처럼 말하세요. Claude 가 받기 전에 몇 번 요청하는지 알려 줍니다.
- 이 게시판에는 사모펀드 현황·외국집합투자기구 등록현황·주채무계열 등 감독 실무 자료가 올라옵니다.

## 실측 검증 (2026-09-30)

itda-hyve 로 실제 금감원 게시판을 받아 확인한 결과입니다.

**검증한 지침** — `/fss-docs 금감원 공통업무자료 최근 30건 보여줘`

- 3쪽(30건)을 받아 전체 1351건·136쪽 표시와 번호 1351~1322 가 빈틈없이 맞음을 확인했습니다. 첨부는 30건 모두에 있었고(엑셀 29·한글 11·PDF 1개),
  옛 판이 0건으로 세던 첨부 수가 바르게 나왔습니다.

**검증한 지침** — 이어서 "1350번, 1336번 자료 첨부파일 받아줘"

- 한글 파일 1개·엑셀 1개(1350번)와 PDF 1개(1336번, 약 6.5MB)를 받아 세 파일 모두 형식 검사를 통과했습니다.

## 안 될 때

- "itda-hyve 가 연결되지 않았다" → itda-hyve 를 설치(0.10.4 이상)하고 Claude Desktop 에 연결한 뒤 다시 부탁하세요.
- "목록이 끝까지 맞지 않았다" (`partial`) → 금감원 사이트가 점검 중이거나 개편됐을 수 있습니다. 잠시 뒤 다시 해 보고, 되풀이되면 스킬 업데이트가 필요합니다.
- "안내·차단 화면이 왔다" (`blocked`) → 사이트가 요청을 막은 상태입니다. 브라우저로 직접 확인하세요.
- 연결이 끊기거나 시간이 초과되면 Claude 가 같은 쪽을 세 번까지 다시 받습니다.
