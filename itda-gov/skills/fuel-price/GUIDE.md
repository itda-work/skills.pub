# fuel-price 사용 가이드

오피넷(한국석유공사) 주유소 **평균 유가**를 조회합니다 — 전국·시도별 × 일간/주간/월간, 전기 대비 등락, 과거 시점까지.
**Claude에게 자연어로 부탁하면 됩니다** — "오늘 기름값 얼마야", "서울 휘발유 가격"처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

---

## 사전 준비 — 없습니다

**회원가입·API 키 없이 바로 됩니다.** 오피넷이 누구에게나 공개하는 평균 판매가격 통계를 그대로 읽습니다.
현재 시세, 16개 시도별 가격, 지난 날짜·달 조회, 일간·주간·월간 시계열이 전부 키 없이 동작합니다.

> (선택) 오피넷 Open API 키가 있으면 일별 조회를 API 로도 할 수 있습니다. 대부분 필요 없습니다 — 아래 "선택: API 키" 참고.

---

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 요청하세요 |
|--------------|-----------------|
| 오늘 기름값 | `/fuel-price 오늘 기름값 얼마야` |
| 지역 기준 | `/fuel-price 서울 휘발유 가격` |
| 이달 월평균 | `/fuel-price 이달 전국 휘발유 월평균` |
| 경유·고급휘발유·등유 | `/fuel-price 인천 경유 가격 알려줘` |
| 최근 추세 | `/fuel-price 최근 두 달 주간 휘발유 추세 표로 보여줘` |
| 지난 특정 달 | `/fuel-price 지난 7월 부산 휘발유 평균가` |
| 특정 날짜 | `/fuel-price 8월 15일 경유 시세` |
| 두 시점 비교 | `/fuel-price 6월 대비 8월 휘발유 얼마나 내렸어` |
| 표로 정리 | `/fuel-price 올해 월별 휘발유 평균가 표로` |
| JSON 으로 | `/fuel-price 이달 평균가 JSON 으로 줘` |

## 활용 시나리오

### 오늘 시세 확인

```
/fuel-price 오늘 서울 휘발유 얼마야
```

```
2026년09월01일 서울 평균 보통휘발유 1,907.45원/L (전일 1,907.58 대비 ▼0.13원)
출처: 오피넷(한국석유공사) https://www.opinet.co.kr — 평균판매가격(부가세 포함, 원/리터)
```

오피넷은 **전일자까지 확정 통계**를 매일 새벽에 냅니다. "오늘"이라고 물으면 가장 최근 확정일(보통 어제) 값이 나오고, 기준일이 함께 표시됩니다.

### 월평균 — 정산·보고 기준값

유류비 정산 등에 쓰는 관행 기준값은 월평균입니다.

```
/fuel-price 이달 서울 휘발유 월평균 알려줘
```

조회 결과로 단가 계산이 필요하면 회사 규정 산식(예: 기준가 ÷ 연비 × 보정계수)을 Claude 에게 함께 말하세요 —
"기준가로 연비 12 기준 km당 단가 계산해줘"처럼 대화에서 바로 계산해 줍니다(스킬은 조회까지만 맡습니다).

### 유가 흐름 보기

```
/fuel-price 최근 두 달 주간 휘발유 추세 표로 보여줘
```

```
| 기간 | 전국 보통휘발유 (원/L) | 증감 |
|---|---:|---:|
| 2026년07월4주 | 1,872.39 | — |
| 2026년07월5주 | 1,869.08 | ▼3.31원 |
| 2026년08월1주 | 1,866.16 | ▼2.92원 |
| ... | | |
```

### 지난 시점 조회 — 소급 확인·감사 대응

"7월에 유가가 얼마였지?" 같은 상황입니다. 1997년부터 조회됩니다.

```
/fuel-price 지난 7월 부산 휘발유 평균가 알려줘
/fuel-price 2026년 8월 15일 경유 시세
```

### 지역 비교

지역을 바꿔 여러 번 물으면 비교 표를 만들어 줍니다.

```
/fuel-price 서울이랑 인천 이달 휘발유 월평균 비교해줘
```

**지원 지역(16개 시도)**: 서울 · 부산 · 대구 · 인천 · 전남광주(광주·전남 통합) · 대전 · 울산 · 경기 · 강원 · 충북 · 충남 · 전북 · 경북 · 경남 · 제주 · 세종. 시군구·개별 주유소는 오피넷 사이트에서 직접.

## 출력 형식 지정

| 원하는 형식 | 이렇게 요청하세요 |
|-------------|-----------------|
| 한 줄 요약(기본) | `/fuel-price 이달 평균가` |
| 기간별 표 | `/fuel-price 최근 6개월 월별 휘발유 표로` |
| JSON 원문 (다른 도구에 넘길 때) | `/fuel-price 이달 평균가 JSON 원문 그대로 줘` |

> 내부적으로 스킬은 항상 JSON(정형 데이터)을 내고, Claude 가 그 안의 완성 문구를 그대로 표·요약으로 보여줍니다 — 숫자가 변형되지 않습니다.

결과에는 항상 **출처(오피넷·한국석유공사)와 통계 기준일**이 붙습니다. 오피넷 저작권 정책상 출처 표기는 지우지 마세요.

## 팁

- **전국 vs 지역**: 일반적인 "기름값"은 전국 평균, 지역 물가·정산 기준이 필요하면 시도를 지정하세요. 서울은 전국보다 40~50원 높게 나오는 편입니다.
- **월간 vs 주간 vs 일간**: 보고·정산 기준값은 월평균, 흐름 파악은 주간, 지금 시세는 일간이 맞습니다.
- **유류비 단가가 필요하면**: 이 스킬은 기준가(원/L)까지 주고, km당 단가는 회사 규정(연비·보정계수)에 따라 Claude 가 대화에서 계산합니다. 규정값을 함께 말해 주세요 — 스킬이 값을 지어내지 않습니다.

## 안 될 때

| 증상 | 원인 / 해결 |
|------|-------------|
| "알 수 없는 지역" | 시·군·구나 "수도권" 같은 권역명. 위 16개 시도 중에서 골라 다시 요청 |
| "알 수 없는 제품" | LPG 등 4종(휘발유·고급휘발유·경유·등유) 밖. 오피넷 평균판매가격 통계에 없는 제품 |
| "… 까지만 있습니다" | 아직 통계가 안 나온 날짜·달(오피넷은 전일까지 확정). 날짜를 앞당기거나 "최신으로" |
| "기간 행이 없습니다" | 조회 기간에 통계 없음(너무 이른 과거 등). 기간을 조정 |
| "오피넷 화면 구조가 바뀐 것 같습니다" | 오피넷 사이트 개편. 스킬 업데이트가 필요하니 알려 주세요 — 임의로 다른 값을 쓰지 않습니다 |
| "오피넷 API 가 빈 결과" | (API 경로만) 키가 없거나 틀림. 오피넷은 에러 대신 빈 결과를 줍니다 — 키 확인 또는 기본 경로로 |
| "주간·월간 평균이 없습니다" | (API 경로만) API 는 최근 7일 일별만 제공. 기본 경로(키 불요)로 요청 |

## 선택: API 키 (`OPINET_API_KEY`)

기본 경로로 전부 되므로 **보통은 필요 없습니다.** 오피넷 Open API 로 최근 7일 일별 값을 받고 싶을 때만 발급합니다.

1. 오피넷 **유가정보 API 안내** 페이지를 엽니다 — https://www.opinet.co.kr/user/custapi/custApiInfo.do
2. 페이지 아래쪽 **「일반 API 이용 신청」** 을 누릅니다. 오피넷 회원이 아니면 회원가입(이름·휴대폰·이메일·아이디·비밀번호)이 먼저 뜹니다.
3. **자동 승인**되어 키가 즉시 발급됩니다(일반 API, 무료). 호출 제한은 페이지 안내 기준 하루 300회 — 이 스킬은 조회 1회에 1콜입니다.
4. 작업 폴더(Cowork 연결 폴더 / Claude Code 프로젝트 루트) 루트에 `.env` 파일을 만들고 한 줄을 넣습니다. 점(`.`)으로 시작하는 파일을 만들기 어렵다면 **`환경변수.txt`** 로 만들어도 똑같이 읽힙니다(메모장이 `.txt` 를 붙여 `.env.txt` 가 되어도 됩니다).

```dotenv
OPINET_API_KEY=발급받은_키
```

5. "API 로 최근 7일 일별 조회해줘" 라고 말하면 API 경로가 쓰입니다.

> 개발자라면 셸 환경변수나 `~/.claude/settings.json` 의 `env` 로 넣어도 됩니다.
> 프리미엄 API(전국 주유소 기본정보·판매가격 검색)는 공사와 제휴가 필요한 유료 서비스로, 이 스킬의 범위 밖입니다.

## 주의사항

- ⚠️ **평균가입니다.** 개별 주유소 가격·최저가 주유소 찾기는 하지 않습니다. 그건 오피넷 사이트·앱에서 직접 보세요.
- ⚠️ **시도 단위까지입니다.** 시·군·구 평균과 LPG(자동차용 부탄)는 지원하지 않습니다.
- ⚠️ **"오늘" 값은 전일 확정치입니다.** 오피넷이 매일 새벽 전일자 통계를 확정하는 구조라 당일 실시간가는 없습니다.
- ⚠️ **조회 전용입니다.** 유류비 정산 단가·공지문은 스킬이 만들지 않습니다 — 조회 결과에 회사 규정 산식을 적용해 대화에서 계산하세요.
- ⚠️ **출처를 지우지 마세요.** 산출물의 "출처: 오피넷(한국석유공사)" 표기는 오피넷 저작권 정책상 필수입니다. 내부 이용은 무방하지만 재배포·상업적 이용은 공사와 사전 협의가 필요합니다.
