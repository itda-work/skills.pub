# funding 사용 가이드

정부·공공기관 지원사업 공고를 **키워드로 검색하는 대신 전부 모아 놓고** 내 아이템에 맞는 것을 골라 줍니다.
아래 지침을 그대로 입력하면 바로 구동됩니다:

```
/funding 우리 아이템에 맞는 정부 지원사업 전수조사 해줘
```

자연어로 "정부 지원사업 전수조사 해줘"라고 말해도 같은 스킬이 동작합니다.
한 번 조사해 두면 다음부터는 `/funding 재조사해줘` 한마디로 **새로 올라온 것과 바뀐 것만** 추려서 알려 줍니다.

---

## 무엇이 달라지나요

키워드 검색은 "AI"로 찾으면 AI라는 말이 든 공고만 나옵니다. 그런데 실제로는 콘텐츠 제작지원이나
예술×기술 입주사업처럼, 아이템을 조금 다르게 설명하면 지원할 수 있는 사업이 훨씬 많습니다.

이 스킬은 **모집 중인 공고를 전부 모은 다음** 제목을 하나하나 읽어 후보를 뽑고,
후보는 **원문과 첨부파일까지 확인**해서 이렇게 나눠 줍니다.

| 분류 | 뜻 |
|------|-----|
| **A그룹** | 지금 신분·소재 그대로 바로 신청할 수 있는 것 |
| **B그룹** | 법인 설립·투자유치·지역 이전 같은 조건을 채우면 열리는 것 (로드맵) |
| **C그룹** | 아이템을 다른 각도로 설명하면 지원 가능한 것 (변형) |

여기에 **부재 확인**(기대할 만한 유명 사업이 지금은 모집 중이 아니라는 사실)과
**우선순위 액션 목록**(언제까지 무엇을 신청할지)이 함께 나옵니다.

---

## 어디를 조사하나요

| 소스 | 무엇이 올라오나 |
|------|-----------------|
| K-Startup | 창업진흥원 계열 + 지자체·창조경제혁신센터 창업지원 (기본) |
| 기업마당 | 전 부처·지자체 중소기업 지원사업 통합 (가장 양이 많음) |
| NIPA | AI 바우처, AI 융합, SaaS·클라우드 |
| SMTECH | 중기부 기술개발 R&D (디딤돌 등) — 목록에 함께 보이는 IRIS 공고도 제목·기간만 담습니다 |
| KOCCA | 콘텐츠 제작지원 — **목록은 자동으로 모으지 않습니다**(사이트의 robots 정책). 직접 찾은 공고 주소를 주면 원문·첨부는 확인해 드립니다 |

그냥 조사하면 K-Startup 을 봅니다. "전부 다 조사해줘"라고 하면 네 곳을 모두 훑고, "AI 쪽만"처럼 말하면 관련 소스만 봅니다.

> 로그인이 필요한 보조금24, 지역 테크노파크·진흥원 사이트는 자동 조사 대상이 아닙니다.
> 해당되는 경우 Claude가 "직접 확인해 보세요"라고 안내합니다.

---

## 사전 준비 — itda-hyve 만 있으면 됩니다

**회원가입·API 키 없이 됩니다.** 각 기관이 누구에게나 공개하는 공고 목록과 공고문을 그대로 읽습니다.

사이트에는 **itda-hyve** 앱이 대신 요청을 보냅니다(Claude Code 와 Cowork 모두 같습니다). 아직 없다면
[itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치(0.10.4 이상)하고 Claude Desktop 에 연결하세요.

결과를 저장할 폴더는 Cowork 에서 **연결한 폴더 안**이어야 합니다 — itda-hyve 가 그 폴더에 받아 두면 Claude 가 같은 파일을 읽습니다.

| 조사 범위 | 사이트 요청 수(대략) | 걸리는 시간 |
|-----------|---------------------|-------------|
| K-Startup 만 (기본) | 약 14번 | 수십 초 |
| 네 곳 전부 | 약 165번 | 1~2분 |
| 후보 상세·첨부 확인 | 후보 1건당 2~4번 | 후보 수에 비례 |

요청이 많은 조사는 Claude 가 **시작 전에 몇 번 요청하는지 알려 드리고 확인을 받습니다.**

---

## 첫 조사 — 이렇게 흘러갑니다

1. **프로필 질문** — 창업 단계(예비창업자/개인사업자/법인), 지역 연고, 대표자 연령대, 필요한 것(자금·공간·R&D…),
   아이템 한 줄 요약을 **한 번에 모아서** 묻습니다. 작업 폴더의 문서에서 알아낼 수 있는 건 묻지 않습니다.
2. **저장 위치 확인** — "결과를 이 폴더에 저장할까요?" 라고 먼저 물어봅니다.
   **동의하기 전에는 파일을 만들지 않습니다.** 다른 곳을 원하면 그때 말하면 됩니다.
3. **전수 수집** — 소스별로 모집 중인 공고를 모읍니다. 각 사이트 첫 쪽에서 전체 쪽 수를 확인한 뒤 끝까지 받고,
   빠진 쪽·중복이 없는지 번호로 맞춰 봅니다. 받는 사이 새 공고가 올라와 쪽이 밀리면 그 쪽만 다시 받습니다.
4. **후보 선별 후 확인** — "후보 N건을 뽑았습니다. 원문·첨부까지 검증할까요?" 라고 다시 물어봅니다.
   여기서 "네"라고 해야 상세 검증이 시작됩니다.
5. **보고서** — A/B/C 분류 + 부재 확인 + 우선순위 액션 + 한계 고지.

## 자주 쓰는 요청

아래 지침을 그대로 입력하면 됩니다 (자연어로 풀어 말해도 동작합니다):

| 하고 싶은 것 | 이 지침을 입력하세요 |
|--------------|-----------------|
| 처음부터 전체 조사 | `/funding 정부 지원사업 전수조사 해줘` |
| 아이템 맞춤 | `/funding 우리 아이템에 맞는 지원사업 찾아줘` |
| 소스를 넓게 | `/funding 빠짐없이 전부 다 조사해줘` |
| 분야를 좁혀서 | `/funding AI 쪽 지원사업 위주로 봐줘` |
| 재조사 (증분) | `/funding 지난번 이후 새로 나온 지원사업 있나?` |
| 마감 임박만 | `/funding 이번 주에 마감되는 것만 알려줘` |
| 로드맵 관점 | `/funding 법인 만들면 열리는 사업이 뭐가 있어?` |

## 활용 시나리오

### 처음 조사할 때

```
/funding 우리 아이템에 맞는 정부 지원사업 전수조사 해줘
```

프로필을 묻고, 저장 위치를 확인한 뒤 필요한 소스를 훑습니다. 결과는 회차 폴더에 보고서와 원본 데이터로 남습니다.

### 2~4주 뒤 다시 볼 때

```
/funding 지난번 이후 새로 나온 지원사업 있나?
```

직전 조사 폴더를 찾아 **신규·변경·종료된 공고만** 비교합니다. 그대로인 공고는 지난 판정을 이어받으므로
250건을 다시 읽지 않습니다. 마감이 연장된 공고, 지난번 A그룹이었는데 접수가 끝난 공고도 알려 줍니다.

### 상황이 바뀌었을 때

```
/funding 법인 설립했어. 프로필 갱신하고 다시 봐줘
```

프로필의 판정 기준(창업 단계·지역·연령 등)이 바뀌면 지난 판정을 이어받지 않고 **전체를 다시 검토**합니다.
예비창업자라서 걸렀던 사업이 A그룹으로 올라옵니다.

---

## 보고서에 담기는 것

- **A/B/C 3분류** — 각 공고의 마감일·지원 내용·신청 대상, **원문 링크 필수**
- **부재 확인** — 기대할 만한 유명 사업이 지금은 모집 중이 아니라는 안내
- **우선순위 액션** — 날짜별로 무엇을 언제까지 신청할지
- **한계 고지** — 어느 소스를 어디까지 수집했는지, 첨부를 확인하지 못한 건이 몇 건인지,
  '예비창업자 가능' 판정이 공고 문구 기준이라는 점

## 팁

- **"전부 다"라고 말해주세요.** 그냥 조사하면 창업지원 중심(K-Startup)만 봅니다.
  전 부처·지자체까지 훑으려면 "빠짐없이 전부"라고 말하는 편이 확실합니다.
- **기업마당은 모집 중인 공고만 1,500건이 넘습니다**(사이트 요청 약 107번). 끝까지 받지만, 보고서에 "쪽 상한"이
  적혀 있다면 전수가 아니라는 뜻입니다. 그때는 "기업마당도 끝까지 봐줘"라고 말하세요.
- **SMTECH 는 최근 공고 위주입니다.** 이 사이트 목록에는 지난 공고까지 모두 섞여 있어, 모집 중인 공고가 더 이상 안 보이는
  쪽이 이어지면 거기서 멈춥니다. 보고서에 "최근 구간"으로 표시됩니다.
- **콘텐츠 분야는 KOCCA 를 직접 봐주세요.** 목록 자동 수집은 사이트 정책상 하지 않습니다. 관심 공고의 주소를 주면 원문과 첨부를 확인해 드립니다.
- **재조사를 위해 저장 폴더를 지우지 마세요.** 직전 회차가 있어야 증분 비교가 됩니다.
- **'불명'은 정직한 답입니다.** 공고에 안 적힌 요건은 추측하지 않고 '불명'으로 남기고 문의처를 함께 줍니다.
  최종 신청 전에는 접수기관에 유선으로 확인하세요.
- **원본 공고 링크를 꼭 확인하세요.** 마감 시각(14:00·16:00 마감 등)이나 연장 여부는 원문이 정본입니다.

## 안 될 때

| 증상 | 원인 / 해결 |
|------|-------------|
| itda-hyve 를 찾을 수 없다고 나옴 | 앱이 설치·연결되지 않았거나 옛 버전입니다. [itda-hyve 받는 곳](https://itda.work/hyve/)에서 0.10.4 이상을 설치하고 Claude Desktop 에 연결하세요 |
| 결과가 "일부만 수집됨"이라고 나옴 | 쪽 상한에 걸렸거나, 받는 사이 목록이 계속 바뀌었거나, 일부 소스에서 오류. "끝까지 다시 수집해줘"라고 하면 새 회차로 범위를 넓혀 재시도합니다 |
| 특정 소스가 "수동 확인"으로 남음 | 그 사이트가 접근을 차단한 상태. 우회하지 않는 것이 원칙이라 해당 사이트만 직접 방문해 주세요 |
| 첨부파일 내용이 안 보임 | K-Startup 첨부는 사이트 정책상 링크만 수집됩니다. 링크로 직접 내려받아 확인하세요 |
| "첨부 미변환 — 설치 안내"가 뜸 | HWP·PDF 첨부 변환은 `itda-doc` 플러그인(hwpx·pdf-context-refinery)이 함께 설치돼 있어야 합니다 |
| 보고서에 "미검증 쪽: p.N" 이 적힘 | 그 PDF 첨부의 해당 쪽이 스캔이라 글자를 읽지 못했습니다. 신청자격·배점표가 그 쪽에 있으면 원문을 직접 확인해 주세요 |
| 수집 건수가 0건 | "미완 수집"으로 보고합니다(0건을 성공으로 적지 않습니다). 사이트 점검·개편 또는 차단 의심 — 잠시 후 재시도하고, 계속되면 원 사이트를 직접 확인해 주세요 |

## 주의사항

- ⚠️ **전수라고 해서 100%는 아닙니다.** 자동 수집은 네 곳이고, KOCCA 목록·지역 테크노파크·NIA·IITP·IRIS 등은
  자동 조사 대상이 아닙니다. 연고 지역 기관은 직접 확인하세요.
- ⚠️ **로그인 기반 서비스는 조사하지 않습니다.** 보조금24 같은 개인 맞춤 지원금은 본인이 직접 확인해야 합니다.
- ⚠️ **공고 시점과 실시간 동기화되지 않습니다.** 최종 신청 직전에는 보고서의 원문 링크로 재확인하세요.
- ⚠️ **프로필에는 판정에 필요한 정보만 저장합니다.** 주민번호·계좌 같은 개인정보는 기록하지 않습니다.

## v1.0.0 변경 안내 (이전 버전 사용자)

0.9.x 까지의 **키워드 검색·연도별 통합공고 현황 기능은 제거**되었습니다.

| 예전 요청 | 지금은 |
|-----------|--------|
| "AI 지원사업 검색해줘" | `/funding AI 쪽 지원사업 전수조사 해줘` — 전수 수집 후 A/B/C 분류로 답합니다 |
| "모집 중인 것만 찾아줘" | 전수조사가 기본적으로 모집 중 공고만 모읍니다 |
| "2026년 청년창업 통합공고 현황" | 대체 기능 없음. K-Startup 사이트에서 직접 확인하세요 |

바뀐 이유는 키워드 검색이 **변형 지원 가능한 사업을 구조적으로 놓치기 때문**입니다.
전수 수집 후 직접 읽는 방식이 같은 시간에 훨씬 많은 기회를 찾아 줍니다.
