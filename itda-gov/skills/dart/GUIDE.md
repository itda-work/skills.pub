# dart 사용 가이드

금융감독원 DART 전자공시시스템에서 기업 정보를 조회합니다.
**Claude에게 자연어로 부탁하면 됩니다** — "삼성전자 재무제표 알려줘", "경쟁사 직원수 비교해줘"처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

---

## 사전 준비 — API 키 발급

DART 스킬은 금융감독원 DART API 키가 필요합니다.

1. [금융감독원 DART](https://opendart.fss.or.kr)에서 회원가입
2. **오픈 API → 인증키 신청/관리** → 사용 목적 입력 후 신청 → **40자리 키 즉시 발급** (별도 승인 대기 없음)
3. 발급받은 키를 **itda-hyve 앱의 시크릿 탭**에 `DART_API_KEY` 이름으로 등록합니다. 키 값은 itda-hyve 에만 저장되고 대화에는 나오지 않습니다. Claude Code·Cowork 모두 같은 방법입니다.

DART 조회는 itda-hyve(사용자 PC 에서 도는 도우미 앱)가 대신 받아 옵니다. itda-hyve 가 설치돼 있지 않으면 Claude 가 설치를 안내합니다. 받아 온 원본 응답은 연결한 작업 폴더의 `dart` 폴더에 저장되고, 같은 자료는 다시 받지 않습니다(기업 목록·기업개황은 7일까지 다시 씁니다).

> 자세한 가입·키 발급 절차는 [DART 발급 가이드](https://itda.work/credentials/dart/)를 참고하세요.

키 값을 대화창에 붙여 넣지 마세요 — 붙여 넣어도 쓰지 않고 시크릿 탭 등록을 다시 안내합니다.

### 첫 호출이 실패할 때

- 키가 40자리 영숫자인지, 앞뒤에 공백은 없는지 확인하세요.
- 발급 직후에는 수 분간 일시적으로 미반영될 수 있습니다. 키를 확인했거나 고쳤다면 "키 고쳤어, 다시 해줘"라고 말하세요 — Claude 가 실패한 자료를 새로 받아 옵니다(같은 날이어도 기다릴 필요가 없습니다).
- "활용신청 URL: ..." 안내가 보이면 [https://opendart.fss.or.kr](https://opendart.fss.or.kr)에서 키 활용 상태를 확인하세요.

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 요청하세요 |
|--------------|-----------------|
| 기업 종합 프로필 | `/dart 카카오 기업 정보 정리해줘` |
| 재무제표 조회 | `/dart 삼성전자 2024년 재무제표 알려줘` |
| 전체 재무항목 | `/dart 삼성전자 2023년 전체 재무항목 다 보여줘` |
| 직원현황 | `/dart 네이버 2024년 직원현황 알려줘` |
| 기업 검색 | `/dart DART에서 '현대' 들어간 회사 찾아줘` |
| 공시 목록 | `/dart 삼성전자 2024년 공시 목록 알려줘` |
| 사업보고서 본문 | `/dart 삼성전자 최신 사업보고서 사업의 내용 섹션 추출해줘` |
| 여러 기업 비교 | `/dart 삼성전자, LG전자, SK하이닉스 2024년 매출액과 영업이익 비교해줘` |
| 분기·최신 데이터 | `/dart SK하이닉스 가장 최신 재무 데이터 조회해줘 (분기·반기 포함)` |
| CSV로 저장 | `/dart 삼성전자 재무제표를 엑셀 파일로 저장해줘` |
| 전기 비교 포함 | `/dart 삼성전자 2023년 재무를 전기와 함께 보여줘` |

## 활용 시나리오

### 경쟁사·고객사 종합 프로필

회사명 하나로 기업개황·재무제표·직원현황까지 한 번에 조회합니다.

```
/dart 카카오 기업 정보 정리해줘
```

### 연도별 재무 추이 비교

경쟁사의 매출·영업이익 추이를 연도별로 비교해 시장 분석 보고서를 만듭니다.

```
/dart 카카오 2022년, 2023년, 2024년 매출 비교해줘
```

### 다기업 재무 비교

여러 기업의 주요 계정을 한 번에 비교하고 원하는 경우 영업이익률·순이익률까지 함께 확인합니다.

```
/dart 삼성전자, LG전자, SK하이닉스 2024년 매출액과 영업이익 비교해줘
```

### 분기·최신 데이터

사업보고서(연 1회)보다 최신 데이터가 필요할 때 분기·반기 보고서까지 포함해 자동 탐색할 수 있습니다.

```
/dart SK하이닉스 가장 최신 재무 데이터 조회해줘
```

### 사업보고서 본문 추출

"사업의 내용" 같은 서술형 섹션을 텍스트로 바로 추출합니다.

```
/dart 삼성전자 최신 사업보고서 사업의 내용 섹션 추출해줘
```

### 공시 목록 추적

특정 기간의 공시 이력을 확인합니다.

```
/dart 삼성전자 2024년 공시 목록 알려줘
```

### 결과를 엑셀로 저장

조회 결과를 엑셀에서 바로 열 수 있는 CSV 파일로 내보냅니다.

```
/dart 삼성전자 2024년 재무제표를 CSV 파일로 저장해줘
/dart 삼성전자, LG전자 비교 결과를 엑셀용 파일로 만들어줘
```

## 출력 형식 지정

출력 형식을 자연어로 함께 말하면 그에 맞게 정리해 줍니다.

| 원하는 형식 | 이렇게 요청하세요 |
|-------------|-----------------|
| 사람이 읽기 좋은 표 | `/dart 삼성전자 2024년 재무제표 표로 보여줘` |
| 엑셀 파일 | `/dart 삼성전자 2024년 재무제표 CSV 파일로 저장해줘` |
| 전기 비교 포함 | `/dart 삼성전자 2024년 재무제표 전기 수치와 함께 보여줘` |
| 증감률도 함께 | `/dart 삼성전자 2024년 재무제표 전기 대비 증감률도 같이 보여줘` |

## 팁

- **공식 법인명을 쓰세요**: "카카오" 대신 "주식회사 카카오", "네이버" 대신 "네이버주식회사"처럼 전체 법인명으로 조회하면 정확도가 높아집니다. 축약형으로 조회했을 때 동명 계열사가 섞이면 "DART에서 '카카오' 들어간 회사 찾아줘"로 먼저 목록을 확인하세요.
- **종합 조회를 우선 요청하세요**: 기업개황·재무·직원 정보를 따로 요청하는 대신 "○○ 기업 정보 정리해줘"처럼 통합 조회로 시작하면 한 번에 볼 수 있습니다.
- **연도를 몰라도 됩니다**: 연도를 따로 말하지 않으면 최근 사업보고서를 자동으로 찾아 조회합니다.
- **분기 데이터가 필요하면**: 사업보고서는 보통 3월 말에 공시됩니다. 더 최신 데이터가 필요하면 "가장 최신 분기 데이터로 알려줘"라고 말하세요.
- **여러 기업 비교 시 계정명도 말해주세요**: "삼성전자, LG전자, SK하이닉스 2024년 매출액, 영업이익, 자산총계 비교해줘"처럼 원하는 계정을 함께 말하면 더 정확하게 비교해 줍니다.

## 안 될 때

| 증상 | 원인 / 해결 |
|------|-------------|
| "API 키가 없다"는 안내 (`secret_missing`) | itda-hyve 시크릿 탭에 `DART_API_KEY` 가 없음. 위 "사전 준비" 3번 |
| "기업을 찾을 수 없습니다" | 회사명 불일치. 공식 법인명 전체로 재검색하거나 "DART에서 ○○ 검색해줘"로 목록 확인 |
| "재무 데이터가 없습니다" | 해당 연도 미공시. 이전 연도로 다시 요청 |
| 권한 오류 (`010`/`011`/`012`) | [https://opendart.fss.or.kr](https://opendart.fss.or.kr)에서 키 활용 상태 확인. 고친 뒤 "다시 해줘"라고 하면 새로 받아 옵니다 |
| 요청 한도 초과 (`020`) | Claude 가 잠시 뒤 두 번까지 다시 받습니다. 그래도 같으면 하루 20,000건 한도라 다음 날 다시 시도 |
| 공시 목록이 너무 많다는 확인 질문 | 기간이 길어 1,000건을 넘습니다. 기간을 좁히거나 "전부 받아줘"라고 답하세요 |
| 시스템 점검 (`800`) · 정의되지 않은 오류 (`900`) | Claude 가 잠시 뒤 두 번까지 다시 받습니다. 그래도 같으면 DART 점검이 끝난 뒤 다시 요청 |
| "다른 질의의 자료가 섞였다"는 안내 | 받은 파일 이름과 내용이 달라 결과를 내지 않은 것입니다. Claude 가 그 자료를 다시 받습니다 |
| "공시 목록 건수가 계속 맞지 않는다"는 안내 | 받는 사이 공시가 계속 올라오는 중입니다. 기간을 어제까지로 좁히거나 잠시 뒤 다시 요청 |

## 주의사항

- ⚠️ **상장사·공시 기업만 조회 가능합니다.** DART는 금융감독원 전자공시 시스템입니다. 비상장·미공시 스타트업·개인사업자는 조회되지 않습니다.
- ⚠️ **API 키와 itda-hyve 가 있어야 조회할 수 있습니다.** [opendart.fss.or.kr](https://opendart.fss.or.kr)에서 발급받은 40자리 키를 itda-hyve 시크릿 탭에 등록해야 합니다(위 "사전 준비").
- ⚠️ **하루 조회 한도가 있습니다.** 키당 일 20,000건 한도입니다. 대량 분석 시 여러 세션에 나눠 조회하세요.
