# realty-supply 사용 가이드

KOSIS(국가통계포털) 주택 공급 지표(미분양·인허가·착공·준공)와 청약홈 분양 공고를 수집합니다.
**Claude에게 자연어로 부탁하면 됩니다** — `/realty-supply 올해 전국 아파트 미분양 추이 보여줘`, `/realty-supply 2024년 전국 인허가·착공·준공 통계 가져와줘`처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

---

## 처음 설정하기

이 스킬은 **itda-hyve** 앱이 대신 요청을 보냅니다. 아직 없다면 [itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치하고 Claude Desktop 에 연결하세요.
키 값은 itda-hyve 에만 저장되고, 스킬과 대화에는 이름만 오갑니다. Claude Code 와 Cowork 모두 같은 방법입니다.

### KOSIS 공급 지표

1. [kosis.kr](https://kosis.kr/openapi/)에 회원가입하고 Open API 활용신청을 합니다(자동 승인).
2. 마이페이지에서 인증키를 복사합니다. 끝의 `=` 까지 전부 복사하세요.
3. 복사한 키를 **itda-hyve** 앱의 **시크릿** 탭에 `KOSIS_API_KEY` 이름으로 등록합니다.

> KOSIS 가입·키 발급 절차는 [KOSIS 발급 가이드](https://itda.work/credentials/kosis/)를 참고하세요.

### 청약홈 분양 공고

1. 공공데이터포털의 [한국부동산원 청약홈 분양정보 조회 서비스](https://www.data.go.kr/data/15098547/openapi.do)를 **따로 활용신청**합니다. `realty-deals` 를 쓰고 있어 키가 있어도, 이 데이터셋은 신청해야 합니다.
2. 마이페이지의 **Decoding** 키를 **itda-hyve** 앱의 **시크릿** 탭에 `KO_DATA_API_KEY` 이름으로 등록합니다(이미 있으면 그대로 씁니다).
3. itda-hyve 0.10.4 전에 `KO_DATA_API_KEY` 를 등록했다면 같은 시크릿의 **허용 호스트**에 `api.odcloud.kr` 를 추가합니다(0.10.4 이후 새로 등록한 키는 이미 들어 있습니다 — 프리셋 변경은 새 등록에만 적용됩니다). 청약홈 서비스는 공공데이터포털의 다른 API 와 주소가 달라서, 추가하지 않으면 "이 주소로는 키를 보낼 수 없다"(`secret_host_denied`)는 안내가 나옵니다.

> 자세한 가입·키 발급 절차(Decoding 키 주의사항 포함)는 [공공데이터포털 발급 가이드](https://itda.work/credentials/data-go-kr/)를 참고하세요.

키 값을 대화창에 붙여 넣지 마세요. 붙여 넣어도 스킬은 그 값을 쓰지 않고 시크릿 탭 등록을 안내합니다.

## 지원하는 데이터

| 데이터 | 설명 | 활용 예 |
|------|------|---------|
| 미분양 | 팔리지 않은 신규 분양 주택 수(시·군·구별) | 공급 과잉·해소 추적 |
| 인허가 | 신규 주택 건설 허가 호수(시도별) — **그 해 1월부터의 누계**로 나옵니다 | 향후 공급 선행지표 |
| 착공 | 공사를 시작한 주택 수(시도별) | 공급 진행 단계 파악 |
| 준공 | 공사가 완료된 주택 수(시도별) | 입주 물량 추정 |
| 청약 분양 공고 | 청약홈 모집공고 — 단지명·공급지역·공급 세대수·접수일·당첨자 발표일 | 분양 일정 파악 |

⚠️ **청약 경쟁률은 제공하지 않습니다.** 청약홈 분양정보 서비스에 경쟁률 항목이 없습니다.

## 알아두면 좋은 점

- **청약 데이터 시작 시점**: 청약 데이터는 2020년 2월부터 제공됩니다. 그 이전 기간을 요청해도 데이터가 없으며, 없는 구간에 데이터를 만들어 채우지 않습니다.
- **청약 공고가 많을 때**: 기간이 길어 받을 쪽이 많으면 Claude 가 받기 전에 몇 번 요청하는지 알려 주고 확인을 받습니다. 모자란 채로 결과를 말하지 않습니다.
- **지역 단위**: 시·군·구까지 나오는 것은 미분양뿐입니다. 인허가·착공·준공은 시도(서울·경기 …) 단위라 "강남구 착공" 처럼 물으면 결과가 없다고 알려 드립니다.
- **값이 비어 있는 칸**: KOSIS 표에서 `-` 로 표시된 칸은 0 이 아니라 "값 없음"으로 보여 줍니다.
- **선행지표로 활용**: 인허가 → 착공 → 준공 순서로 공급 파이프라인을 파악할 수 있습니다. `/realty-supply 인허가부터 준공까지 전 단계 보여줘`처럼 한 번에 요청해도 됩니다.

## 안 될 때

| 증상 | 원인 / 해결 |
|------|-------------|
| "시크릿이 없다"는 안내 (`secret_missing`) | itda-hyve 시크릿 탭에 `KOSIS_API_KEY` 또는 `KO_DATA_API_KEY` 가 없습니다. 위 "처음 설정하기" 확인 |
| 청약 요청에서 "이 주소로는 키를 보낼 수 없다" (`secret_host_denied`) | `KO_DATA_API_KEY` 의 허용 호스트에 `api.odcloud.kr` 를 추가하세요(itda-hyve 0.10.4 전에 등록한 키) |
| 청약 요청에서 인증 오류 (`-401`) | 청약홈 분양정보 데이터셋 활용신청을 했는지, Decoding 키를 등록했는지 확인 |
| KOSIS 인증 오류 (`10`·`11`) | KOSIS 키가 비었거나 기간이 끝났습니다. 마이페이지에서 확인·연장 |
| KOSIS "조회결과 초과" (`31`) | 기간이 너무 깁니다. 기간을 나눠 요청하세요 |
| 청약 데이터가 없음 | 2020년 2월 이전 구간은 데이터가 제공되지 않습니다 |
