# realty-jeonse-gap 사용 가이드

매매와 전월세 실거래를 단지·전용면적 기준으로 대조해 **전세가율**과 **갭**을 계산하고, 조건에 맞는 후보를 추려드립니다.
`/realty-jeonse-gap 강남구 아파트 전세가율 80% 넘는 단지 찾아줘`, `/realty-jeonse-gap 분당 연립다세대 갭 3천만 이하 목록 뽑아줘`처럼 말하면 됩니다.

---

## 처음 설정하기

이 스킬은 공공데이터포털 API 키가 필요합니다. 아파트 매매·전월세 두 서비스를 모두 신청해야 합니다.

1. [data.go.kr](https://www.data.go.kr)에 가입합니다.
2. 아파트 매매 실거래 서비스를 활용신청합니다: https://www.data.go.kr/data/15126469/openapi.do
3. 아파트 전월세 실거래 서비스를 활용신청합니다: https://www.data.go.kr/data/15126474/openapi.do
4. 발급받은 키를 **itda-hyve 앱의 "시크릿" 탭**에 `KO_DATA_API_KEY` 라는 이름으로 등록합니다(itda-hyve 0.10.4 이상이 없으면 [여기서 내려받아](https://itda.work/hyve/) 설치하고 Claude Desktop 에 연결합니다). 키 값은 그 앱 안에만 저장되고 Claude 에게는 전달되지 않습니다(Claude 는 이름만 씁니다). Claude Code 와 Cowork 모두 같은 방법입니다.

> 공공데이터포털은 같은 키를 **Encoding / Decoding** 두 형태로 보여 줍니다. **Decoding 키**를 등록하세요 — Encoding 키를 넣으면 "등록되지 않은 서비스키"(resultCode 30) 오류가 납니다.

> 자세한 가입·키 발급 절차는 [공공데이터포털 발급 가이드](https://itda.work/credentials/data-go-kr/)를 참고하세요.

키 값을 Claude 대화창에 붙여 넣지 마세요 — Claude 는 그 값을 쓰지 않습니다.

> 자동승인이라도 동기화에 5~30분이 걸릴 수 있습니다. 신청 직후 오류가 나면 잠시 기다렸다가 다시 요청하세요.

## 계산 방식

| 지표 | 산식 |
|------|------|
| **전세가율** | 전세보증금 ÷ 매매가 × 100 (%) |
| **갭** | 매매가 − 전세보증금 (만원) |

- **전세보증금은 전세 계약만** 씁니다. 월세·반전세 계약의 보증금은 전세가가 아니라서 넣지 않습니다(넣으면 전세가율이 2%처럼 엉뚱하게 낮아집니다).
- 같은 단지·전용면적에 전세 실거래가 여러 건이면 **보증금의 중간값(중위값)** 을 기준으로 계산합니다. 같은 기간에 새 계약과 갱신 계약(인상 5% 상한)이 섞여 있어, 가장 높은 값이나 가장 낮은 값은 한 건에 끌려가기 때문입니다. 결과에는 그 단지·면적의 전세 건수와 최저·최고 보증금도 함께 나옵니다.
- **해제된 매매는 뺍니다.** 계약 뒤 해제 신고된 매매는 실제 시세가 아니므로 기본으로 계산에서 빼고, 몇 건을 뺐는지 알려 드립니다. 넣고 싶으면 "해제 거래도 포함해줘"라고 말하세요.

## 알아두면 좋은 점

- **조건 없이도 사용 가능**: 전세가율·갭 필터를 말하지 않으면 해당 지역·기간의 모든 단지 결과를 보여줍니다. 필터는 선택사항입니다.
- **복수 전세 처리**: 같은 단지·면적에 전세 거래가 여러 건이면 보증금의 중간값을 기준으로 전세가율을 계산합니다. 전세 건수가 1건인 단지는 그 한 건이 기준이니 참고용으로 보세요.
- **기본 유형은 아파트**: 유형을 따로 말하지 않으면 아파트 실거래를 기준으로 스크리닝합니다.
- **요청 수가 많습니다**: 한 달마다 매매·전월세를 쪽(100건)마다 받습니다. 강남구 아파트 전월세는 한 달에 11~15쪽이라, 6개월이면 요청이 100번 가까이 됩니다. Claude 가 먼저 예상 요청 수를 알려 드리고 범위를 확인합니다.
- **다 받은 뒤에만 결과를 냅니다**: 일부 쪽만 받은 상태로 계산하면 전세가율이 틀리므로, 빠진 쪽이 있으면 Claude 가 마저 받은 뒤 계산합니다.
- **받는 사이 거래가 늘면 다시 받습니다**: 실거래는 매일 추가됩니다. 앞 쪽과 뒤 쪽을 받는 사이 목록이 바뀌면 그 달을 처음부터 다시 받아야 하는데, 이미 받은 파일을 덮어쓰게 되므로 Claude 가 먼저 물어봅니다.
- **지역명 인식 오류 시**: `/realty-jeonse-gap 법정동코드 11680으로 검색해줘`처럼 법정동코드(5자리)로 직접 지정할 수 있습니다.

## 안 될 때

| 증상 | 원인 / 해결 |
|------|-------------|
| "키가 등록되지 않았다"는 안내 (`secret_missing`) | itda-hyve 시크릿 탭에 `KO_DATA_API_KEY` 가 없음. 위 "처음 설정하기" 확인 |
| "등록되지 않은 서비스키" (`api`, 코드 30) | Encoding 키를 등록했을 가능성. 시크릿 탭에 **Decoding 키**로 다시 등록 |
| 권한 오류 (`api`, 코드 20) | 매매·전월세 두 서비스 중 하나를 활용신청하지 않았거나 동기화 대기 중. 5~30분 후 다시 요청 |
| 일일 요청 한도 초과 (`api`, 코드 22) | 공공데이터포털 일일 트래픽을 다 썼음. 기간을 줄이거나 다음 날 다시 요청 |
| "지역을 모르겠다"는 안내 (`args`) | 지역명을 다시 말하거나 법정동코드 직접 지정을 요청 |
| API 서비스 오류 (`api`) | 공공데이터포털 활용신청 승인 상태를 확인하고 다시 요청 |
| 결과가 없음 | 해당 기간에 조건을 만족하는 실거래가 없을 수 있습니다. 기간을 늘리거나 조건을 완화해 다시 요청하세요 |
