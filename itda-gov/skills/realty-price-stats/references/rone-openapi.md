# R-ONE 통계 조회 Open API — 요청 계약 (판독 2026-09-30)

한국부동산원 부동산통계정보시스템 R-ONE 의 「통계 조회 조건 설정」 서비스. `rone` 명령의 정본 근거다.

## 근거

| 무엇 | 어디서 | 판독 |
|---|---|---|
| 상세주소·기본인자·요청인자·출력값·메시지 코드 | R-ONE → Open API → Open API 목록 → 「통계 조회 조건 설정」(`https://www.reb.or.kr/r-one/portal/openapi/selectServicePage.do`) | 2026-09-30, aside 브라우저로 DOM 판독 |
| sample 키 동작(키 없으면 pIndex 1·pSize 5 고정) | 같은 페이지 기본인자 표 · 개발가이드(`…/openapi/openApiDevPage.do`) | 2026-09-30 |
| 통계표 ID | R-ONE → Open API → 통계코드 검색(`…/openapi/openApiGuideCdPage.do`) 에서 「아파트 매매가격지수」·「매매가격지수」·「전월세전환율」 검색 | 2026-09-30 |
| 응답 형태·기간 필터·오류 본문 | itda-hyve `http_request` 로 **키 없이** 부른 sample 응답 5종(`tests/fixtures/rone/`) | 2026-09-30 |

인증키를 넣은 호출(여러 쪽·1,000행 쪽)은 이 머신 itda-hyve 에 `RONE_API_KEY` 가 없어 아직 실측하지 못했다 — Cowork 실측 대기.

## 요청

```
GET https://www.reb.or.kr/r-one/openapi/SttsApiTblData.do
```

| 인자 | 필수 | 뜻 | 스킬이 넣는 값 |
|---|---|---|---|
| `KEY` | 필수(없으면 sample) | 인증키 | `{{secret:RONE_API_KEY}}` |
| `Type` | 필수(기본 xml) | 호출 문서 `xml`·`json` | `json` |
| `pIndex` | 필수(기본 1) | 페이지 위치 | 쪽 번호 |
| `pSize` | 필수(기본 100) | 페이지 당 요청 숫자 — **최대 1,000**(`ERROR-336`) | `1000` |
| `STATBL_ID` | 필수 | 통계표 ID | 아래 표 |
| `DTACYCLE_CD` | 필수 | 주기코드 | `WK`·`MM` |
| `WRTTIME_IDTFR_ID` | 선택 | 자료작성 시점(단일) | 쓰지 않는다 |
| `GRP_ID`·`CLS_ID`·`ITM_ID` | 선택 | 그룹·분류·항목 ID | 쓰지 않는다(지역 필터는 받은 뒤 스크립트가 한다) |
| `START_WRTTIME`·`END_WRTTIME` | 선택 | 자료작성 시점 시작·종료 | 기간(양끝 포함 — 월간 202601~202603 = 690행 = 230지역 × 3, 실측) |

옛 코드가 쓰던 `apiKey`·`statbl_id`·`strtYymm`·`endYymm`·`format` 과 통계표 `HPIWK`·`HPIMON`·`JRRATE` 는 이 계약에 없다(0.11.0 까지의 결함).

## 주간 시점 ID — 달력으로 확정하지 않는다

W2 재리뷰(2026-09-30)가 키 없는 sample 을 `WRTTIME_IDTFR_ID=<id>` 로 **31표본**(2015~2026) 조회한 결과다. 없음 = `INFO-200`.

| ID | `WRTTIME_DESC` | 비고 |
|---|---|---|
| `201553` | 없음 | 2015 는 52주 |
| `201601` · `201653` · `201701` | 2015-12-28 · 2016-12-26 · 2017-01-02 | 1월 1일 금(윤년) — 53주 있음, ISO 와 갈림 |
| `201952` · `201953` · `202001` | 2019-12-23 · 없음 · 2019-12-30 | |
| `202052` · `202053` · `202101` · `202102` | 2020-12-21 · 없음 · 2020-12-28 · 2021-01-04 | ISO 로는 202101 = 2021-01-04 |
| `202152` · `202153` · `202201` · `202202` | 2021-12-20 · 없음 · 2021-12-27 · 2022-01-03 | |
| `202226` · `202228` · `202252` · `202253` · `202301` · `202302` | 2022-06-20 · 07-04 · 12-19 · 12-26 · 2023-01-02 · 01-09 | 2022 는 53주 |
| `202552` · `202553` · `202601` · `202602` | 2025-12-22 · 없음 · 2025-12-29 · 2026-01-05 | |
| `202626` · `202627` · `202636` · `202638` · `202639` · `202640` | 06-22 · 06-29 · 08-31 · 09-14 · 09-21 · 없음(미공표) | 조회 시점 최신 공표 202639 |

1차 리뷰·구현 실측에서 값이 적힌 표본 중 위에 없는 것: `202127` 2021-06-28 · `202227` 2022-06-27 · `202401` 2024-01-01 · `202501` 2024-12-30 · `202609` 2026-02-23.
범위 질의 4건(`202152~202228` 등)의 `list_total_count` 는 주 수 × 지역 수(223·230)와 정확히 맞았다 — R-ONE 은 ID 문자열 범위로 거른다.

- 표본에 맞는 규칙: 주를 **일~토**로 끊고 1월 1일이 든 주를 1주로 센다. 라벨은 그 주의 월요일(엑셀 `WEEKNUM(토요일, 1)`).
  1월 1일이 금·토인 해(2016·2021·2022, 앞으로 2027·2028)에 ISO 와 한 주 갈린다.
- 공표된 규칙이 아니라 표본에서 세운 규칙이다. 그래서 스크립트는 이 규칙으로 **어림**만 하고 요청 창을 앞뒤로 한 주씩 넓힌다
  (연 경계에서는 시작 쪽을 전년 `52`, 끝 쪽을 다음 해 `01` 로 — 52·53주를 모두 덮는다). 받은 행은 `WRTTIME_DESC`(그 주 월요일)가
  시작월 1일~종료월 말일 안인 주만 남기고(양끝 날짜 포함), 거른 수를 출력 `period_filter` 에 싣는다.
- **연초 첫 주의 귀속** — R-ONE 이 "2021년 1주" 라 부르는 `202101`(월요일 2020-12-28)은 월요일 기준이라 **2020년 12월 요청에 들고
  2021년 1월 요청에서는 빠진다.** R-ONE 사이트의 연·주 표기와 한 주 다를 수 있다.
- 결손 신호는 둘이다. ① **안쪽 결손** — 요청 기간의 월요일 중 결과에 없는 주(가장 늦게 공표된 주까지)는 경고한다.
  ② **끝 결손** — 넓힌 창이 모자라 기간 마지막 주와 그 뒤 주가 함께 빠지면 ①은 못 본다. 창이 충분했다면 기간 뒤 한 주가 반드시
  잘려 나오므로 `dropped_after == 0` 이 신호다 — 기간 끝에서 14일이 지났으면 경고한다(그 전은 미공표일 수 있어 경고하지 않는다).
  시작 쪽은 과거라 늘 공표돼 있어 ±1주 창과 첫 주 대조로 충분하다.
- 골든 표: `tests/test_rone.py` `RONE_WEEK_GOLDEN`(31표본)·`RONE_WEEK_GOLDEN_EXTRA`(5).

**정정 이력** — 0.12.0 초판은 202609 → 2026-02-23 **한 표본**으로 "시점 ID = ISO 주차" 를 확정했다. 2026 년은 1월 1일이 목요일이라
우연히 같았을 뿐이고, 2021·2022 년 요청은 기간이 앞뒤로 한 주씩 밀린 채 전량 대조를 통과했다(리뷰 M1 — 예: 202201~202206 을
202152~202226 으로 받아 2021-12-20 주가 들어오고 2022-06-27 주가 빠졌다). 규칙 `collection-completeness` ⑩(한 표본으로 계약을
확정하지 않는다)이 경고한 형태 그대로다.

## 응답

성공(HTTP 200, content-type 은 `text/html` 로 온다):

```json
{"SttsApiTblData": [
  {"head": [{"list_total_count": 230}, {"RESULT": {"CODE": "INFO-000", "MESSAGE": "정상 처리되었습니다."}}]},
  {"row": [{"STATBL_ID": "T244183132827305", "DTACYCLE_CD": "WK", "WRTTIME_IDTFR_ID": "202609",
            "GRP_ID": null, "GRP_NM": null, "CLS_ID": 50001, "CLS_NM": "전국", "ITM_ID": 10001, "ITM_NM": "지수",
            "DTA_VAL": 98.8572393202812, "UI_NM": "지수", "GRP_FULLNM": null, "CLS_FULLNM": "전국",
            "ITM_FULLNM": "지수", "WRTTIME_DESC": "2026-02-23"}]}]}
```

출력값 15개: `STATBL_ID`·`DTACYCLE_CD`·`WRTTIME_IDTFR_ID`·`GRP_ID`·`GRP_NM`·`CLS_ID`·`CLS_NM`·`ITM_ID`·`ITM_NM`·`DTA_VAL`(숫자)·`UI_NM`·
`GRP_FULLNM`·`CLS_FULLNM`(예: `서울>강북지역>도심권`)·`ITM_FULLNM`·`WRTTIME_DESC`. 응답은 쪽 번호(`pIndex`)를 되돌려주지 않는다 — 스킬은 저장 이름으로 쪽을 안다.

오류(HTTP 200, 실측 2건):

```json
{"RESULT": {"CODE": "ERROR-300", "MESSAGE": "필수 값이 누락되어 있습니다. 요청인자를 참고 하십시오."}}
{"RESULT": {"CODE": "ERROR-290", "MESSAGE": "인증키가 유효하지 않습니다. 인증키가 없는 경우, 홈페이지에서 인증키를 신청하십시오."}}
```
