# customs-notice 사용 가이드

관세청 공지사항 게시판을 모아 표로 정리하고, 원하면 공지의 첨부파일까지 받아 줍니다.
아래 지침을 그대로 입력하면 바로 구동됩니다:

```
/customs-notice 관세청 공지사항 최근 10건 보여줘
```

"관세청 공지 확인해줘"처럼 자연어로 말해도 같은 스킬이 동작합니다.

---

## 사전 준비 — itda-hyve 만 있으면 됩니다

회원가입·API 키가 필요 없습니다. 관세청이 누구에게나 공개하는 공지사항 게시판만 읽습니다.

관세청 사이트에는 **itda-hyve** 앱이 대신 요청을 보냅니다(Claude Code 와 Cowork 모두 같습니다). 아직 없다면
[itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치(0.10.4 이상)하고 Claude Desktop 에 연결하세요.

받은 게시판 화면과 첨부는 작업 폴더 아래 `customs-notice-runs/` 에 요청마다 새 폴더로 쌓입니다.
Cowork 에서는 연결한 폴더 안에 만들어집니다.

---

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 말하세요 |
|--------------|-----------------|
| 최근 공지 확인 | `/customs-notice 관세청 공지사항 최근 10건 보여줘` |
| 키워드 검색 | `/customs-notice 관세청 공지에서 원산지 관련된 것만 찾아줘` |
| 기간 조회 | `/customs-notice 관세청 이번 달 공지 정리해줘` |
| 엑셀 저장 | `/customs-notice 관세청 공지 최근 20건 엑셀로 저장해줘` |
| 첨부 받기 | 표를 받은 뒤 이어서 "1626번 공지 첨부파일 받아줘" |

---

## 활용 시나리오

### 매주 공지 훑어보기

```
/customs-notice 관세청 공지사항 이번 주 것만 표로 정리해줘
```

번호·날짜·제목·작성자와 원문 링크가 표로 나옵니다. 링크를 누르면 관세청 상세 페이지로 이동합니다.

### 업무 키워드 모니터링

```
/customs-notice 관세청 공지 최근 50건에서 FTA나 원산지 관련 공지 있으면 알려줘
```

키워드와 기간은 **받아 온 목록 안에서** 찾습니다. 받은 범위가 좁으면 Claude 가 "받은 5쪽 안에서만 찾았다"고 알려 주니,
더 넓게 보고 싶으면 "최근 100건에서"처럼 범위를 넓혀 다시 부탁하세요(한 번에 200건까지).

### 첨부파일까지 받기

```
/customs-notice 관세청 공지 중 개인정보 영향평가 공지의 첨부파일 받아줘
```

공지 상세 화면에서 첨부 목록을 읽고 파일을 받은 뒤, **게시판이 표시한 파일 크기와 같은지**, PDF·HWP·엑셀 형식이 온전한지(끝까지 받았는지)
검사합니다. 검사를 통과하지 못한 파일은 "첨부 미검증"으로 알려 드립니다.

### 보고용 엑셀 만들기

```
/customs-notice 관세청 공지 최근 30건을 엑셀 파일로 저장해줘
```

## 결과에 포함되는 정보

번호 · 날짜 · 제목 · 작성자 · 조회수(엑셀) · 원문 링크. 첨부를 받으면 파일마다 검사 결과와 받은 위치.

## 빠짐없이 받았는지 확인합니다

관세청 목록에는 "전체 1,626 건 1/163 페이지" 같은 표시와 게시물 번호가 있습니다. 이 스킬은 받은 쪽들이 그 표시와 번호에
**빈틈없이 맞는지** 대조한 뒤에만 결과를 냅니다. 받는 도중 새 공지가 올라와 목록이 밀리면 알아서 다시 받고,
그래도 맞지 않으면 "목록이 계속 바뀐다"며 멈춥니다 — 빠진 목록을 다 받은 것처럼 보여 주지 않습니다.

## 팁

- 기본은 최근 10건(1쪽)입니다. 더 필요하면 "최근 30건"처럼 말하세요. Claude 가 받기 전에 몇 번 요청하는지 알려 줍니다.
- 한 번에 받을 수 있는 첨부는 공지 10건까지입니다.

## 실측 검증 (2026-09-30)

itda-hyve 로 실제 관세청 게시판을 받아 확인한 결과입니다.

**검증한 지침** — `/customs-notice 관세청 공지 최근 20건에서 설명회 관련만 보여줘`

- 2쪽(20건)을 받아 전체 1,626건·163쪽 표시와 번호 1626~1607 이 빈틈없이 맞음을 확인하고, 제목에 "설명회"가 든 2건을 표로 냈습니다
  ("2027년 관세청 정보화사업 통합 설명회", "2026년 관세청 해외통관제도 설명회 및 상담회 개최 안내").
- 키워드가 받은 20건 안에서만 찾은 것이라는 안내가 함께 나왔습니다.

**검증한 지침** — 이어서 "1626번, 1625번 공지 첨부파일 받아줘"

- 1626번은 첨부 PDF 1개를 받아 게시판 표시 크기(124,771바이트)와 같고 PDF 끝 표지가 있음을 확인했고, 1625번은 첨부가 없다고 답했습니다.

## 안 될 때

- "itda-hyve 가 연결되지 않았다" → itda-hyve 를 설치(0.10.4 이상)하고 Claude Desktop 에 연결한 뒤 다시 부탁하세요.
- "목록이 끝까지 맞지 않았다" (`partial`) → 관세청 사이트가 점검 중이거나 개편됐을 수 있습니다. 잠시 뒤 다시 해 보고, 되풀이되면 스킬 업데이트가 필요합니다.
- "안내·차단 화면이 왔다" (`blocked`) → 관세청이 요청을 막은 상태입니다. 브라우저로 사이트를 직접 확인하세요.
- 연결이 끊기거나 시간이 초과되면 Claude 가 같은 쪽을 세 번까지 다시 받습니다.
