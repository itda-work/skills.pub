# 가족 `corporate` — 코퍼레이트 리포트

경영진·이사회가 30초 안에 지표를 읽는 문서. v0.2 골격의 개선판 — **카드를 KPI·콜아웃에만** 쓰고 나머지는
헤어라인으로 구획해 표면 위계를 세운다. 기본 팔레트 `samsung-sds`(대안 `consulting-mbb`).

## 골격 토큰

| 축 | 값 |
|---|---|
| 페이지 | `--bg` 전면. 본문 컨테이너 760px, 표·차트 브레이크아웃 1040px. ≥1100px 에서 좌측 232px 스티키 TOC |
| 히어로 | **밝은 배경**(`--bg`) + 상단 4px `--accent` 룰 하나. eyebrow(sans 12px 600 자간 .04em `--g500`) → h1 `clamp(32px,5.5vw,52px)` 700 → 부제 17px `--g700` → 메타 `<dl>` 4열 그리드(라벨 11px `--g500` / 값 14px tabular). 하단 1px `--line`. 밴드·그라데이션 금지 |
| 표면 3단 | ① 카드(`--paper` + 1px `--line` + radius 6px): **KPI·콜아웃·결정 카드만** ② 헤어라인 패널(보더 없음, 상단 1px `--line` + 캡션): 표·figure·타임라인 ③ 맨 본문 |
| 라운드·그림자 | radius 6px. 그림자 0(토글 버튼 제외) |
| 라벨 | sans 12px 600 자간 .04em `--g500`. **mono 는 문서번호·표 안 수치 스파크·Exhibit 류 식별자에만** |
| 섹션 | 번호 `01` sans 13px 700 `--accent` + h2 28px + 리드 16px `--g700`. 섹션 간 72px, 섹션 위 1px `--line` |
| KPI 스트립 | 카드 수 4 → 4열, 5~6 → 3열, 7~8 → 4열 2행(`grid-template-columns` 를 **명시**, auto-fit 금지 — 고아 카드 금지). 값 32px 700 tabular `--ink`(액센트 아님), 델타 12px 부호+색, 보조 11px `--g500` |
| 표 | 헤더 배경 없음 + 하단 2px `--ink` 룰, 헤더 12px 600 소문자 `--g700`. 행 구분 1px `--line`. 합계 행 `--tint` 배경 + 상단 2px `--accent` — **`th`·`td` 모두** 적용. 셀 스파크바·프로그레스바 허용 |
| 차트 | §3 그대로. 2계열 = `--accent` + `--g300`(파랑 두 톤 금지). 막대 `rx=2`. 값 라벨 sans 11px 600 |

| 타임라인 | 수직: 점(10px, `--paper` 채움 + 2px `--line`, 활성은 `--accent` 채움) + 선 1px `--line` + **카드 없이** 날짜 mono 12px `--accent` + 제목 15px 700 + 설명 13.5px |
| TOC | 좌측 보더 2px `--line`, 활성 `--accent` + 600. 라벨 `Contents` 는 sans 11px 600 |
| 푸터 | 상단 1px `--line`, 12px `--g500`, `<dl>` 가로 배열 |

## 금지

- 표·figure·details 를 카드로 감싸기(보더 박스 중첩)
- 짙은 단색 히어로 밴드, 다색 그라데이션, 히어로 안 KPI
- mono 대문자 eyebrow·섹션 번호·표 헤더
- KPI 값에 액센트색(값은 `--ink`, 액센트는 델타·섹션 번호·차트 주 시리즈에만)
- `grid-template-columns: repeat(auto-fit, …)` 로 KPI 배치

## 가족 자기검증 (§10 에 추가)

- [ ] 카드(보더 박스)가 KPI·콜아웃·결정 카드 외에 없다
- [ ] 히어로 배경 = `--bg`, 밴드 없음
- [ ] KPI 그리드 열 수가 명시돼 있고 마지막 행 고아 없음
- [ ] 합계 행 첫 셀(`th`)에도 tint 적용
- [ ] 라벨·헤더에 mono 대문자 없음(문서번호 제외)
