# 가족 `editorial` — 에디토리얼

연차보고서·브랜드 매거진처럼 **읽히는** 문서. 여백·리듬·타이포 대비가 구조를 말한다. 기본 팔레트
`warm-editorial`(대안 `print-broadsheet`). display 폰트(Georgia 계열 세리프)는 라틴·숫자·h1 에만.

## 골격 토큰

| 축 | 값 |
|---|---|
| 페이지 | `--bg`(크림) 전면. **본문 640px**(좁게), 브레이크아웃 2단계: 표·차트 960px, 풀폭 인용 1200px. 좌측 TOC 는 ≥1100px 에서 유지하되 폭 200px, 보더 없이 텍스트만(활성 `--accent`) |
| 히어로 | 밴드 없음. eyebrow(sans 12px 600 자간 .06em `--g500`) → h1 **`clamp(40px,7vw,72px)` 세리프 스택**(`"<display>",Georgia,"Noto Serif KR","Apple Myungjo",serif` — 한글 글리프는 로컬 명조로 떨어짐, 없으면 Pretendard 폴백 허용) 400 weight, line-height 1.1 → 데크(부제) 19px `--g700` 최대 48ch → 바이라인 행(작성·일자, 13px). 히어로 하단 **굵은 룰 2px `--ink`**(마스트헤드 감각) |
| 섹션 | 번호 대신 **세리프 h2 34px**(라틴·숫자 세리프, 한글은 sans 600) + 상단 여백 96px + h2 위 짧은 24px×2px `--accent` 대시. 리드 문장 18px `--g700` 1.6 |
| 본문 타이포 | 본문 16px / 1.8. 첫 섹션 첫 문단 **드롭캡**(세리프 3줄, `--accent`) 1회만. 인용은 `<blockquote>` 풀폭 브레이크아웃: 세리프 26px `--ink` + 좌측 4px `--accent` 없이 위아래 1px `--line` |
| 사이드노트 | ≥1100px: 본문 옆 우측 여백에 `<aside class="side">` 13px `--g500`(주석·출처·정의). 미만: 본문 뒤 각주 스타일 |
| KPI | 카드 금지. **숫자 문단**: 4~5개를 가로 배열, 값 40px 세리프 `--ink` + 라벨 13px `--g500` + 델타 12px, 항목 사이 좌측 1px `--line`. 배경 없음 |
| 표면 | 카드·박스 금지(콜아웃 제외). 표·figure 는 상하 1px `--line` 만. radius 0~4px. 그림자 0 |
| 표 | 헤더 배경 없음 + 하단 1px `--ink`, 헤더 12px 600 소문자. 행 1px `--line`, 마지막 행 하단 1px `--ink`. 숫자 tabular. 합계 행 볼드(배경 없음) |
| 차트 | §3 그대로. 색은 `--accent`(코랄) 1 + `--accent-2`(틸) 1 + `--g300`. 라인 차트 우선(추이), 그리드 최소(수평 3줄), 축 라벨 세리프 금지(sans 11px) |
| 콜아웃 | 박스 대신 **풀 블리드 색면**: `--tint` 배경이 컨테이너 밖까지, 안쪽 본문 640px, 레이블 sans 12px 600 `--accent`. ≥2개 |
| 타임라인 | 수평 연표 우선(년·월 축 + 점 + 짧은 캡션), 수직이면 카드 없이 텍스트만 |
| 부록·푸터 | `<details>` 는 상하 1px `--line` 만. 푸터는 세리프 소제목 `Colophon` + 13px 메타 |

## 금지

- 카드 그리드, 보더 박스 중첩, pill 배지(등급은 텍스트·점)
- 짙은 히어로 밴드, 그라데이션, 이미지 대체 목적의 큰 아이콘
- 한글 세리프를 웹폰트로 추가(CDN 1건 계약) — 로컬 명조 스택 + Pretendard 폴백만
- 본문 700px 초과, 좁은 본문을 표가 아닌 텍스트로 깨기
- 세리프 h1 에 음수 letter-spacing(한글 필터)

## 가족 자기검증 (§10 에 추가)

- [ ] h1 세리프 스택 + 40px 이상, 히어로 밴드 없음
- [ ] 본문 컨테이너 ≤ 700px, 풀폭 인용·색면 콜아웃 각 ≥1
- [ ] 카드(보더 박스) 0(콜아웃 색면 제외)
- [ ] KPI 가 숫자 문단 형태(배경 없음)
- [ ] 드롭캡 정확히 1회
