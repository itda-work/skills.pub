# 가족 `public-kr` — 공공기관 보고서형

정부·지자체·공공기관·정부출연연에 제출하거나 내부 결재에 올리는 보고서. 한국 행정 문서의 **개조식 번호
체계·격자 표·흑백 인쇄 우선·명조 제목** 관행을 HTML 로 옮긴다. 팔레트 `gov-mono` 고정(강조 1색만 사용자 hex 치환 가능).
다크 모드 계약(§6)은 유지하되 토글 기본은 라이트, 인쇄는 흑백에서 정보 손실 0 이 목표.

## 인쇄 강화 (§7 위에 추가)

- `@page { size: A4; margin: 20mm 18mm; }` + `@page { @bottom-center { content: "- " counter(page) " -"; } }`
- 흑백 판독: 의미색은 부호(▲▼·상중하)와 반드시 병기, 차트 패턴 fill 은 `print-color-adjust: exact` 없이도 보이게 SVG 패턴으로
- 표지는 `break-after: page`, `Ⅰ.` 대제목마다 `break-before: auto`(강제 페이지 나눔 금지 — 빈 페이지 방지)

## 금지

- 컬러 배경 밴드, 카드 그리드, pill 배지, 이모지, 그라데이션, 그림자
- 색만으로 등급·증감 구분
- 섹션 번호를 `01 02` 아라비아 2자리·mono 로 표기(로마 숫자 Ⅰ Ⅱ 텍스트)
- 표·차트의 본문 폭 초과 브레이크아웃(인쇄 동형 깨짐)
- 한글 세리프 웹폰트 CDN 추가

## 가족 자기검증 (§10 에 추가)

- [ ] 표지 존재(문서번호·보고일·기관명·명조 h1), 색 배경 0
- [ ] 대제목이 `Ⅰ. Ⅱ.` 텍스트, 하위가 `1. 가. 1)` + `□ ○ -` 개조식
- [ ] 모든 표가 격자(4면 보더) + `<표 N>` 캡션 + 출처/주석
- [ ] 차트가 흑백에서 계열 구분 가능(패턴 또는 명도 차 ≥ 2단계) + `<그림 N>`
- [ ] `붙임`·`끝.` 표기 존재, 인쇄 페이지 번호 `- N -`
