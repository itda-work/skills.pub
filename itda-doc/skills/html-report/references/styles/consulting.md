# 가족 `consulting` — 컨설팅 문서형

MBB 류 임원 보고 문법. **제목이 주장(액션 타이틀)** 이고 본문은 근거다. 시각 장식 대신 규율(같은 자리의
Exhibit 번호·출처·페이지 헤어라인)이 정체성. 기본 팔레트 `consulting-mbb`(대안 `samsung-sds`·`print-broadsheet`).

## 골격 토큰

| 축 | 값 |
|---|---|
| 페이지 | `--bg` 백지. 본문 720px, 표·차트 1000px. 좌측 스티키 TOC 는 ≥1100px 에서 유지하되 `Contents` 대신 **`목차`** + 번호 없이 액션 타이틀 축약(≤22자) |
| 히어로 | 표지형: eyebrow(클라이언트/부서·문서 유형·기밀 등급, sans 12px 600) → h1 = **문서 전체의 결론 한 문장**(clamp 30px~44px, 700, 최대 2줄) → 부제 = 근거 요약 1문장 → 메타 행(작성·일자·버전·배포 범위). 배경 `--bg`, 상단 8px `--accent` 두꺼운 룰(consulting-mbb 네이비). 이미지·밴드 금지 |
| 액션 타이틀 | 모든 h2 는 **주장형 문장**(명사구 금지, 마침표 없음, ≤40자). h2 위에 sans 12px 600 `--g500` 로 "논점 N" 표기. h3 는 근거 소제목(명사구 허용) |
| 핵심 요약 | 히어로 직후 **`Executive Summary` 박스**: `--tint` 배경, 좌측 4px `--accent`, 번호 목록 3~5개(각 1문장 + 뒷받침 수치 1개). 콜아웃 ≥2 계약은 이 박스 + "권고" 박스로 충족 |
| Exhibit | 모든 figure·표 위에 `Exhibit N` sans 12px 700 `--accent` + 제목(설명형 명사구) + 아래 **출처 라인 필수**(`자료: …` 11px `--g500`). figcaption(§3 주장 캡션)은 유지 |
| 표면 | 카드 금지. 패널은 `--tint` 색면 + 상하 1px `--line`. radius 2px(거의 직각). 그림자 0 |
| KPI | 스트립 대신 **숫자 행**: `<dl>` 4~6열, 값 28px 700 tabular `--accent`, 라벨 12px `--g500`, 델타 12px. 셀 사이 좌측 1px `--line` 구분, 배경 없음 |
| 표 | 헤더 `--accent` 배경 + `--bg` 글자 12px 600(mbb 네이비 헤더). 행 1px `--line`, 소계 상단 2px `--ink`. 합계 행 볼드 + `--tint`. **의미색은 숫자에만**(행 배경 tint 금지) |
| 차트 | §3 그대로 + 주 시리즈 `--accent`, 비교군 `--accent-2`(mbb 아이스 블루)·`--g300`. 강조 1개는 `--ink`. 4면 프레임 금지, 값 라벨 11px 600. 워터폴·불릿 우선 검토 |
| 권고·의사결정 | 문서 끝 `권고` 섹션: 번호 카드 대신 **표**(권고 / 근거 / 필요 자원 / 시한 / 담당) |
| 푸터 | 헤어라인 + 좌 `자료 출처 종합` · 우 `문서번호 · 기밀 등급`. 인쇄 시 `@page` 하단 페이지 번호(`counter(page)`) |
| 라벨 | sans 12px 600 자간 .04em. mono 는 Exhibit 번호·문서번호에만 |

## 금지

- 명사구 h2("2분기 실적" ✗ → "2분기 매출은 12% 성장했으나 원가가 이익을 잠식했다" ✓)
- 제목 밑 액센트 라인, 카드 그리드, pill 배지(등급 표시는 텍스트 + 점)
- 출처 없는 Exhibit, 번호 없는 figure·표
- 팔레트 외 색, 그림자·입체, 본문 가운데 정렬
- 히어로에 KPI 나열(결론 문장 1개만)

## 가족 자기검증 (§10 에 추가)

- [ ] 모든 h2 가 문장형 액션 타이틀(≤40자)
- [ ] 모든 figure·표에 `Exhibit N` + 출처 라인
- [ ] Executive Summary 박스 존재(번호 3~5)
- [ ] 카드(보더 박스)·pill 0
- [ ] 히어로 h1 이 문서 결론 문장
