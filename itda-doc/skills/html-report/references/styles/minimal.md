# 가족 `minimal` — 미니멀 문서

Notion·Linear 문서 감각. **보더 0, 헤어라인 1px, 좁은 본문, 코드·표가 1급**. 인시던트 회고·기술 문서·사내
가이드. 기본 팔레트 `minimal-mono`(대안 `tech-vivid-dark`·`equity-research-dark` — 다크 부팅).

## 골격 토큰

| 축 | 값 |
|---|---|
| 페이지 | `--bg` 전면. 본문 **680px**, 브레이크아웃 920px. ≥1100px 좌측 TOC 220px: 보더·번호 없이 텍스트 13px, 활성 `--ink` 700(액센트 아님), 들여쓰기로 h3 계층 표시 |
| 히어로 | 밴드·룰 없음. 상단 여백 96px → eyebrow(문서 유형·상태 배지 텍스트, sans 12px 500 `--g500`) → h1 `clamp(30px,4.5vw,40px)` 700 → 요약 1문단 16px `--g700` → 메타 **인라인 행**(`작성 · 일자 · 버전 · 상태`, 13px `--g500`, 구분 `·`). 하단 1px `--line` 후 본문 |
| 섹션 | 번호 없음. h2 24px 700 + 상단 64px + 리드 15px `--g700`. h3 18px 600. 헤딩 앵커 `#` 링크(hover 시 표시) |
| 표면 | **보더 박스 0**. 패널이 필요하면 `--tint` 색면(radius 6px, 보더 없음). 그림자 0 |
| 라벨 | sans 12px 500 `--g500`. 상태·등급은 **텍스트 배지**: `--tint` 배경 + 11px 500 + radius 4px(pill 금지), 의미색은 점(6px) 또는 글자색 |
| KPI | 카드 금지. **인라인 스탯 행**: `<dl>` 가로 flex, 값 24px 600 tabular `--ink`, 라벨 12px `--g500`, 항목 간 32px, 상하 1px `--line`. 4~6개. 델타(§2-3)는 원본에 비교 기준(전기·목표)이 있을 때만 — 장애 회고처럼 기준이 없으면 생략이 정상 |
| 표 | 헤더 배경 없음 + 하단 1px `--ink`, 12px 500. 행 1px `--line`, 셀 패딩 8px 12px(조밀). 긴 표 sticky 헤더 `--bg`. 코드 셀 mono 12.5px |
| 코드 블록 | `<pre>` `--tint` 배경, mono 13px, 좌측 보더 없음, 상단 우측에 언어 라벨 11px `--g500`. 인라인 `<code>` `--tint` + 1px 패딩 |
| 차트 | §3 그대로 + 색은 `--ink` 1 + `--accent` 강조 1 + `--g300`. 축·그리드 최소(수평 3줄, 축선 없음). 시계열 라인은 1.5px. 캡션 13px `--g500` |
| 콜아웃 | `--tint` 색면 + 좌측 2px 의미색 + 레이블 12px 500. 종류: 참고 `--accent` / 주의 `--warn` / 위험 `--neg` / 결정 `--ink`. ≥2 |
| 타임라인(회고) | **표 형태 우선**(시각 · 이벤트 · 담당 · 상태) 또는 mono 시각 + 텍스트 수직 목록(점·선 없음) |
| 체크리스트·액션 | `<ul>` 에 네이티브 `<input type=checkbox disabled checked>` 허용(액션 아이템 상태) |
| 푸터 | 1px `--line` + 13px `--g500` 인라인 메타 |

## 다크 부팅 프리셋(`tech-vivid-dark`·`equity-research-dark`) 추가 규칙

- 기본 `data-theme` 미지정 시 다크로 부팅하되 `prefers-color-scheme: light` 면 라이트 부팅(§6). 인쇄는 무조건 라이트.
- 액센트(그린·옐로)는 **문서당 강조 3곳 이하**(핵심 수치·활성 TOC·주 시리즈). 배경 glow·그라데이션 금지.
- 차트 그리드 `--line`, 축 텍스트 `--g500`, 값 라벨 `--ink` — 다크 검수 필수.

## 금지

- 보더 박스(카드·표 래퍼·figure 박스·details 박스) — 색면·헤어라인만
- 섹션 번호, mono 대문자 라벨, pill 배지, 히어로 밴드·룰·그라데이션
- 본문 720px 초과, 장식용 아이콘
- 액센트색 4곳 이상 남발(다크 프리셋)

## 가족 자기검증 (§10 에 추가)

- [ ] `border:` 로 그려진 박스 0(헤어라인 `border-top/bottom` 1px 만)
- [ ] 히어로에 배경색·룰 없음(`--bg` 그대로)
- [ ] KPI 가 인라인 스탯 행
- [ ] 코드 블록 있으면 `--tint` 색면 + 언어 라벨
- [ ] 다크 부팅 프리셋이면 라이트 부팅 분기 + 인쇄 라이트 강제 존재
