## 0.3.0 (2026-09-03)

스타일을 **골격 가족 × 팔레트** 2축으로 분리 (#1642). 종전은 단일 골격 + 컬러 스킴 3종이었다.

- 골격 가족 5종 신설: `corporate`(코퍼레이트 리포트) · `consulting`(컨설팅 문서형 — 액션 타이틀·Exhibit·출처 규율) · `editorial`(에디토리얼 — 세리프 h1·좁은 본문·풀폭 인용·사이드노트) · `minimal`(미니멀 문서 — 보더 0·헤어라인·코드 1급) · `public-kr`(공공기관 보고서형 — Ⅰ·1·가·1) 개조식·격자 표·흑백 인쇄 우선·명조 제목). 스펙은 `references/styles/<가족>.md`, 정본 인덱스는 `references/styles/README.md`.
- 팔레트 축을 형제 스킬(docx/pptx/xlsx-design)과 같은 `design-core/library/` 프리셋 8종 + `gov-mono` 로 통일. 값은 단일 파일 원칙대로 `:root` 인라인. 사용자 DESIGN.md 치환 지원. 구 프리셋 3종(네이비·웜·다크)은 하위 호환 표로 흡수.
- 워크플로우 2단계를 "테마 확정" → "스타일 확정(가족 × 팔레트)" 으로 개정: 신호 있음 → 즉시 / 무신호 대화형 → AskUserQuestion 가족 후보 2~3 + "알아서" / 비대화형 → 자동 선택 + 근거.
- 공통 계약 개정: 히어로 기본을 짙은 밴드에서 밝은 배경 + 룰 하나로, 라벨을 mono 대문자에서 sans 12px 600 으로, KPI 열 수 명시(auto-fit 고아 금지), 2계열 차트 색은 액센트 + 뉴트럴(같은 색 두 톤 금지), 합계 행 선택자 `tr.tot > *`(행 머리 th 포함), 한글 헤딩 음수 자간 금지(design-core 한글 가드 정합).
- 가족별 샘플 5건(`references/sample-*.html`) — 기존 분기 보고 샘플은 `corporate × samsung-sds` 로 재작성하며 실측 결함 3건(KPI 5+1 고아 · 합계 th tint 누락 · 그룹 막대 파랑 두 톤) 해소.
