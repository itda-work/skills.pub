# imagegen 사용 가이드

발표자료·블로그·문서에 넣을 이미지를 만듭니다. **Claude에게 말로 부탁하면 됩니다** — "블로그 대표 이미지 만들어줘", "쇼츠용 세로 삽화 만들어줘", "이 주제로 포스터 만들어줘"처럼요.

케이스별로 **실측 검증된 프롬프트 템플릿**을 갖춰 두어, 같은 요청이라도 품질 하한이 보장됩니다.

> ⚠️ 동작하려면 PC에 **itda-hyve**(0.10.1 이상)가 설치돼 있어야 합니다. itda-hyve 창의 **에이전트** 탭에서 차례로
>
> 1. **codex 설치** — itda-hyve 가 검증한 codex 를 내려받아 설치합니다(지금은 Apple Silicon Mac). 따로 설치해 둔 codex 는 쓰지 않습니다.
> 2. **계정 추가** — codex 계정을 하나 만듭니다. 처음 추가했다면 Claude Desktop 을 다시 시작합니다.
> 3. **로그인** — 브라우저가 열리면 ChatGPT 계정으로 로그인합니다. 터미널은 필요 없습니다.
>
> 별도 API 키는 필요 없습니다. 이미지는 사용자의 ChatGPT 구독 사용량으로 만듭니다.
>
> 로그인이 안 돼 있으면 Claude가 만들기 전에 알아채고 "에이전트 탭에서 로그인해 주세요"라고 안내합니다. 로그인을 마쳤다고 말하면 이어서 만듭니다.

---

## 무엇을 할 수 있나요?

| 케이스 | 이렇게 실행하세요 |
|------|-----------------|
| 블로그·문서 히어로/삽화 | `/imagegen 이 글에 어울리는 대표 이미지 만들어줘` |
| 발표·슬라이드 비주얼 | `/imagegen 발표자료에 넣을 배경 이미지 만들어줘` |
| 아이콘·로고·UI 시안 | `/imagegen 이런 의미의 앱 아이콘 시안 몇 개 만들어줘` |
| 캐릭터·일러스트 | `/imagegen 마스코트 캐릭터 만들어줘` |
| 쇼츠/유튜브 영상 삽화 | `/imagegen 쇼츠용 세로 장면 이미지 만들어줘` |
| 상품화 피규어 | `/imagegen 이 캐릭터를 피규어 사진으로 만들어줘` |
| 실사 인물 | `/imagegen 실사 느낌 프로필 사진 만들어줘` |
| 제품 카탈로그 | `/imagegen 이 제품 화이트 배경 상품샷 만들어줘` |
| 포스터 | `/imagegen 이 주제로 포스터 만들어줘` |

여러 장이 필요하면 "5장 만들어줘"처럼 장수를 말하면 됩니다. 3장까지 동시에 만들고, 나머지는 차례를 기다렸다가 이어서 만듭니다(4장 이상이면 Claude가 장수를 먼저 확인합니다).

## 자주 쓰는 시나리오

### 블로그 대표 이미지 만들기

```
/imagegen AI 에이전트가 사무 업무를 자동화하는 내용의 블로그 글 대표 이미지 만들어줘
```

Claude가 실사 사진풍으로 만들고, 제목을 얹을 여백도 한쪽에 비워 둡니다. 일러스트풍을 원하면 "일러스트로 만들어줘"라고 하면 됩니다.

### 쇼츠용 세로 이미지 만들기

```
/imagegen 주식이 오르는 걸 보고 기뻐하는 장면, 쇼츠용 세로로 만들어줘
```

세로(1024×1536, 2:3)로 만들고, 위·아래는 자막 얹을 공간을 비워 둡니다. 9:16 쇼츠 화면에는 양옆을 조금 잘라 맞춥니다. 한국 인물이 필요하면 "한국인 여성"처럼 말해 주세요 — 말하지 않으면 서양인으로 나올 수 있습니다.

### 포스터 만들기 (스타일은 알아서 추천)

```
/imagegen 바다 플라스틱 줄이자는 캠페인 포스터 만들어줘
```

스타일을 말하지 않아도 Claude가 내용을 보고 어울리는 스타일을 골라 제안합니다. 제목 글자도 이미지에 직접 넣을 수 있습니다(영문·한글 모두). 정확한 긴 문구나 특정 폰트가 필요하면 글자 자리를 비워 두고 따로 얹는 방식을 권합니다.

### 제품 사진 만들기

```
/imagegen 매트 블랙 텀블러를 화이트 배경 상품샷으로 만들어줘
```

쇼핑몰 상세페이지에 바로 쓸 만한 팩샷을 만듭니다.

### 여러 장 만들기

```
/imagegen 이 캐릭터로 표정만 다른 이미지 5장 만들어줘
```

3장씩 동시에 만들고, 다 되면 저장 폴더의 파일 목록을 알려 줍니다.

## 안 될 때

- **"codex 를 설치해 주세요" 안내가 나옴** → itda-hyve 창의 **에이전트** 탭에서 **codex 설치**를 누르세요. 진행률이 끝나면 "설치됨" 으로 바뀝니다. 컴퓨터에 따로 설치해 둔 codex 가 있어도 itda-hyve 는 그것을 쓰지 않습니다. 단 **Intel Mac 은 아직 지원하지 않습니다**(지금은 Apple Silicon Mac 만) — Intel Mac 이면 설치 버튼이 실패합니다. 그렇다고 Claude 에게 말씀해 주시면 설치를 다시 권하지 않습니다.
- **"codex 로그인이 필요합니다" 안내가 나옴** → itda-hyve 창의 **에이전트** 탭에서 **로그인**을 누르세요. 브라우저가 열리면 ChatGPT 로 로그인합니다(터미널은 열리지 않습니다). itda-hyve 가 잠시 뒤 저절로 확인합니다(표시가 안 바뀌면 **상태 확인**). 그다음 Claude에게 "로그인했어"라고 말하면 이어서 만듭니다.
- **"에이전트 계정이 없습니다" 안내가 나옴** → itda-hyve 창의 **에이전트** 탭에서 codex 를 설치하고 계정을 추가하세요. 처음 추가했다면 Claude Desktop 을 다시 시작해야 합니다.
- **"itda-hyve 를 업데이트해 주세요" 안내가 나옴** → itda-hyve 가 옛 판이거나, codex 가 itda-hyve 의 설정을 받아들이지 못했습니다. 최신판으로 업데이트하세요. 다시 시도해도 같은 결과라 Claude 가 되풀이하지 않습니다.
- **만들기 전에 "진행할까요?" 확인을 물음** → 참조 이미지를 보내거나 codex 판이 바뀌었을 때 붙는 안전 확인입니다. 내용을 보고 진행 여부를 답하면 됩니다.
- **이미지에 글자가 깨져 나옴** → 긴 문구·정확한 브랜드명은 글자 자리를 비우고 따로 얹는 방식을 쓰세요("글자 없이 만들고 자리만 비워줘").
- **정사각형인데 크기가 1024가 아님** → 비율은 맞으나 픽셀이 다를 수 있습니다. 정확한 크기가 필요하면 리사이즈를 요청하세요.
- **품질이 아쉬움** → 어느 부분이 아쉬운지 말해 주면 그 피드백을 반영해 다시 만듭니다.

## 알아두세요

- 생성 품질은 케이스 카드(`cases/`)에 **실측 기록**으로 쌓여 있어, 같은 케이스를 반복할수록 품질이 안정적입니다.
- 콘텐츠용 이미지(블로그·슬라이드·영상)는 **실사 사진풍이 기본**입니다. 일러스트·3D 렌더는 요청할 때만 씁니다.
- 정밀한 마스킹 편집·초고해상도(2K+)·멀티 레퍼런스 합성은 이 스킬의 범위가 아닙니다.
- 한 장 만드는 데 40초~1분 반쯤 걸립니다(생성 모델 응답 시간). 계정을 추가하고 처음 만들 때는 준비 확인 때문에 조금 더 걸립니다. 5장을 한꺼번에 부탁하면 3분 남짓 걸렸습니다(2026-09-28 실측).
- 만드는 중인 작업은 itda-hyve 창의 **에이전트** 탭 작업 목록에서 보고, 필요하면 거기서 취소합니다.
