# hwpx 서식 생성(report) 사용 가이드

작성하려는 보고서 내용을 말하면, **대한민국 정부 범용 한글 서식(.hwpx)** 으로 만들어 줍니다.
**Claude에게 말로 부탁하면 됩니다** — `/hwpx-report 올해 청년정책 추진현황을 정부 보고서로 만들어줘`처럼요. 터미널을 직접 다룰 필요는 없습니다.

내용은 Claude가 작성하고, 이 스킬이 제목 박스·머리글·□/❍ 개조식 본문·표가 들어간 한글 문서로 바꿔 줍니다. 다 쓴 한글 문서(읽기·요약)를 마크다운으로 바꾸는 일은 반대 방향인 hwpx 읽기(reader) 경로를 쓰세요.

---

## 빠른 시작

```
/hwpx-report 이 내용으로 정부 한글 보고서 만들어줘
/hwpx-report 분기 실적을 개조식 보고서(.hwpx)로 정리해줘
/hwpx-report 아래 표까지 넣어서 한글 보고서로 뽑아줘
```

내용만 주면 Claude가 개조식(□·❍)으로 구조를 잡고, 제목·보고일·부서가 든 한글 문서를 만들어 경로를 알려줍니다.

---

## 실사용 예시 — 회의결과 보고

실제로 아래처럼 요청하면(정리해 둔 내용을 붙여넣기),

```
/hwpx-report 아래 내용을 hwpx 문서로 생성해줘.

# 스마트팩토리 전환 TF 제4차 회의결과 (’26. 7. 25., 기획조정실)

1. 회의 개요
+ 일시·장소: '26. 7. 24.(금) 14:00, 본관 3층 대회의실
+ 참석: TF 단장(부사장) 등 12명
    - 생산본부 4, 정보전략팀 3, 품질본부 2, 재무팀 2, 외부 자문 1

2. 논의 사항
+ 1단계(음성 2공장) 센서 설치 진척 점검
    - 설비 214대 중 187대 완료(87.4%), 잔여 27대는 8월 첫째 주 완료 예정
+ MES 연동 데이터 표준안 확정
    - 태그 체계 3안 중 2안(공정-설비-센서 3계층) 채택
+ 예지보전 파일럿 대상 설비 선정
    - 프레스 라인 6대 우선 적용, 성과 검증 후 확대

3. 결정 사항
+ 예지보전 파일럿 예산 4.2억원 승인
+ 2단계(광주 공장) 착수 시점을 11월로 확정
+ 데이터 표준안은 8. 8.까지 전 부서 의견 수렴 후 시행

4. 향후 일정
+ 8. 22. 제5차 회의: 파일럿 중간 성과 보고
+ 9월 말: 1단계 완료 보고회
```

Claude가 경고 없이 변환을 마치고 이렇게 답합니다 — "정부 보고서 서식(gov-report)으로 hwpx 문서를 생성했습니다. 개조식(□/❍) 구조와 제목·보고일('26. 7. 25.)·부서(기획조정실)가 머리글에 반영됐습니다."

생성된 한글 문서는 이렇게 나옵니다:

![스마트팩토리 전환 TF 제4차 회의결과 — 생성된 한글 문서](/images/skill-guides/itda-doc/hwpx-report/meeting-result.png)

제목 박스와 우상단 머리글(보고일·부서), □/❍ 2단 개조식이 정부 보고서 관례대로 배치됩니다.

> **Tip** — 자료를 먼저 마크다운(md) 포맷으로 정리하고, 내용을 검토·수정해 확정한 뒤에 "이제 hwpx로 생성해줘"라고 요청하면 가장 깔끔하게 나옵니다.

---

## 무엇을 만들 수 있나 — 이렇게 말해 보세요

내용은 Claude가 채웁니다. 주제·핵심 사실만 주면 됩니다.

| 만들고 싶은 문서 | 이 지침을 입력하세요 |
|---|---|
| 정책·사업 추진 현황 | `/hwpx-report 청년 주거지원 정책 추진현황을 정부 보고서로 만들어줘` |
| 결과·실적 보고 | `/hwpx-report 상반기 도시재생 사업 결과를 보고서로 정리해줘` |
| 통계·수치 보고(표) | `/hwpx-report 민원 처리 통계를 표로 넣어서 한글 보고서로 만들어줘` |
| 예산 집행 점검 | `/hwpx-report 2분기 예산 집행 점검 결과를 개조식으로 작성해줘` |
| 회의 결과 정리 | `/hwpx-report 오늘 추진단 회의 결과를 정부 서식 보고서로 만들어줘` |
| 연구·검토 보고 | `/hwpx-report 친환경 소재 연구 중간보고를 한글 문서로 뽑아줘` |
| 점검·감사 결과 | `/hwpx-report 노후시설 안전점검 결과를 보고서로 정리해줘` |
| 행사·교육 계획 | `/hwpx-report 신규 임용자 교육 계획을 정부 보고서로 만들어줘` |

여러 건을 한 번에 부탁해도 됩니다 — `/hwpx-report 이 세 가지 사업을 각각 보고서로 만들어줘`.

## 표 넣기

수치·현황은 표로 부탁하면 헤더와 데이터가 그대로 칸에 맞춰 들어갑니다.

```
/hwpx-report 부서별 인력 현황을 표로 정리해서 보고서에 넣어줘
/hwpx-report 권역별 방문객 수를 표로 만들어서 같이 넣어줘
```

실제로 위 두 가지를 함께 부탁하면 이런 문서가 나옵니다 — 표 2개가 각 섹션에 배치되고, 숫자 칸은 오른쪽·분류 칸은 가운데로 정리됩니다:

![부서별 인력 및 권역별 방문객 현황 보고 — 표 2개가 든 한글 문서](/images/skill-guides/itda-doc/hwpx-report/dept-visitor-tables.png)

- 표는 **헤더(맨 윗줄) + 데이터 행**으로 구성되고, 칸마다 값이 그대로 채워집니다.
- 열 개수·행 개수는 자유입니다(2열이든 6열이든). 숫자·기호(`·`, `「」`, `%`, 소수점)도 그대로 들어갑니다.
- 표는 **글에서 쓴 위치 그대로** 들어갑니다 — 표 앞에 설명을 쓰고 뒤에 결론을 쓰면, 표가 그 사이에 놓입니다(설명이 표 위로, 결론이 표 아래로).
- **칸별 정렬**도 됩니다 — "금액 칸은 오른쪽 정렬로", "구분 칸은 가운데 정렬로"처럼 말하면 숫자는 오른쪽, 분류는 가운데로 맞춰 줍니다(머리행은 보고서 관례상 가운데로 둡니다).
- **칸 안 굵게·기울임**도 됩니다 — "상태 칸의 '완료'는 굵게", "급한 항목은 기울임으로"처럼 말하면 그 글자만 강조됩니다(머리행과 링크는 평범하게 들어갑니다).
- **칸 너비**는 내용에 맞춰 자동 조절됩니다 — 긴 설명이 들어가는 칸은 넓게, 번호·기호처럼 짧은 칸은 좁게 잡아 줍니다.

> ⚠️ 칸별 정렬·칸 안 굵게·기울임·칸 너비 자동 조절까지 지원합니다. 셀 병합은 아직 반영되지 않습니다(향후 개선). 정교한 표가 꼭 필요하면 미리 말해 주세요 — 현재 한계를 안내해 드립니다.

### 실사용 예시 — 통계 표 보고

실제로 아래처럼 표가 든 내용을 붙여넣어 요청하면(정렬 기호 `:--` 좌 / `--:` 우 / `:-:` 가운데까지 그대로),

```
/hwpx-report 아래 내용을 hwpx 문서로 생성해줘. 표는 열 정렬 그대로 살려줘.

# 2026년 상반기 민원 처리 현황 보고 ('26. 7. 10., 민원봉사과)

1. 개요
- 상반기 민원 접수 12,847건, 처리 12,310건(처리율 95.8%)
- 법정 기한 내 처리율 99.2%로 전년 동기(97.1%) 대비 개선

2. 유형별 처리 현황

| 유형 | 접수(건) | 처리(건) | 처리율 | 비고 |
|:--|--:|--:|--:|:-:|
| 도로·교통 | 4,213 | 4,102 | 97.4% | — |
| 환경·청소 | 3,105 | 2,987 | 96.2% | — |
| 건축·주택 | 2,441 | 2,275 | 93.2% | 지연 개선 중 |
| 복지·보건 | 1,872 | 1,811 | 96.7% | — |

- 자주 묻는 민원 30건을 챗봇 자동 안내로 전환(9월)
```

## 보고일·부서 넣기 (머리글)

머리글 오른쪽 위에 "'26. 6. 9., ○○과)"처럼 보고일과 부서가 들어갑니다.

```
/hwpx-report 보고일은 6월 9일, 부서는 재정기획담당관으로 해줘
```

- **함께 말해 주는 것을 권장**합니다. 보고일을 안 주면 만든 날짜로 자동으로 채우고, 부서를 안 주면 머리글에 "부서명"이라는 빈 자리표시가 남습니다 — 이때는 안내해 드립니다.

---

## 잘 나오게 하는 팁

- **개조식이 기본**입니다 — 한 항목당 한 줄(□), 그 아래 세부는 한 단계 들여쓰기(❍)로 정리됩니다. "개조식으로", "핵심만 짧게"라고 하면 더 깔끔합니다.
- **번호 항목(1. 2. 3.)** 은 `##` 섹션 안에서는 □ 항목으로 들어갑니다. `#`/`##` 제목이 전혀 없는 순수 번호 문서에서만 보고서의 큰 절 제목으로 처리됩니다.
- **소제목이 너무 깊으면**(3단계 이상) 한 단계로 정리되고, 그 사실을 알려줍니다.
- 길게 쓴 문단도 자동으로 □ 항목으로 정리됩니다.

---

## 결과 받기

- 만들어진 한글 문서(`.hwpx`)의 **저장 위치를 알려드립니다.** 더블클릭하면 한글에서 열립니다.
- 다시 고치고 싶으면 `/hwpx-report 두 번째 항목 표현 바꿔서 다시 만들어줘`처럼 말하면 됩니다.
