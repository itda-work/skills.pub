## 추진 배경
- 직원들의 민원 처리 시간 단축 요구가 지속적으로 제기되고 있음
  - 정보화담당관이 2026년 상반기 직원 설문조사를 실시한 결과, 68%가 개선이 필요하다고 응답함

## 주요 내용
- (추진절차) 희망부서 접수, 심사, 시행부서 확정의 3단계로 추진함

< 스마트 행정 도입 세부 추진절차 >

| 단계 | 내용 | 일정 |
| :-: | :-- | :-: |
| 접수 | 부서별 신청서 접수 | 9월 |
| 심사 | 서면·대면 심사 | 10월 |
| 확정 | 시행부서 확정·공개 | 11월 |

- (세부일정) 세부 일정은 아래 표와 같음

| 기간 | 활동 |
| :-: | :-- |
| 9월 1주 | 신청 공고 |
| 9월 2주 | 접수 마감 |

이 계획은 담당자 협의회 결과에 따라 일부 조정될 수 있으며, 조정 내용은 별도로 보고함.

## 향후 계획
- 도입 성과가 우수한 부서에 예산이 확대될 수 있도록 배분체계 개편안을 마련할 예정임
