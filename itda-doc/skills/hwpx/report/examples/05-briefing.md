## 추진 배경
- 민원 처리 시간 단축 요구가 전년 대비 지속 증가
  - 전자민원 접수 비중 68%, 처리 평균 4.2일
    - 특히 건축·환경 분야가 평균 6일 이상 소요
      - 담당자 1인당 처리 건수 월 210건
- 타 지자체 스마트 행정 도입 사례 확산

## 현황 및 문제점
- 부서별 시스템이 분절되어 데이터 재입력 반복
  - 동일 민원인 정보를 평균 3회 입력
- 도입 현황은 아래 표와 같음

| 부서 | 도입 시스템 | 도입률 | 비고 |
| :-- | :-: | --: | :-- |
| 민원과 | 전자민원 | 92% | 완료 |
| 건축과 | 인허가 | 61% | 진행 |
| 환경과 | 배출관리 | 45% | 착수 |

## 개선 방안
- 통합 데이터 허브 구축으로 재입력 제거
  - 2027년 상반기까지 1단계 연계
    - 민원·건축·환경 3개 시스템 우선
- 담당자 역량 교육 분기별 시행

## 향후 계획
- 2026년 10월 협의회 개최 후 세부 일정 확정
