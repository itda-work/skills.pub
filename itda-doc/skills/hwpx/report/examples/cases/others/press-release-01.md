# 스킬잇다시, 전국 최초 '24시간 AI 민원 상담' 서비스 개시

## 1. 서비스 개요

- 스킬잇다시는 9월 15일부터 24시간 AI 민원 상담 서비스를 전국 최초로 개시한다고 밝혔다
  - 야간·휴일에도 전화·카카오톡·홈페이지 3개 창구에서 상담 가능
- 시는 지난 6개월간 시범운영을 거쳐 응답 정확도 94%를 확보했다고 설명했다

## 2. 주요 내용

- 상담 가능 분야는 주민등록·세무·환경·건축 등 42개 업무
  - 복잡한 사안은 다음 근무일 담당자 통화로 자동 연계
- 시범운영 기간 중 야간 상담 요청은 전체의 31%를 차지했다

- 시범운영 6개월 실적과 1년 목표는 다음과 같다
  - 상담 처리 건수 41,280건 → 120,000건
  - 야간 상담 비중 31% → 35%
  - 응답 정확도 94% → 97%

## 3. 기대 효과

- 민원 대기시간이 평균 12분에서 40초로 단축될 것으로 기대된다
- 담당 공무원은 단순 반복 문의 대신 복합 민원에 집중할 수 있게 된다

## 4. 관계자 발언

- 김서준 스킬잇다시장은 "시민이 시간에 구애받지 않고 행정 서비스를 이용할 수 있게 됐다"며 "연내 다국어 상담까지 확대하겠다"고 말했다
