## 검토 배경
- 현행 요금체계는 2019년에 정해진 이후 7년간 조정되지 않아 운영비 상승분을 반영하지 못하고 있음
  - 2026년 관리 위탁비는 2019년 대비 38.4% 증가하였으나 요금 수입은 6.2% 증가에 그침
  - 2025년 회계연도 기준 공영주차장 21개소의 운영수지는 4억 7천만 원 적자임
- 도심 8개소는 회전율이 낮아 장시간 점유가 문제로 지적되고 있음
  - 평일 평균 주차시간이 3시간 42분으로, 유사 규모 지자체 평균(2시간 5분)보다 길음

## 검토 대안
- 세 가지 대안을 요금 인상 폭과 회전율 개선 효과 측면에서 비교함

| 구분 | 1안(현행 유지) | 2안(단일 인상) | 3안(구간 차등) |
| :-- | :-- | :-- | :-- |
| 기본 30분 | 500원 | 700원 | 700원 |
| 추가 10분 | 200원 | 300원 | 1시간 초과 400원 |
| 예상 수입 증가 | 0원 | 연 5.2억 원 | 연 6.1억 원 |
| 회전율 개선 | 없음 | 12% 개선 | 27% 개선 |
| 이용자 부담 | 없음 | 전 구간 증가 | 단시간 이용자 부담 완화 |
| 조례 개정 | 불요 | 필요 | 필요 |

- 3안은 단시간 이용자의 부담 증가가 상대적으로 작으면서 회전율 개선 효과가 가장 큼

| 주차시간 | 현행 | 3안 | 증감 |
| :-: | --: | --: | --: |
| 30분 | 500 | 700 | +200 |
| 1시간 | 1,100 | 1,500 | +400 |
| 2시간 | 2,300 | 3,900 | +1,600 |
| 4시간 | 4,700 | 8,700 | +4,000 |

## 검토 의견
- 3안이 재정 건전성과 회전율 개선을 동시에 달성할 수 있어 가장 적합하다고 판단됨
- 다만 인근 상인회가 장시간 이용 고객 이탈을 우려하고 있어 사전 협의가 필요함
  - 8월 26일 상인회 간담회에서 유예기간 6개월을 요청받음

## 건의 사항
- 3안을 기준으로 조례 개정을 추진하되, 시행일을 2027년 4월 1일로 하여 6개월의 유예기간을 두는 방안을 건의함
- 상인회 협의를 위해 9월 중 실무 협의체를 구성하고, 10월 말까지 합의안을 마련하도록 건의함
