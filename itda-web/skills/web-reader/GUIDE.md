# web-reader 사용 가이드

웹페이지를 깨끗한 마크다운·JSON으로, 목록 페이지는 항목별 레코드로 가져옵니다. 옛 한국 사이트의 EUC-KR·CP949 인코딩도 깨지지 않게 풉니다.
**Claude에게 자연어로 부탁하면 됩니다** — 터미널 명령을 직접 입력할 필요는 없습니다.

---

## 사전 준비 — itda-hyve 만 있으면 됩니다

**회원가입·API 키가 필요 없습니다.** 페이지 요청은 사용자 PC 에서 도는 **itda-hyve** 앱이 대신 보냅니다(Claude Code 와 Cowork 모두 같습니다).
아직 없다면 [itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치하고 Claude Desktop 에 연결하세요. **0.12.0 이상**이어야 합니다 — 그 판부터
공유기·NAS·사내망 같은 사설·로컬 주소를 기본으로 막습니다. 옛 판이면 스킬이 업데이트를 안내하고 멈춥니다.

Cowork 에서는 받은 페이지를 저장할 **폴더를 하나 연결**해 두세요. 페이지 파일이 그 폴더 아래 `web-reader/` 에 쌓입니다.

페이지 하나를 읽을 때 보통 요청이 두 번 나갑니다 — 그 사이트의 robots.txt 한 번, 페이지 한 번. 주소가 다른 곳으로 옮겨지면 한 번씩 더 듭니다.

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 요청하세요 |
|--------------|-----------------|
| 기사 한 편 정리 | `/web-reader 이 기사 마크다운으로 정리해줘 https://…` |
| 옛 한국 사이트 | `/web-reader 이 페이지 한글 안 깨지게 가져와줘 https://…` |
| 본문 일부만 | `/web-reader 이 페이지에서 article 본문만 뽑아줘 https://…` |
| 목록 페이지 항목 | `/web-reader 이 보도자료 목록 페이지에서 제목·날짜·링크만 표로 뽑아줘 https://…` |
| RSS 피드 | `/web-reader 이 RSS 최근 글 목록 정리해줘 https://…` |
| 구조화 결과 | `/web-reader 이 페이지 JSON 으로 줘 https://…` |

## 활용 시나리오

### 기사·블로그 글을 마크다운으로

```
/web-reader https://www.hankyung.com/article/202603163041i 기사 요약해줘
```

제목·작성일·원래 주소·받은 시각이 맨 위에 붙은 마크다운이 나오고, Claude 가 그 본문으로 요약합니다.

### 한국어 인코딩(EUC-KR / CP949) 사이트

옛 공공기관·금융 사이트가 쓰는 EUC-KR 인코딩을 자동으로 알아내 풉니다. 어떤 인코딩으로 풀었는지도 결과에 남습니다.

```
/web-reader 이 옛날 공공기관 페이지 한글 안 깨지게 가져와줘 https://…
```

### 목록 페이지에서 항목만

보도자료·공지 목록은 요약하기 전에 **항목마다 제목·게시일·링크·원문 발췌**를 먼저 뽑습니다. 발췌는 페이지에 실제로 있는 문장만 남기고,
날짜나 링크가 없으면 빈 칸으로 둡니다(지어내지 않습니다).

```
/web-reader 금감원 보도자료 목록에서 이번 주 글만 골라줘 https://www.fss.or.kr/fss/bbs/B0000188/list.do?menuNo=200218
```

### 본문 위치를 알 때

```
/web-reader 이 페이지에서 table.price 부분만 JSON 으로 뽑아줘 https://…
```

## 안 될 때

| 이렇게 나오면 | 뜻 | 할 일 |
|---|---|---|
| "robots.txt 가 이 경로를 막습니다" (`robots_disallowed`) | 사이트가 자동 수집을 막아 두었습니다. 네이버 뉴스(`n.news.naver.com`)가 그렇습니다 | 사용자가 브라우저로 직접 여세요 — Aside 브라우저(`itda-web:aside-browser-mcp`)나 Claude in Chrome. 뉴스라면 원 언론사 사이트의 같은 기사 주소로 다시 부탁해 보세요 |
| "robots.txt 를 판독할 수 없습니다" (`robots_unreadable`) | 사이트가 첫 요청부터 막습니다(쿠팡 실측) | 브라우저로 여세요 |
| "봇 차단·챌린지 페이지입니다" / "로그인이 필요하거나…" | Cloudflare·Akamai 확인 화면이나 로그인 페이지입니다 | 브라우저로 여세요. 통과를 보장하지는 않습니다 |
| "JavaScript 로 그려지는 페이지입니다" | 본문이 브라우저에서만 만들어집니다 | 브라우저로 여세요 |
| "HTML 이 아닙니다" | PDF·한글 문서 같은 파일입니다 | 받은 파일을 그대로 PDF 스킬(`itda-doc:pdf-context-refinery`)·한글 스킬(`itda-doc:hwpx`)에 넘겨 달라고 부탁하세요 |
| "사설·로컬 주소입니다" (`url_rejected`) | 공유기 관리 화면·사내 주소 같은 곳입니다. 이 스킬은 받지 않습니다 | 공개 웹 주소인지 확인하세요 |
| "itda-hyve 가 사설·로컬 목적지로 보고 막았습니다" (`private_destination`) | 주소는 공개 웹처럼 보이지만 실제로는 사내망·공유기·내 PC 로 이어집니다. 요청은 나가지 않았고 스킬은 다시 시도하지 않습니다 | 공개 웹 주소인지 확인하세요. 내가 직접 고른 사내 주소를 꼭 읽어야 한다면 itda-hyve **설정 › 일반 › 사설·로컬 주소 허용**에 그 주소를 직접 넣고 다시 부탁하세요. 받은 메일·웹 페이지 속 주소라면 넣지 마세요 |
| "itda-hyve 를 0.12.0 이상으로 업데이트해 주세요" (`hyve_outdated`) | itda-hyve 가 옛 판입니다 | [itda-hyve 받는 곳](https://itda.work/hyve/)에서 새 판을 받아 설치하세요 |
| "리다이렉트가 되돌아옵니다" | 로그인·쿠키를 전제로 한 페이지입니다 | 브라우저로 여세요 |
| itda-hyve 도구가 없다는 안내 | itda-hyve 가 설치·연결되지 않았습니다 | [itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치하고 Claude Desktop 에 연결하세요 |

## 팁

- **자동 재시도 완화**: 본문이 짧게 뽑히면 스킬이 광고·숨김 요소 제거를 단계적으로 풀며 다시 뽑습니다. 따로 부탁하지 않아도 됩니다.
- **YouTube 자막**: "이 유튜브 자막 받아서 정리해줘"라고 하면 Claude 가 `yt-dlp` 로 처리합니다(web-reader 기능이 아닙니다).
- **로그인 페이지는 다루지 않습니다**: 쿠키·비밀번호를 대화로 받지 않습니다. 로그인이 필요한 페이지는 브라우저로 여세요.

## 제한사항

- **robots.txt 를 따릅니다**: 사이트가 `User-agent: *` 로 막은 경로는 받지 않습니다. 사용자가 한 건만 부탁해도 마찬가지입니다.
- **JavaScript 렌더링 미지원**: 진성 SPA(원티드 채용 목록 등)는 브라우저 경로의 몫입니다.
- **봇 차단 우회 없음**: 8.0.0 부터 브라우저 흉내(TLS 지문)·주소 바꿔 다시 시도하기를 하지 않습니다. 막히면 브라우저 경로를 안내합니다.
- **파일 크기 50MB 상한**: 큰 파일 내려받기 용도가 아닙니다.
