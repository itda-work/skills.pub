# web-reader 사용 가이드

웹페이지 본문을 출처가 붙은 깨끗한 마크다운으로, 목록 페이지는 항목별 레코드로 가져옵니다. 옛 한국 사이트의 EUC-KR·CP949 인코딩도 깨지지 않게 풉니다.
**Claude에게 자연어로 부탁하면 됩니다** — 터미널 명령을 직접 입력할 필요는 없습니다.

---

## 사전 준비 — itda-hyve 만 있으면 됩니다

**회원가입·API 키가 필요 없습니다.** 페이지는 사용자 PC 에서 도는 **itda-hyve** 앱이 받아 본문만 골라 줍니다(Claude Code 와 Cowork 모두 같습니다).
아직 없다면 [itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치하고 Claude Desktop 에 연결하세요. **웹 페이지 읽기(`web_read`)가 들어간 판**이어야 합니다 —
옛 판이면 스킬이 업데이트를 안내하고 멈춥니다. 목록 항목 추출은 그보다 새 판이 필요할 수 있습니다(스킬이 알려 줍니다).

긴 글이나 여러 페이지를 파일로 남기고 싶으면 Cowork 에서 저장할 **폴더를 하나 연결**해 두세요.

페이지 하나를 읽을 때 요청은 한 번 나갑니다(주소가 다른 곳으로 옮겨지면 itda-hyve 가 따라갑니다).

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 요청하세요 |
|--------------|-----------------|
| 기사 한 편 정리 | `/web-reader 이 기사 마크다운으로 정리해줘 https://…` |
| 옛 한국 사이트 | `/web-reader 이 페이지 한글 안 깨지게 가져와줘 https://…` |
| 본문 일부만 | `/web-reader 이 페이지에서 article 본문만 뽑아줘 https://…` |
| 목록 페이지 항목 | `/web-reader 이 보도자료 목록 페이지에서 제목·날짜·링크만 표로 뽑아줘 https://…` |
| RSS 피드 | `/web-reader 이 RSS 최근 글 목록 정리해줘 https://…` |
| 파일로 저장 | `/web-reader 이 글 연결한 폴더에 마크다운으로 저장해줘 https://…` |

## 활용 시나리오

### 기사·블로그 글을 마크다운으로

```
/web-reader https://www.yna.co.kr/view/AKR20261010045600099 기사 요약해줘
```

제목·작성자·게시일·원래 주소·받은 시각이 함께 나오고, Claude 가 그 본문으로 요약합니다.

### 한국어 인코딩(EUC-KR / CP949) 사이트

옛 공공기관·금융 사이트가 쓰는 EUC-KR 인코딩을 자동으로 알아내 풉니다. 어떤 인코딩이었는지도 결과에 남습니다.

### 목록 페이지에서 항목만

보도자료·공지 목록은 요약하기 전에 **항목마다 제목·게시일·링크·원문 발췌**를 먼저 뽑습니다. 발췌는 페이지에 실제로 있는 문장만 남기고,
날짜나 링크가 없으면 빈 칸으로 둡니다(지어내지 않습니다). 이 기능은 itda-hyve 새 판에서 됩니다 — 아직 없는 판이면 Claude 가 업데이트를 안내합니다.

```
/web-reader 금감원 보도자료 목록에서 이번 주 글만 골라줘 https://www.fss.or.kr/fss/bbs/B0000188/list.do?menuNo=200218
```

### 네이버 블로그 글

데스크톱 주소(`blog.naver.com/아이디/글번호`)는 본문이 안쪽 프레임에 있어 한 번에 안 나옵니다. Claude 가 itda-hyve 가 알려 준 실제 본문 주소로
한 번 더 읽습니다.

## 안 될 때

| 이렇게 나오면 | 뜻 | 할 일 |
|---|---|---|
| "봇 차단·로그인 화면입니다" (`blocked`) | Cloudflare·Akamai 확인 화면이나 로그인 페이지입니다 | 사용자가 브라우저로 직접 여세요 — Aside 브라우저(`itda-web:aside-browser-mcp`)나 Claude in Chrome. 통과를 보장하지는 않습니다 |
| "스크립트가 그리는 페이지입니다" (`js_rendered`) | 본문이 브라우저에서만 만들어집니다 | 브라우저로 여세요 |
| "본문을 찾지 못했습니다" (`extract_failed`) | 다른 주소로 바로 넘어가는 페이지거나 본문이 없습니다 | Claude 가 안내된 주소로 한 번 더 읽습니다. 그래도 안 되면 브라우저로 여세요 |
| "HTML 이 아닙니다" (`not_html`) | PDF·한글 문서 같은 파일입니다 | 파일을 내려받아 PDF 스킬(`itda-doc:pdf-context-refinery`)·한글 스킬(`itda-doc:hwpx`)에 넘겨 달라고 부탁하세요 |
| "itda-hyve 가 사설·로컬 목적지로 보고 막았습니다" (`private_destination`) | 주소가 실제로는 사내망·공유기·내 PC 로 이어집니다. 요청은 나가지 않았습니다 | 공개 웹 주소인지 확인하세요. 내가 직접 고른 사내 주소를 꼭 읽어야 한다면 itda-hyve **설정 › 일반 › 사설·로컬 주소 허용**에 그 주소를 직접 넣고 다시 부탁하세요. 받은 메일·웹 페이지 속 주소라면 넣지 마세요 |
| "itda-hyve 를 최신 판으로 업데이트해 주세요" | itda-hyve 가 웹 페이지 읽기(`web_read`)가 없는 옛 판입니다 | [itda-hyve 받는 곳](https://itda.work/hyve/)에서 새 판을 받아 설치하세요 |
| itda-hyve 도구가 없다는 안내 | itda-hyve 가 설치·연결되지 않았습니다 | [itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치하고 Claude Desktop 에 연결하세요 |

## 팁

- **긴 글은 파일로**: 본문이 2만 자를 넘으면 앞부분만 오고 잘렸다고 알려 줍니다. "파일로 저장해서 읽어줘" 라고 하면 전체를 받습니다.
- **YouTube 자막**: "이 유튜브 자막 받아서 정리해줘"라고 하면 Claude 가 `yt-dlp` 로 처리합니다(web-reader 기능이 아닙니다).
- **로그인 페이지는 다루지 않습니다**: 쿠키·비밀번호를 대화로 받지 않습니다. 로그인이 필요한 페이지는 브라우저로 여세요.

## 제한사항

- **robots.txt 를 확인하지 않습니다**: 9.0.0 부터 itda-hyve 가 받으며 robots.txt 는 보지 않습니다. 요청은 내 PC 에서 나가 그 사이트 기록에 남으니,
  한 사이트를 많이 읽을 때는 그 사이트의 이용 조건을 직접 확인하세요.
- **JavaScript 렌더링 미지원**: 진성 SPA(원티드 채용 목록 등)는 브라우저 경로의 몫입니다.
- **봇 차단 우회 없음**: 막히면 브라우저 경로를 안내합니다.
- **페이지 크기 10MB 상한**: 큰 파일 내려받기 용도가 아닙니다.
