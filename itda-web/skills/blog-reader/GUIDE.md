---
title: "blog-reader 활용 가이드"
---

네이버 블로그의 글 목록·본문·댓글·블로그 내 검색, 그리고 네이버 블로그 전체 키워드 검색을 로그인 없이 읽는 스킬입니다. **아래처럼 `/blog-reader` 뒤에 지침을 붙여 입력하면 됩니다** — 자연어로 말해도 동작합니다. 터미널 명령을 직접 입력할 필요는 없습니다.

---

## 빠른 시작

아래 예시는 그대로 입력하면 **추가 질문 없이 결과까지** 나옵니다. 어느 블로그인지
특정해야 하는 기능은 블로그 ID(주소의 `blog.naver.com/` 뒤 부분) 또는 포스트 URL을
함께 말해 주세요.

```
/blog-reader 네이버 블로그에서 '클로드 코워크' 관련 최신 글 3개 찾아줘
```

```
/blog-reader astroyuji 블로그 최근 7일 글 보여줘
```

```
/blog-reader https://blog.naver.com/astroyuji/224284984821 본문이랑 댓글 같이 보여줘
```

블로그를 지정하지 않고 "네이버 블로그 글 가져와줘"처럼 말하면 어느 블로그인지
되묻습니다 — 대화 중 이미 특정 블로그·글을 다루고 있었다면 "이 블로그", "이 글"로
이어 말해도 됩니다.

---

## 활용 시나리오

### 최근 글 목록 조회

특정 블로그의 최근 포스트를 날짜 내림차순으로 가져옵니다.

```
/blog-reader 아스트로유지 블로그 최근 7일 포스팅 가져와줘
```

최대 몇 개까지 가져올지, 특정 카테고리만 볼지도 함께 말할 수 있습니다.

```
/blog-reader 아스트로유지 블로그 여행 카테고리 글 10개만 보여줘
```

### 본문 + 댓글 한 번에 보기

URL 하나로 본문과 댓글 트리를 동시에 가져오고 싶을 때 유용합니다.

```
/blog-reader https://blog.naver.com/astroyuji/224284984821 본문이랑 댓글 같이 보여줘
```

대화 중 이미 특정 글을 다루고 있다면 URL 없이 이어 말해도 됩니다.

```
/blog-reader 이 블로그 포스팅 본문이랑 댓글 같이 보여줘
```

본문만 보고 싶으면 "본문만", 댓글만 보고 싶으면 "댓글만"이라고 말하세요.

### 블로그 내 키워드 검색

특정 블로그 안에서 키워드로 포스트를 찾습니다.

```
/blog-reader astroyuji 블로그에서 '인공지능' 검색해줘
```

```
/blog-reader 아스트로유지 블로그에서 파이썬 관련 글 5개만 찾아줘
```

### 네이버 블로그 전체에서 찾아 바로 읽기

특정 블로그가 아니라 **네이버 블로그 전체**에서 키워드로 글을 찾을 수 있습니다.
API 키나 로그인 없이 동작하며, 먼저 제목·요약·링크 목록을 보여주고 원하는 글을
골라 본문·댓글까지 이어서 읽어줍니다.

```
/blog-reader 네이버 블로그에서 '클로드 코워크' 관련 글 찾아줘
```

```
/blog-reader 네이버 블로그에서 세무사랑 관련 최신 글 5개 찾아서 첫 번째 글 읽어줘
```

관련도순이 기본이고, "최신 글"이라고 말하면 최신순으로 정렬합니다.
뉴스·웹문서까지 포함한 범용 검색이 필요하면 `web-search` 스킬을 사용하세요.

### 특정 작성자 댓글 모으기

```
/blog-reader 이 글에 홍길동이 단 댓글만 모아줘
```

## 팁

- **이미지 URL 제거**: 이미지가 많은 블로그(여행·맛집·리뷰 등)를 읽을 때 "이미지는 빼고", "본문 텍스트만"처럼 말하면 이미지 URL이 제거되어 응답이 훨씬 가벼워집니다. 실측으로 이미지 26장 여행 포스트가 18,723 B → 6,522 B(-65%)로 줄었습니다. 단순히 "요약해줘" 같은 말에는 적용되지 않습니다.
- **자가차단 방지**: 동일 블로그에 대한 반복 조회는 줄이고, 필요한 정보를 한 번에 가져온 뒤 사용하세요. 과도한 연속 요청은 네이버 봇 감지에 걸릴 수 있습니다.
- **댓글 깊이 제한**: 댓글이 매우 많을 때는 "댓글 2단계까지만", "최대 50개만"처럼 범위를 말해주면 됩니다.

## 제한 사항

| 증상 | 원인 / 해결 |
|------|-------------|
| "차단됐다"는 안내 (`4`) | 네이버 봇 차단(403·429). 잠시 후 다시 시도하세요. anti-bot 우회는 하지 않습니다 |
| "결과가 없다"는 안내 (`3`) | 해당 날짜·카테고리에 게시물이 없거나 검색어에 맞는 글이 없음 |
| "비공개 블로그"라는 안내 (`6`) | 로그인이 필요한 비공개 포스트 — 지원하지 않습니다 |
| "지원하지 않는 플랫폼"이라는 안내 (`5`) | 네이버 외 도메인(Tistory·Velog·Brunch)은 아직 미지원입니다 |
| 이미지 위치가 `[이미지]`로만 표시됨 | "이미지는 빼고" 요청 시 URL은 제거되지만 이미지 위치와 설명은 남습니다 — 정상 동작입니다 |

- **조회 전용**: 포스트 작성·수정·댓글 달기는 지원하지 않습니다.
- **네이버 블로그만**: Tistory·Velog·Brunch는 향후 별도 지원 예정입니다.
- **캐시 없음**: 매번 신선하게 조회합니다.
