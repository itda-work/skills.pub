## 1단계 — 추출 프롬프트 (복사해서 붙여넣기)

```
아래 정보원 목록의 각 URL 을 읽고, 최근 [기간: 예 7일] 안의 항목을 **표**로 추출하세요.
요약하지 말고 옮겨 적기만 하세요.

열: 정보원 | 제목 | 게시일 | 출처 URL | 원문 발췌(1~3문장, 원문 그대로) | 수집 시각
규칙:
1. 발췌는 원문 그대로 — 요약·의역 금지. 내가 URL 을 열어 그 문장을 찾을 수 있어야 합니다.
2. 항목이 없는 정보원도 "0건" 으로 한 줄 남기세요 (읽지 못한 것과 없는 것을 구분하기 위해).
3. 읽지 못한 정보원은 "읽기 실패: [이유]" 로 표시하세요. 검색 결과로 대신 채우지 마세요.
4. 키워드 필터: [키워드: 예 현대해상, 손해보험, 실손]

정보원:
{{SOURCES}}
```

**확인(2~3분)**: 표에서 2~3줄을 골라 URL 을 열고 발췌가 실제로 있는지 봅니다. 전부 확인할 필요는 없습니다.

## 2단계 — 가공 프롬프트 (확인된 표만 붙여넣기)

```
아래 표(1단계 추출 결과)만 근거로 [형식: 예 경영진 브리핑 / 상품팀 메모] 를 작성하세요.
표에 없는 내용은 쓰지 말고, 각 항목 끝에 출처 URL 을 다세요.
선별 기준: [예: 우리 회사·경쟁사 직접 언급 우선, 규제 변화 다음, 중복 보도는 1건으로]

[여기에 표 붙여넣기]
```

## 반복(주간)

프로젝트 지침에 1단계 프롬프트를 저장해 두고 매주 실행 → 지난주 표와 이번 주 표를 나란히 두면 "새로 나온 것" 만 보입니다.
