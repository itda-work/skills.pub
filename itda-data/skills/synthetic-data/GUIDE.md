# synthetic-data 활용 가이드

> 실제 환자·직원 데이터는 한 건도 필요 없습니다. **우리 문서의 칸 이름과 규칙**만 알려 주면 같은 구조의 가짜 데이터를 만들어 드립니다.

**코드 몰라도 됩니다.** 평소 말로 `/synthetic-data 우리 입퇴원 대장 구조로 가상 데이터 50건 만들어줘` 처럼 적으면 됩니다. 터미널 명령을 직접 칠 필요는 없습니다.

이 가이드의 예시 데이터는 전부 **스킬을 실제로 돌려 나온 결과**입니다(요양병원·노인장기요양 8종 프리셋, 2026-09-06 실측). 표가 길어 대부분 접어 두었습니다 — **▸ 삼각형이나 제목을 누르면 펼쳐집니다.**

---

## 1. 무엇을 만드나 — 한눈에

| 도메인 | 문서 4종 |
|---|---|
| **요양병원** `nursing-hospital` | 입퇴원 대장 · 3교대 근무표 · 환자분류군 집계 · 상담 기록지 |
| **노인장기요양** `longterm-care` | 수급자 명단 · 급여제공기록지 · 요양보호사 근무표 · 프로그램 참여 일지 |

프리셋은 **출발점**입니다. 우리 서식과 다르면 "이 칸을 빼고 저 칸을 더한다"로 고치면 됩니다(§4).

## 2. 시작하면 무엇을 묻나요

1. **"이 예시는 실제 환자·직원이 아닌 것을 확인합니다."** — 예시로 주시는 2~3건도 가짜여야 합니다. 이 확인 전에는 만들지 않습니다.
2. 어떤 문서인가요 — 위 8종에서 가장 가까운 것을 고릅니다.
3. 프리셋 항목 표를 보고 **빼는 칸 / 더하는 칸 / 이름이 다른 칸**만 말씀해 주세요.
4. 항목 간 규칙(입원일 ≤ 퇴원일, 병실 → 병동 등)이 맞는지 확인합니다.
5. 몇 건 만들지, 채울 엑셀·한글 양식이 있는지 알려 주세요.

> ⚠️ 프리셋은 해당 업무의 문서 구조를 **예측해 만든 것일 뿐 정확하지 않습니다.** 고치지 않고 그대로 만들면 산출물에 "프리셋 그대로 생성 — 본인 서식과 다를 수 있음" 이 표시됩니다.

## 3. 자주 쓰는 지시

| 하고 싶은 것 | 이렇게 말하세요 |
|---|---|
| 프리셋 그대로 빠르게 | `/synthetic-data 요양병원 입퇴원 대장 프리셋으로 30건만 만들어줘` |
| 우리 서식으로 | `/synthetic-data 우리 대장은 '연락처' 대신 '보호자 휴대폰'이고 '주소' 칸은 없어. 담당의 칸을 넣어서 50건 만들어줘` |
| 엑셀 양식에 채우기 | `/synthetic-data 이 양식.xlsx 헤더 아래에 가상 데이터 100건 채워줘` |
| 한글 양식(1건 1장) | `/synthetic-data 상담기록지.hwpx 양식으로 가상 상담 기록 3장 만들어줘` |
| 실습용 판단 기준표 | `/synthetic-data 항목별 개인정보 등급 표도 같이 뽑아줘` |

## 6. 왜 안전한가 — 값은 전부 가짜

50행을 만들어 직접 세어 본 결과입니다(seed 7):

| 항목 | 실측 |
|---|---|
| 검증식(체크섬)을 통과하는 주민번호 | **0 / 50** — 형식만 맞고 검증 자리가 틀려 실존 번호일 수 없습니다 |
| 동명이인 | 47종 이름 중 3쌍이 겹침 — 마스킹·재식별 실습의 함정 재료로 일부러 섞습니다 |
| 연락처 | 전부 `010-0000-…` — 부여될 수 없는 형식 밖 대역 |
| 주소 | `가상시 가상구 …` 가상 지명 |

- **항목별 분포만 닮았고 항목끼리의 상관관계는 없습니다.** 수식·스크립트·절차 검증용이며 **경영 판단 수치로 쓰지 마세요.**
- 실제 주민번호·휴대전화 형태가 예시나 자유 문장에 섞이면 도구가 거부합니다(형식 기반 탐지). 실명·실제 문장까지는 못 잡으니 **첫 질문에 정직하게 답하는 것이 1차 방어선**입니다.
- 원본 양식 파일은 절대 덮어쓰지 않습니다 — 산출은 항상 새 폴더에 만들어집니다.

## 8. Windows 노트북에서

강의용 Windows 노트북에서도 똑같이 됩니다. Claude 가 알아서 처리하니 신경 쓸 것은 아래뿐입니다.

- 처음 한 번은 엑셀을 채우는 데 필요한 준비물을 Claude 가 자동으로 설치합니다(관리자 권한 없이). 준비물이 없어도 표(CSV)와 리포트는 나오고 엑셀 파일만 잠시 생략됩니다.
- `C:\Users\이름\바탕 화면\가상 데이터` 처럼 **한글·공백이 든 폴더**에 만들어도 됩니다.
- 한글이 깨질까 걱정하지 않아도 됩니다 — 안내 문구·리포트가 온전한 한글로 나옵니다.
- 만들어진 엑셀은 Excel 로, 한글 파일(HWPX)은 한글로 그대로 열립니다.
