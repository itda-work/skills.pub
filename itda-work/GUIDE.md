# itda-work 시작 가이드 (처음이세요?)

코드 몰라도 됩니다. **평소 말로** 요청하면 됩니다. 스킬 이름을 외울 필요도 없습니다.

## 1. 먼저 할 일 — itda-hyve 에 계정 등록

메일·캘린더·아침 브리핑은 사용자 PC 에서 도는 **itda-hyve** 앱을 거쳐 요청합니다.
[itda-hyve 받는 곳](https://itda.work/hyve/)에서 설치한 뒤 앱의 **계정** 화면에 메일·캘린더 계정을 등록하세요.
비밀번호는 itda-hyve 에만 저장되고, 대화로 묻지 않습니다.

## 2. 이렇게 말하세요 (복붙용)

| 하고 싶은 일 | 채팅에 이렇게 |
|---|---|
| 안 읽은 메일 정리 | `/email 안 읽은 메일 중요한 것만 추려줘` |
| 메일 보내기 | `/email 김 팀장에게 내일 회의 시간 확인 메일 보내줘` |
| 오늘 일정 확인 | `/calendar 오늘 일정 뭐 있어?` |
| 일정 추가 | `/calendar 다음 주 화요일 오후 3시에 팀 회의 잡아줘` |
| 아침 브리핑 | `/morning-brief 아침 브리핑 만들어줘` |
| 환율 | `/exchange-rate 오늘 달러 환율 알려줘` |
| 날씨 | `/weather-here 지금 여기 날씨 어때?` |
| 문서 창 보고서 쓰기·고치기 | `/markdown-doc 3분기 실적 보고서를 보고서 양식으로 써줘` |
