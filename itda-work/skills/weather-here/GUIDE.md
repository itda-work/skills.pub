title: "weather-here (현재 위치 날씨) 활용 가이드"
---

## 빠른 시작

현재 대략적 위치 또는 지정한 지역의 날씨를 한국어로 빠르게 알려줍니다.
위치를 말하지 않아도 되묻지 않고 바로 답합니다.

```
/weather-here 지금 날씨 어때
```

```
/weather-here 부산 날씨 알려줘
```

```
/weather-here 수원 날씨, 자세히
```

위치를 말하지 않으면 itda-hyve 가 내 컴퓨터의 위치를 찾아 주고,
지역명(한국어 또는 주요 도시 영문)을 말하면 그 지역을 우선합니다.

## 사전 준비

인증키·회원가입·신청은 **필요 없습니다.** 대신 날씨 조회와 현재 위치 찾기는 내 PC 에서 도는 도우미 프로그램
**itda-hyve 0.10.4 이상**이 맡습니다(Cowork 작업 공간에서는 외부 사이트 접속이 막히거나 끊길 수 있기 때문입니다).

1. itda-hyve 를 설치하고 Claude Desktop 에 연결합니다 — 받는 곳 https://itda.work/hyve/ .
2. Cowork 라면 결과 파일을 둘 폴더를 연결해 두세요. 조회 한 번에 작은 파일(수 KB)이 그 폴더의 `weather-here` 아래에 저장됩니다.

itda-hyve 는 먼저 **컴퓨터의 위치 서비스**(Wi-Fi 기반, 구 단위까지)로 위치를 찾고, 안 되면 인터넷 주소로
위치를 알려 주는 서비스 여러 곳의 **다수결**로 찾습니다. 인터넷 주소 한 곳만 보면 통신사 거점(예: KT 는 성남)이
잡혀 시·도부터 틀리는 일이 흔합니다.

- macOS 에서 처음 쓰면 "itda-hyve 가 위치를 사용하려고 합니다" 창이 뜹니다. **허용**하면 구 단위까지 맞습니다.
  놓쳤다면 시스템 설정 > 개인정보 보호 및 보안 > 위치 서비스 > itda-hyve 를 켜세요.
- 날씨 데이터는 Open-Meteo(무료 공개 날씨 서비스)에서 받습니다. 한 번 물을 때마다 한 번만 조회합니다.

## 활용 시나리오

### 위치 안 말하고 바로 묻기

가장 흔한 사용법입니다. 현관 나서기 전 "비 와?" 같은 순간.

```
/weather-here 지금 날씨
```

위치를 되묻지 않고 itda-hyve 가 찾은 위치 기준으로 바로 답합니다.

### 현재 위치는 어떻게 찾았나

```
/weather-here 지금 여기 날씨 어때
```

itda-hyve 로 내 PC 의 위치를 받아 그 위치의 날씨를 알려줍니다. 위치를 어떻게 찾았는지에 따라 첫머리가 다릅니다.

| 첫머리 | 뜻 |
|---|---|
| `대전광역시 중구 · 오늘 …` | 컴퓨터 위치 서비스로 찾음(구 단위) |
| `대전광역시 (시·도 기준) · 오늘 …` | 인터넷 주소 서비스 다수결로 찾음(시·도까지) |
| `… (대략·IP 기준) · 오늘 …` | 다수결이 안 났거나 인터넷 주소 한 곳 기준 — 지역이 다르면 지역명을 말해 주세요 |

itda-hyve 가 연결돼 있지 않거나 위치를 못 찾으면 **다른 곳의 날씨를 대신 보여주지 않고** 지역명을 알려 달라고 안내합니다.

### 특정 지역 지정 (한국어·영문)

```
/weather-here 대전 날씨 알려줘
```

```
/weather-here Busan 날씨
```

시·도(서울·부산·경기 등)와 시군구(해운대구 등), 그리고 일반구가 있는
시(수원·성남·창원 등)를 지원합니다. 주요 도시는 영문 이름도 됩니다.
지역명은 기상청 공식 좌표표를 기준으로 해석해 엉뚱한 곳의 날씨가
나오지 않습니다.

### 상세 수치까지 보기

```
/weather-here 서울 날씨 자세히
```

기본은 한 줄 요약(지역·상태·강수확률)이고, "자세히/상세"를 붙이면
기온·습도·강수량·바람까지 보여줍니다.

## 출력 옵션

| 모드 | 보여주는 것 | 사용 시점 | 부르는 법 |
|------|-------------|-----------|-----------|
| 기본(요약) | 지역, 날씨 상태, 강수확률 한 줄 | 외출 전 빠른 확인 | "지금 날씨" |
| 상세 | 기온·습도·강수량·바람까지 | 수치가 필요할 때 | "자세히" / "상세" 덧붙이기 |
| 지역 지정 | 다른 지역의 날씨 | 현재 위치 말고 다른 곳 | "부산 날씨" 처럼 지역명 명시 |

### 결과 화면 예시

기본:

```
대전광역시 · 오늘 대체로 맑음, 강수확률 8% — 비 올 가능성 낮아요
```

자세히:

```
[대전광역시] 현재 날씨
날씨 상태: 대체로 맑음
기온: 17.2°C
습도: 88%
강수량: 0.0mm
풍속: 2.7m/s

오늘 강수확률: 8%
```

## 팁

- **되묻지 않음** — 위치를 안 말해도 itda-hyve 로 찾아 바로 답합니다. 추정이
  빗나가면 지역명을 직접 말해 주세요(그 지역이 우선됩니다).
- **인터넷 주소로 찾은 위치는 출구 기준** — VPN·회사망을 쓰면 그 출구 위치가 잡힙니다. 컴퓨터 위치 서비스를 허용해 두면 영향이 없습니다.
  그럴 땐 지역명을 말해 주세요.
- **키 발급 불필요** — 별도 신청이 없어 설치 직후 바로 동작합니다.
- **해외 위치는 대략값만** — 한국 밖이면 "(해외·대략·미검증)" 라벨과 함께
  대략값만 제공합니다. 정확도를 보장하지 않습니다.
- ⚠️ **읍·면·동 단위는 지원 안 함** — 시·도와 시군구(일반구 포함)까지만
  지원합니다. 같은 시 안의 동네별 차이는 구분하지 않습니다.
- ⚠️ **물을 때마다 새로 조회** — 같은 분 안에 다시 물은 경우만 방금 받은 결과를 다시 씁니다. 위치도 한 시간이 지나면 새로 찾습니다.
- ⚠️ **조회 실패 시** — itda-hyve 가 켜져 있고 Claude Desktop 에 연결돼 있는지 먼저 확인하세요.
  연결돼 있는데 실패하면 일시적 네트워크 문제이니 잠깐 뒤 다시 요청하세요.
- ⚠️ **"묵은 파일" 안내** — 받아 둔 날씨가 3시간 넘게 지난 것이면 쓰지 않고 새로 받습니다.
