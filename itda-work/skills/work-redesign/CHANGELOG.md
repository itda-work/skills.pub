# Changelog — work-redesign

## [0.3.1] — 2026-08-17

### Added

- **검증의 주체 판별 기준** — 증강/자동화의 경계를 명문화: 검증까지 규칙·코드로 적을 수
  있으면 자동화(항목에 `검증(규칙):` 병기 권장, `다음:` 핸드오프 유지), 산출을 사람이 매번
  읽고 판단하면 증강. 검증이 규칙으로 적히는 순간의 증강→자동화 승격 개념 추가(4단계·의미
  점검). 기존에는 좌측 우선만 있고 우측 2칸의 배치 기준이 없어, 규칙 집계류가 증강에 오배치
  되는 사례 발생(블로그 work-redesign-before-after 4분면 이미지 교정 계기 — 마스터 지적
  2026-08-17, hyve-training `[기획] 4분면 정합` 문서 참조).
- **일부러 유지의 사유 2분화** — ⓐ 기술 한계로 못 맡김 / ⓑ 전환 비용(설명·검증 품 >
  절감)이 커서 안 맡김을 4분면 표·4단계 질문에 명시("되느냐가 아니라 남느냐"). 기존 표의
  "전환 비용·기술 한계" 병렬 나열을 사유 구분으로 승격.
- **게이트·산출 계약 불변** — C1~C5·W1~W4, work-map.md 섹션 구조, 파서 계약 모두 그대로.
  문서(SKILL·GUIDE)만 변경.

## [0.3.0] — 2026-08-11

### Added

- **정답×협업 렌즈** — 4단계 매핑에 보조 질문 2개 도입: ① 정답 질문("정석·체크리스트가 있는가" → 있으면 그것이 검증 기준, 없으면 이해관계자 승인이 검증), ② 협업 질문(대인 행동에 `[협업]` 태그). 도입부에 "정답이 있는 일은 AI로 넘어가고, 정답 없는 일과 사람 사이의 일이 남는다" 브리지 추가. 개념 출처: 지식인초대석 EP.132 김대식 소개 분류(정답 유무×협업 유무, 원 프레임 출처 미상 — hyve-training `docs/김대식-정답x협업-매트릭스-igm-접목-연구.md` 참조) + Autor·Levy·Murnane(2003)·Deming(2017) 계보. **4분면 축(가치×AI개입)·산출 계약·게이트 계약은 불변** — 질문 언어만 흡수.
- `check_work_map.py` W4 경고 — 자동화 항목에 협업 신호(`[협업]` 태그 또는 전화·회의·설득 등 대인 어휘) 감지 시 "기술만 분리 위임" 재검토 안내. VERIFY_SIGNAL 에 정답·정석·체크리스트 어휘 추가.
- aliases에 정답있는일·정답없는일·AI역할분담 추가 (강연·영상 어휘 라우팅).
- GUIDE에 연도별 생존전략 타임라인(2023 프롬프트→2026 에이전트) 한 단락 — 자동화 사다리의 외부 근거.
