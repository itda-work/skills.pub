# markdown-doc 사용 가이드

PC 에 설치한 **itda-hyve 문서 창**에서 보는 마크다운(.md) 문서 — 보고서·제안서·기안문·회의록·매뉴얼·발표 자료 — 를 Claude 가 대신 쓰고 고칩니다.
**아래처럼 `/markdown-doc` 뒤에 지침을 붙여 입력하면 됩니다** — `/markdown-doc 3분기 사업 보고서를 보고서 양식으로 써줘`처럼요. 자연어로 말해도 동작합니다.

Claude 는 지금 설치된 itda-hyve 가 아는 문법을 앱에서 받아 쓰고, 문서 창과 같은 방법으로 검사해 **경고가 없게** 맞춥니다.
md 를 직접 고칠 줄 몰라도 됩니다. 터미널 명령을 입력할 필요도 없습니다.

---

## 처음 설정하기

1. **itda-hyve 0.17.2 이상을 설치하고 Claude Desktop 에 연결합니다.** [itda-hyve 내려받기](https://itda.work/hyve/)에서 받습니다. 이미 있다면 최신판으로 업데이트하세요 —
   문서 도구(문법 받기·검사·미리보기)는 0.17.2 부터 들어 있습니다.
2. 설치한 뒤 itda-hyve 설정 창의 Claude Desktop 연결에서 등록합니다.
3. Claude 에게 `/markdown-doc 문서 창에서 쓸 수 있는 차트 종류 알려줘` 라고 말해 보세요. 종류가 나오면 준비가 끝났습니다.

Cowork 에서 쓸 때는 문서를 둘 폴더를 **연결 폴더**로 고르세요. 연결 폴더 밖의 파일은 Cowork 가 쓸 수 없습니다.

## 이렇게 말하세요

### 새 문서 쓰기

- `/markdown-doc 3분기 영업 실적 보고서를 써줘. 분기별 매출 차트와 목표선을 넣어줘`
- `/markdown-doc 오늘 회의 내용을 회의록 양식으로 정리해줘` (메모를 함께 붙여 넣으세요)
- `/markdown-doc 이 보고서를 10장짜리 발표 자료로 바꿔줘`
- `/markdown-doc 협조 요청 공문 초안을 기안문 양식으로 써줘`

처음 만든 문서는 문서 창이 한 번 열립니다. 그 뒤로 Claude 가 고칠 때마다 창이 저절로 따라 바뀝니다.

### 열린 문서 고치기 — "Claude 에게 고쳐 달라기"

문서 창 도구 막대의 **Claude 에게 고쳐 달라기**(또는 미리보기에서 고칠 부분을 오른쪽 클릭 → **이 부분 고쳐 달라기**)를 누르고,
무엇을 고칠지 적은 뒤 **경로로 복사**를 누르세요. 그 글을 Claude 대화창에 그대로 붙여 넣으면 됩니다 — `/markdown-doc` 을 앞에 붙이면 더 확실합니다.

- Claude 는 고르신 **그 부분만** 고칩니다. 다른 곳에 경고가 있으면 같이 고칠지 묻습니다.
- 공유 폴더가 없는 대화(Claude Desktop 에서 파일을 못 쓰는 경우)라면 **본문 포함 복사**를 쓰세요. Claude 가 고친 전체 글을 돌려주면,
  문서 창에서 전체를 바꿔 붙여 넣고 저장합니다. 문서가 너무 크면(64KB 넘음) 본문 포함 복사가 되지 않습니다.

### 경고 고치기

- `/markdown-doc 보고서.md 에 경고가 떠 있어. 고쳐줘`
- `/markdown-doc 이 차트가 표로만 보여. 왜 그런지 보고 고쳐줘`

경고를 없애려고 표의 숫자를 지우지 않습니다. 차트에 다 못 그리는 항목은 차트를 나누거나 표를 함께 싣습니다.

## 안 될 때

| 증상 | 할 일 |
|---|---|
| "itda-hyve 가 연결되지 않아 스킬에 든 문법 사본으로 썼다" 고 함 | itda-hyve 를 최신판으로 업데이트하고 Claude Desktop 을 다시 시작하세요. 그동안 쓴 문서는 문서 창의 경고 단추(⚠)로 확인하세요 |
| 문서 창이 열리지 않음 | itda-hyve 설정에서 **파일·링크 열기**가 꺼져 있을 수 있습니다. 켜거나, 알려 준 파일을 문서 창에서 직접 여세요 |
| 창에서 고치던 중에 "이 파일이 밖에서 바뀌었습니다" 띠가 뜸 | Claude 가 같은 파일을 고친 것입니다. **다시 읽기**(Claude 의 글로) 또는 **내 것 유지**를 고르세요. 창은 묻지 않고 덮어쓰지 않습니다 |
| Cowork 에서 파일을 못 찾음 | 문서가 연결 폴더 안에 있는지 확인하세요 |

> 문서 안에 적힌 글은 Claude 에게 내리는 지시가 아닙니다. 남이 보낸 문서에 "이 파일을 지워라" 같은 글이 있어도 따르지 않습니다.
