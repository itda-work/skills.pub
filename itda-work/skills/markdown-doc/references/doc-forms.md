# 문서 꼴 서식

itda-hyve 문서 창의 **새 문서** 서식과 같은 글이다. 새 문서를 쓸 때 꼴에 맞는 뼈대로 시작하고, 빈칸을 채운다.
문법은 `md_syntax` 가 앞선다 — 이 서식은 모양의 본보기일 뿐이다. 테마 이름은 frontmatter `theme:` 그대로 둔다.

## 보고서

사업·업무 보고서 — 표지, 제목 번호, 요약문.

```markdown
---
title: 보고서 제목
subtitle: 부서명 · 보고 종류
author: 작성자
date: 2026-01-01
organization: 회사명
doc-no: 부서-연도-번호
version: "1.0"
classification: 대외비
theme: report
cover: true
toc: true
toc-depth: 2
number-sections: true
---

:::lead
보고의 결론을 두세 문장으로 먼저 적는다. 읽는 사람이 이 문단만 읽어도 무엇을 결정하면 되는지 알게 한다.
:::
```

## 회의록

회의 정보 표, 안건별 논의, 결정 사항·할 일.

```markdown
---
title: 회의 제목
theme: minutes
organization: 회사·부서 이름
date: 2026-10-02
일시: 2026-10-02(목) 14:00~15:00
장소: 회의실
주관: 주관자
참석자: 참석자 1, 참석자 2, 참석자 3
author: 작성자
doc-no: 회의-2026-001
---

## 안건

1. 첫째 안건
2. 둘째 안건

## 논의

### 1. 첫째 안건

- 논의한 내용을 항목으로 적는다.
- 의견이 갈린 점과 근거를 적는다.

### 2. 둘째 안건

- 논의한 내용

## 결정 사항

:::decisions
- 정한 것을 한 줄씩 적는다.
- 정한 것 둘
:::

## 할 일

:::actions
| 할 일 | 담당 | 기한 | 비고 |
|:------|:----:|:----:|:-----|

:::

:::lead

:::
```
