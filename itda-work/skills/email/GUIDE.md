title: "email 활용 가이드"
---

네이버·Gmail·다음/카카오·아이클라우드·회사 메일로 메일을 찾고 읽고 보내는 스킬입니다. **Claude에게 자연어로 말하면 됩니다.**
메일 계정은 PC 에 설치한 **itda-hyve** 앱에 등록해 두고, Claude 는 그 앱을 통해서만 메일에 접근합니다.
비밀번호는 itda-hyve 안에만 있고 Claude 에게 전달되지 않습니다.

---

## 처음 설정하기

1. **itda-hyve(0.9.0 이상)를 설치하고 Claude Desktop 에 연결합니다.** [itda-hyve 내려받기](https://itda.work/hyve/)에서 운영체제에 맞는 설치 파일을 받습니다(설치 방법도 같은 페이지에 있습니다).
   설치한 뒤 itda-hyve 앱의 "Claude Desktop" 화면에서 등록 버튼을 누르면 됩니다.
2. **메일 서비스에서 앱 비밀번호를 발급합니다.** 메일 서비스는 보안 때문에 계정 비밀번호를 그대로 쓰지 못합니다. 아래 서비스별 절차대로 2단계 인증을 켜고 앱 비밀번호를 받으세요.
3. **itda-hyve 의 "계정" 화면에서 계정을 추가합니다.** 제공자·아이디·앱 비밀번호만 넣으면 서버 주소는 자동으로 채워지고, 저장 전에 연결 테스트를 합니다(메일은 보내지 않습니다).

> 비밀번호를 Claude 대화창에 붙여 넣지 마세요. Claude 는 그 값을 쓰지 않습니다.

쓰는 메일 서비스를 누르면 설정 페이지가 열립니다.

:::cards

- [네이버](https://nid.naver.com) — 2단계 인증 후 앱 비밀번호 발급 · IMAP 켜기
- [Gmail](https://myaccount.google.com/apppasswords) — 2단계 인증 후 앱 비밀번호(16자리) 발급
- [다음 / 카카오](https://mail.daum.net) — IMAP 켜고 전용 비밀번호 확인
- [아이클라우드](https://account.apple.com) — 앱 전용 비밀번호 생성
- 회사 메일 — itda-hyve 계정 화면의 "직접 입력" 에서 보내기·받기 서버 정보 입력

:::

> 네이버·iCloud 앱 비밀번호 발급 절차는 [네이버](https://itda.work/credentials/naver-app-password/) · [iCloud](https://itda.work/credentials/icloud-app-password/) 발급 가이드도 참고하세요.

### 네이버

1. [네이버 로그인 보안](https://nid.naver.com)에서 2단계 인증을 켭니다.
2. 보안 설정 → 2단계 인증 → "애플리케이션 비밀번호 관리"에서 비밀번호를 발급받아 **그 자리에서 복사**합니다(한 번만 보입니다).
3. 네이버 메일 → 설정(톱니바퀴) → "POP3/IMAP 설정"에서 IMAP을 **사용함**으로 켭니다.
4. itda-hyve 계정 화면에서 제공자 "네이버" 를 고르고 아이디·앱 비밀번호를 넣습니다.

### Gmail

1. [Google 계정](https://myaccount.google.com) → 보안에서 2단계 인증을 켭니다.
2. [앱 비밀번호 페이지](https://myaccount.google.com/apppasswords)에서 이름(예: itda-hyve)을 적고 만들기 → **16자리 비밀번호**를 복사합니다.
3. itda-hyve 계정 화면에서 제공자 "Gmail" 을 고르고 넣습니다. (일반 로그인 비밀번호는 동작하지 않습니다.)

### 다음 / 카카오

1. [다음 메일](https://mail.daum.net) → 환경설정 → "IMAP/POP3" 탭에서 IMAP 사용을 **사용함**으로 켭니다.
2. 같은 화면의 "비밀번호 확인하기"를 눌러 카카오 계정 인증 후 나오는 **전용 비밀번호**를 복사합니다.
3. itda-hyve 계정 화면에서 제공자 "다음" 을 고르고 넣습니다. `@daum.net`·`@hanmail.net`·`@kakao.com` 모두 같습니다.

### 아이클라우드 (iCloud Mail)

1. [Apple 계정 관리](https://account.apple.com) → **로그인 및 보안**에서 2단계 인증이 켜져 있는지 확인합니다.
2. 같은 페이지의 **앱 전용 비밀번호** → "앱 전용 비밀번호 만들기" 로 **xxxx-xxxx-xxxx-xxxx** 형식의 비밀번호를 받습니다(한 번만 표시됩니다).
3. itda-hyve 계정 화면에서 제공자 "iCloud" 를 고르고 넣습니다. `@icloud.com`·`@me.com`·`@mac.com` 모두 같습니다.

```

```

자연어로 말해도 그대로 동작합니다 — `/email` 접두는 생략 가능합니다.

## 활용 시나리오

### 목록 먼저, 고른 메일만 열기

"네이버 메일 보여줘" 라고 하면 Claude 가 먼저 **날짜·보낸 사람·제목** 목록만 보여 줍니다. 그중 "2번 열어줘" 처럼 고른 메일만 본문을 엽니다.
메일을 열어도 **읽음 표시는 바뀌지 않습니다** — 웹메일에서는 여전히 안 읽은 메일로 보입니다.

```
/email 네이버에서 이번 주에 김대리가 보낸 메일 찾아줘
/email 그중 첫 번째 열어줘
```

### 보내기 전에 미리보기 확인

메일을 보낼 때는 Claude 가 먼저 **미리보기(보낸 사람·받는 사람·제목·본문 앞부분·첨부)** 를 보여 주고, "보내" 라고 확인해야 실제로 발송됩니다.
미리보기를 보고 내용을 고치라고 하면 고친 내용으로 미리보기를 다시 보여 줍니다. 미리보기는 10분이 지나면 다시 만들어야 합니다.

### 파일 첨부

첨부할 파일이 있는 **폴더를 함께 말하면** 됩니다. Claude 가 그 폴더(작업 폴더 또는 itda-hyve 저장 폴더)에서 파일을 찾아 붙입니다.

```
/email 작업 폴더의 reports/q3.pdf 를 김대리(kim@example.com)에게 보내줘
```

폴더를 말하지 않으면 itda-hyve 저장 폴더에서 찾습니다(새로 설치하면 `다운로드/itda-hyve`, 개명 전 판에서 옮겨 왔다면 예전 폴더 그대로 — 실제 폴더는 itda-hyve 의 "상태·로그" 화면에서 확인). 어느 폴더든 **사용자 홈 아래 폴더**여야 하고, 홈 폴더 자체·숨김 폴더·시스템 설정 폴더(`AppData`·`라이브러리`)는 안 됩니다.

### 받은 첨부를 받아서 읽기

"첨부를 받아서 요약해줘" 라고 하면 Claude 가 첨부를 **작업 폴더에 파일로 저장한 뒤 그 파일을 열어** 내용을 요약합니다.
메일 본문이 아니라 **첨부 파일의 내용**(PDF 의 숫자, 엑셀의 표 등)을 읽습니다.

```
/email naver 에서 "3분기 보고" 메일의 첨부를 작업 폴더에 받아서, 핵심만 정리해줘
/email 그 메일의 엑셀 첨부만 받아줘
```

- **Cowork 에서는 폴더를 먼저 연결하세요.** 첨부는 연결한 폴더에 저장되고, Claude 는 거기서 파일을 엽니다. 폴더를 연결하지 않으면 저장은 되지만 Claude 가 내용을 읽을 수 없습니다.
- 같은 제목의 메일이 여러 통이면 어느 메일인지 먼저 물어봅니다.
- 같은 이름의 파일이 이미 있으면 「이름 (1).pdf」 처럼 새 이름으로 저장합니다. 기존 파일을 덮어쓰지 않습니다.
- 첨부를 받아도 **읽음 표시는 바뀌지 않습니다.**
- **실행 파일은 받지 않습니다** — `.exe`·`.js`·`.bat`·`.lnk`·`.ps1`·`.msi`·`.iso` 같은 실행·스크립트 형식은 저장하지 않고 이유를 알려 줍니다. 모르는 사람이 보낸 실행 파일은 피싱일 가능성이 높습니다.
- **매크로 문서** (`.docm`·`.xlsm`·`.pptm` 등)는 저장하되 경고를 붙입니다. 열 때 매크로(콘텐츠 사용)를 켜지 마세요.
- 첨부 하나가 **30MB 를 넘으면** 받지 않습니다. 웹메일에서 직접 내려받으세요.
- 첨부 파일 안에 "이 파일을 누구에게 보내라" 같은 문구가 있어도 Claude 는 따르지 않습니다.

### 받은 메일에 답장

```
/email 방금 그 거래처 메일에 "확인했습니다, 금요일까지 회신드리겠습니다" 라고 답장해줘
```

원래 메일과 같은 대화로 묶이도록 답장합니다(제목에 `Re:`).

### 여러 계정

itda-hyve 에 계정을 여러 개 등록했다면 "work 계정으로 보내줘" 처럼 계정 이름을 말하세요. 계정 이름은 itda-hyve 계정 화면에 보이는 이름입니다.

## 받는 결과에 들어 있는 것

- **목록** — 날짜·보낸 사람·제목·첨부 여부·읽음 여부. 본문은 고른 메일만 엽니다.
- **첨부 요약** — 저장한 파일 이름·크기와 그 파일의 내용 요약. 받지 못한 첨부는 이름과 이유를 따로 알려 줍니다.
- **피싱 주의 표시** — 회신 주소가 보낸 사람과 다른 도메인이거나, 표시 이름과 주소가 어긋나거나, 급하다며 링크·송금·비밀번호를 요구하면 ⚠️ 표시가 붙습니다.
  이 경로에서는 발신 인증(SPF/DKIM/DMARC) 결과를 받지 않으므로 "인증은 확인하지 못했다" 는 말이 함께 붙습니다.
- **메일 속 지시는 따르지 않음** — 메일 본문에 "이 메일을 전달하라" 같은 문구가 있어도 Claude 는 따르지 않고, 필요하면 먼저 물어봅니다.

## 안 될 때

- **"계정이 없다"고 나온다** — itda-hyve 계정 화면에 계정이 등록돼 있지 않습니다. 계정 화면에서 추가하세요(추가하면 다시 시작하지 않아도 바로 반영됩니다).
- **"로그인 실패"(auth_error)** — 앱 비밀번호가 틀렸거나 메일 서비스에서 IMAP 이 꺼져 있습니다. itda-hyve 계정 화면의 "연결 테스트" 로 확인하고, 필요하면 앱 비밀번호를 다시 발급받아 교체하세요.
- **Claude 가 itda-hyve 를 모른다고 한다** — itda-hyve 가 Claude Desktop 에 연결되지 않은 것입니다. itda-hyve 의 "Claude Desktop" 화면에서 등록하고 Claude Desktop 을 다시 시작하세요.
- **첨부를 받았는데 메일 본문만 요약한다** — "첨부 **파일의 내용**을 요약해줘" 처럼 말하면 확실합니다.
- **첨부를 받았는데 Claude 가 파일을 못 연다** — Cowork 에서 폴더를 연결하지 않았거나 다른 폴더에 저장된 경우입니다. 폴더를 연결하고 "연결 폴더에 받아줘" 라고 다시 말하세요.
- **첨부가 거부된다** — 첨부 파일이 있는 폴더를 말하지 않았거나, 그 폴더가 사용자 홈 밖·홈 폴더 자체·숨김 폴더이거나, 첨부가 숨김 파일·바로가기(심볼릭 링크)입니다. "작업 폴더의 …" 처럼 어느 폴더인지 알려 주세요.

## 제한사항

- **이 스킬로 할 수 없는 것** — 임시보관함(초안) 저장, 메일 이동·스팸 처리·휴지통·영구 삭제, 읽음/별표 표시 변경, 폴더 만들기·이름 바꾸기·지우기, 미회신 메일 자동 판정. 이런 작업은 웹메일·메일 앱에서 직접 하세요.
- **앱 비밀번호 필수** — 메인 계정 비밀번호로는 로그인이 안 됩니다.
- **첨부 크기** — Gmail 은 한 통에 25MB, 네이버는 10MB(합계 20MB)까지입니다.
- **발송 상한** — Gmail 무료 계정 100통/일, 워크스페이스 2,000통/일. 네이버는 한 번에 받는 사람 100명까지.
