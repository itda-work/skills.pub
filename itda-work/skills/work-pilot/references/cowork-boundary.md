# Cowork 가능/불가 경계 지도 — 파일럿 기획 판별 기준

> 관문1 3분류의 판별 준거. 환경(커넥터 구성)에 따라 달라질 수 있는 항목은 "환경 확인"으로
> 표시 — 단정하지 말고 사용자에게 1문으로 확인한다.

## [Cowork 안] — 지금 바로 되는 것

- 업로드된 파일(엑셀·CSV·워드·PPT·PDF·텍스트) 읽기·분석·요약·분류·대조
- 문서·표·보고서·이메일 **초안** 생성, 파일로 저장(outputs)
- 기준·가이드 문서를 근거로 한 일관된 판정(근거 제시 포함)
- 모의 데이터 생성, 통계 집계, 결과표 작성
- 웹 검색(공개 정보 조사 — 환경에 따라 제한 가능: 환경 확인)
- 커스텀 스킬(SKILL.md) 저작·사용

## [수동 브릿지] — 사람이 한 동작으로 잇는 것 (파일럿 포함 가능)

- 사내 웹 시스템의 데이터 → **내보내기(엑셀/CSV)** → Cowork 업로드
- 메일·메신저 발송: AI 는 초안까지, **복사→발송은 담당자** (발송 커넥터는 환경 확인)
- 처리 결과를 사내 시스템에 반영: 결과표를 보고 담당자가 입력
- 정기 실행: 예약 실행 없음 — **담당자가 루틴으로 세션을 여는 방식**으로 설계

## [시스템 연동] — Cowork 밖, IT 과제로 분리 (파일럿 제외)

- 사내 시스템·DB·API 직접 접속(로그인 자동화·스크래핑 포함)
- 무인 정기 실행(스케줄러)·실시간 트리거(접수 즉시 자동 처리)
- 자동 발송·자동 시스템 기입(사람 승인 없는 실행)
- 대량·상시 데이터 파이프라인

## 판별 요령

1. "데이터가 **파일로 나올 수 있는가**?" — 나오면 수동 브릿지로 파일럿 가능.
2. "이 단계에 **사람 승인이 원래 필요한가**?" — 필요하면 자동화 제외가 손해가 아니라 설계다
   (검토·승인은 §6 지표의 일치율 측정 지점이 된다).
3. "**무인·실시간**이어야만 가치가 있나?" — 그렇다면 시스템 연동 과제. 대부분의 업무는
   일 1회 배치(수동 브릿지)로도 절감 효과의 대부분을 얻는다 — 신청서 기대 효과와 대조해 설명.
