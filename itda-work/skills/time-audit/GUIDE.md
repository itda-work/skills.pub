# time-audit 사용 가이드

> 코드를 몰라도 됩니다. 캘린더만 있으면 됩니다.

## 이 스킬이 하는 일

내 캘린더 실적으로 "시간이 어디로 가는지"를 숫자로 보여 줍니다 — 업무별 소요 시간,
난이도(상/중/하)별 분포, 주별 추이, 건당 가장 오래 걸리는 병목 후보까지. 감이 아니라
실측이라, 뭘 AI에 맡기고 뭘 줄일지 판단할 근거가 생깁니다.

## 이렇게 말해 보세요

- `/time-audit 내 시간 어디에 쓰는지 분석해줘`
- `/time-audit 지난 4주 캘린더로 업무 시간 매핑해줘`
- `/time-audit 시간 감사 해줘`
- `/time-audit 뭐가 오래 걸리는지 봐줘`

구글 캘린더 커넥터를 연결해 뒀거나, 아이클라우드·네이버 캘린더(itda 캘린더 스킬),
캘린더 내보내기 파일 중 아무거나 있으면 됩니다.

## 진행 순서 (약 10~20분)

1. **기간·캘린더 고르기** — 기본은 최근 4주.
2. **일정 분류 같이 하기** — 업무가 아닌 일정(점심·개인 약속)을 골라내고, 업무 일정을
   카테고리로 묶습니다. 업무 지도(work-map.md)를 먼저 만들었다면 그 태스크가 그대로
   분류 후보로 나옵니다.
3. **난이도 정하기** — 카테고리마다 상/중/하.
4. **리포트 받기** — time-audit.md 가 폴더에 생깁니다. 모든 숫자는 스크립트가 계산한
   값 그대로입니다.

## 팁

- **완료한 일을 캘린더에 기록하는 습관**이 이 스킬의 연료입니다. 기록이 없으면 스킬이
  분석 대신 기록 방법부터 안내합니다 — 그게 정상 동작입니다.
- 월 1회 돌리면 추이가 쌓입니다. 업무 지도의 4분면을 실측으로 다듬는 데 쓰세요.
- "미배정 20% 초과" 경고가 나오면 분류를 조금 더 채우라는 뜻입니다.
