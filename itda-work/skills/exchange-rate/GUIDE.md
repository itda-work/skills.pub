---
title: "Exchange Rate (매매기준율) 활용 가이드"
---

원화 기준 매매기준율을 일별·월평균·기간 표로 조회하는 스킬입니다. 데이터는 서울외국환중개(www.smbs.biz)가 고시하는 값이고, **API 키나 가입이 필요 없습니다.** Claude에게 자연어로 말하면 날짜와 통화를 파악하고, 휴일에는 직전 영업일 환율로 알려 줍니다.

---

## 사전 준비

환율 사이트 조회는 사용자 PC 에서 도는 **itda-hyve** 앱이 대신 보냅니다(Cowork 작업 공간에서는 외부 사이트 접속이 막히거나 끊길 수 있기 때문입니다).

1. itda-hyve 0.10.4 이상을 설치하고 Claude Desktop 에 연결합니다(https://itda.work/hyve/).
2. Cowork 라면 결과 파일을 둘 폴더를 연결해 두세요. 조회 한 번에 작은 파일 하나(수 KB)가 그 폴더의 `exrate` 아래에 저장됩니다.

등록할 키는 없습니다.

---

## 빠른 시작

```
/exchange-rate 오늘 달러 환율 알려줘
```

```
/exchange-rate 이번 달 엔화 평균 환율 보여줘
```

```
/exchange-rate 이번 달과 지난달 달러 평균 환율 비교해줘
```

자연어로 말해도 그대로 동작합니다 — `/exchange-rate` 접두는 생략 가능합니다.

---

## 활용 시나리오

### 특정 일자 환율 조회

```
/exchange-rate 2025년 1월 5일 달러 환율 알려줘
```

날짜는 `2025-01-05`, `2025.01.05` 형태 모두 그대로 붙여넣어도 됩니다.

### 한 달 일별 환율 전체 조회

월 단위로 일별 매매기준율을 한 번에 표로 받습니다(1년까지 조회 1회, 더 길면 1년마다 한 번씩 — 최대 10년).

```
/exchange-rate 2025년 9월 한 달간 달러 환율을 일별로 보여줘
```

### 월간 비교 분석

서로 다른 월의 평균을 비교해 추이를 파악합니다. 여러 달의 월평균은 표 하나로 한 번에 받습니다(최대 5년).

```
/exchange-rate 이번 달 엔화 평균과 지난달 엔화 평균을 비교해줘
```

```
/exchange-rate 올해 달러 월평균 추이 보여줘
```

### 휴일 자동 폴백

주말·공휴일 날짜로 조회하면 직전 영업일 매매기준율이 돌아옵니다. 추석처럼 연휴가 길어도 최대 2주 전까지 거슬러 찾습니다.

```
/exchange-rate 2025년 10월 5일 달러 환율 알려줘
```

추석 연휴 중이라 직전 영업일(10월 2일) 값으로 알려 줍니다.

## 안 될 때

- **itda-hyve 도구가 보이지 않는다고 할 때** — itda-hyve 앱이 켜져 있는지, Claude Desktop 에 연결돼 있는지 확인하세요.
- **"고시된 환율이 없습니다" (`empty`)** — 통화 이름이 다르거나, 그 기간에 고시가 없었습니다. 통화 코드(예: USD, JPY)로 다시 말해 보세요.
- **"응답이 일부만 왔을 수 있어 결과를 내지 않습니다" (`gap`)** — 기간 표 중간이 비어 있습니다. 잠시 뒤 다시 요청해 보세요.
- **오늘 날짜인데 어제 값이 나올 때** — 매매기준율은 영업일 아침(9시 이전)에 고시됩니다. 고시 전이면 직전 영업일 값을 보여 주고 그 사실을 함께 알립니다. 조금 뒤 다시 물으면 새로 받아 옵니다.
- **이번 달 평균이 "아직 집계되지 않았습니다" (`empty`)** — 달 초에는 월평균이 아직 없습니다. "이번 달 달러 환율 일별로" 처럼 일별 표로 보세요.
- **위안화** — 서울외국환중개는 2016년부터 위안을 역외 위안(CNH)으로만 고시합니다. "위안" 이라고 말하면 CNH 로 조회합니다.

---

## 팁

- **휴일 폴백 트릭**: 주말·공휴일 날짜로 조회하면 직전 영업일 값이 돌아옵니다. "가장 최근 영업일 환율"을 빠르게 확인할 때 유용합니다.
- **진행 중인 달의 평균**: 이번 달 평균은 오늘까지의 평균이라 달이 끝나면 바뀝니다. 결과에 그 사실이 함께 표시됩니다.
- **한국어 통화 별칭**: "달러", "엔", "유로" 같은 한국어 이름도 ISO 코드(USD, JPY, EUR)로 매핑됩니다.
- ⚠️ **조회 범위 제한**: 서울외국환중개가 고시하는 58개 통화, 2000년 이후만 조회됩니다. 은행별 현찰·송금 환율(살 때·팔 때)은 다루지 않습니다.
