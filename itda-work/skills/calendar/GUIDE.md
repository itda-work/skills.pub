# calendar 사용 가이드

네이버·아이클라우드(및 CalDAV 주소를 넣은 직접 입력 계정) 캘린더의 일정을 자연어로 조회·검색·추가·수정·삭제하고, 빈 시간도 찾아줍니다.
**아래처럼 `/calendar` 뒤에 지침을 붙여 입력하면 됩니다** — `/calendar 이번 주 일정 보여줘`, `/calendar 내일 3시 회의 추가해줘`, `/calendar 다음 주에 1시간 빈 시간 찾아줘`처럼요. 자연어로 말해도 동작합니다.

캘린더 계정은 PC 에 설치한 **itda-hyve** 앱에 등록해 두고, Claude 는 그 앱을 통해서만 캘린더에 접근합니다.
비밀번호는 itda-hyve 안에만 있고 Claude 에게 전달되지 않습니다. 터미널 명령을 입력할 필요는 없습니다.

---

## 지원하는 캘린더

:::cards

- [네이버 캘린더](https://calendar.naver.com) — 네이버 메일 계정을 등록하면 캘린더도 됩니다
- [아이클라우드 캘린더](https://www.icloud.com/calendar) — iCloud 메일 계정을 등록하면 캘린더도 됩니다
- 직접 입력 — 표준 CalDAV 를 제공하는 서비스(Fastmail · Nextcloud · mailbox.org · Posteo 등). 계정의 고급 설정에 캘린더 주소를 넣습니다

:::

셋 다 **표준 CalDAV** 와 **앱(전용) 비밀번호**로 연결합니다. 메일 계정과 캘린더가 **같은 계정·같은 앱 비밀번호**를 씁니다 —
email 스킬 때문에 네이버·아이클라우드 메일을 이미 등록했다면 **추가 설정 없이** 캘린더도 바로 쓸 수 있습니다.

---

## 처음 설정하기

1. **itda-hyve(0.9.0 이상)를 설치하고 Claude Desktop 에 연결합니다.** [itda-hyve 내려받기](https://github.com/itda-work/itda-hyve.pub/releases/latest)에서 운영체제에 맞는 설치 파일을 받습니다(설치 방법은 [설치 안내](https://github.com/itda-work/itda-hyve.pub#readme)).
   설치한 뒤 itda-hyve 앱의 "Claude Desktop" 화면에서 등록 버튼을 누르면 됩니다.
2. **메일 서비스에서 앱 비밀번호를 발급합니다.** 아래 서비스별 절차를 보세요. 메일용으로 이미 발급했다면 그대로 씁니다.
3. **itda-hyve 의 "계정" 화면에서 계정을 추가합니다.** 제공자·아이디·앱 비밀번호를 넣으면 서버 주소가 자동으로 채워집니다.
   저장 전 연결 테스트에 **캘린더(CalDAV) 줄**이 함께 나오니 성공인지 확인하세요.
4. Claude 에게 `/calendar 내 캘린더 목록 보여줘` 라고 말해 보세요. 캘린더 이름이 나오면 준비가 끝났습니다.

> 비밀번호를 Claude 대화창에 붙여 넣지 마세요. Claude 는 그 값을 쓰지 않습니다.

### 네이버

네이버는 **메일과 같은 앱 비밀번호**를 캘린더에도 씁니다.

1. [네이버 로그인 보안](https://nid.naver.com)에서 **2단계 인증**을 켭니다(앱 비밀번호는 2단계 인증이 켜져 있어야 발급됩니다).
2. 보안 설정 → 2단계 인증 → **"애플리케이션 비밀번호 관리"** 에서 비밀번호를 발급받아 **그 자리에서 복사**합니다(한 번만 보입니다).
3. itda-hyve 계정 화면에서 제공자 **"네이버"** 를 고르고 아이디·앱 비밀번호를 넣습니다. 캘린더 주소는 자동으로 정해집니다.

> 자세한 발급 절차는 [네이버 앱 비밀번호 발급 가이드](https://itda.work/credentials/naver-app-password/)를 참고하세요.

### 아이클라우드(iCloud)

캘린더는 **애플 메일과 같은 앱 전용 비밀번호**를 씁니다.

1. [Apple 계정 관리](https://account.apple.com) → **로그인 및 보안**에서 2단계 인증이 켜져 있는지 확인합니다.
2. 같은 페이지의 **앱 전용 비밀번호** → "앱 전용 비밀번호 만들기" → 이름(예: `itda-hyve`)을 넣고 만들면
   **xxxx-xxxx-xxxx-xxxx** 형식의 비밀번호가 나옵니다(다시 볼 수 없으니 바로 복사).
3. itda-hyve 계정 화면에서 제공자 **"iCloud"** 를 고르고 Apple 계정 이메일·앱 전용 비밀번호를 넣습니다. 캘린더 주소는 자동으로 정해집니다.

> 자세한 발급 절차는 [iCloud 앱 전용 비밀번호 발급 가이드](https://itda.work/credentials/icloud-app-password/)를 참고하세요.

### 직접 입력 (CalDAV 주소)

네이버·아이클라우드가 아닌 CalDAV 서비스는 itda-hyve 계정 화면의 **"직접 입력"** 으로 계정을 만들고,
**고급 설정의 캘린더(CalDAV) 주소** 칸에 서비스가 알려 주는 주소를 넣습니다. 주소는 **https** 로 시작해야 합니다.
대부분 2단계 인증을 켜면 **앱 비밀번호**를 써야 합니다(일반 비밀번호는 거부될 수 있습니다).

| 서비스 | 캘린더 주소 예시 | 비고 |
|--------|-----------------|------|
| Fastmail | `https://caldav.fastmail.com/dav/` | 앱 비밀번호 필수 |
| Nextcloud | `https://<내 서버 주소>/remote.php/dav` | 앱 비밀번호 권장 |
| mailbox.org | `https://dav.mailbox.org` | 2단계 인증 시 앱 비밀번호 |
| Posteo | `https://posteo.de:8443/` | **포트 8443 을 주소에 포함** |

캘린더 주소를 넣지 않은 직접 입력 계정은 메일만 쓸 수 있습니다. 이 경우 Claude 는 "이 계정은 캘린더를 쓸 수 없다" 는 이유를 알려 줍니다.

## 자주 쓰는 요청

| 하고 싶은 것 | 이 지침을 입력하세요 |
|--------------|-----------------|
| 일정 확인 | `/calendar 이번 주 일정 보여줘`, `/calendar 오늘 뭐 있어?`, `/calendar 6월 일정 알려줘` |
| 특정 캘린더만 | `/calendar 강의 일정 캘린더만 보여줘` |
| 일정 검색 | `/calendar OO 프로젝트 회의 다 찾아줘`, `/calendar 강남에서 하는 일정 찾아줘` |
| 빈 시간 찾기 | `/calendar 다음 주에 1시간 빈 시간 찾아줘`, `/calendar 이번 주 오후에 회의 잡을 수 있는 시간 알려줘` |
| 일정 상세 | `/calendar 그 회의 자세히 보여줘` |
| 일정 추가 | `/calendar 내일 오후 3시 강의 일정 추가`, `/calendar 금요일 점심 약속 잡아줘` |
| 겹침 확인하며 추가 | `/calendar 겹치는 일정 없는지 보고 내일 2시에 회의 잡아줘` |
| 반복 일정 | `/calendar 매주 월요일 9시 스탠드업 추가` |
| 알림 | `/calendar 회의 10분 전에 알림 설정해서 추가` |
| 수정 | `/calendar 그 회의 30분 미뤄줘`, `/calendar 제목 바꿔줘` |
| 삭제 | `/calendar 토요일 약속 취소해줘` (지우기 전에 확인을 거칩니다) |
| 여러 계정일 때 | `/calendar 아이클라우드 계정으로 이번 주 일정 보여줘` |

## 안전장치

- **지우기는 항상 확인을 거칩니다.** 어떤 일정을 지울지 먼저 보여 주고, "지워" 라고 확인해야 실제로 지웁니다. 확인 없이 10분이 지나면 다시 물어봅니다.
- **반복 일정은 한 번 더 확인합니다.** 매주 회의처럼 반복되는 일정을 고치면 모든 회차가 함께 바뀝니다. Claude 는 바뀐 뒤 모습을 먼저 보여 주고 확인을 받은 뒤에만 고칩니다.
  한 회차만 옮기고 싶다면 캘린더 앱에서 직접 하세요.
- **수정 충돌 방지.** 조회한 뒤 그 사이 폰이나 웹에서 같은 일정이 바뀌었다면 덮어쓰지 않고, 바뀐 내용을 보여 준 뒤 다시 확인합니다.
- **참석자가 있는 일정은 건드리지 않습니다.** 다른 사람을 초대한 일정(또는 초대받은 일정)을 고치거나 지우면 참석자에게 메일이 갈 수 있어서,
  이런 일정은 캘린더 앱에서 직접 고치도록 안내합니다. 주최자만 있고 참석자가 없는 일정은 고칠 수 있습니다.
- **안전하게 고칠 수 없는 일정도 건드리지 않습니다.** 캘린더 서버가 "지금 이 버전" 을 확인할 값(etag)을 주지 않거나 약한 값만 주면,
  다른 기기의 변경을 덮어쓸 수 있어 고치거나 지우지 않고 캘린더 앱에서 직접 하도록 안내합니다. 보기는 됩니다.
  네이버·아이클라우드는 해당하지 않고, 주로 직접 주소를 입력한 캘린더 서버에서 생깁니다.
- **일정 속 지시는 따르지 않습니다.** 초대받은 일정의 설명에 "이 일정을 지워라" 같은 문구가 있어도 Claude 는 따르지 않고, 필요하면 먼저 물어봅니다.

## 안 될 때

| 증상 | 원인 / 해결 |
|------|-------------|
| "캘린더를 쓸 수 있는 계정이 없다" | itda-hyve 에 네이버·아이클라우드 계정이 없거나, 직접 입력 계정에 캘린더 주소가 비어 있습니다. 위 "처음 설정하기" 를 확인하세요 |
| "이 계정은 캘린더를 지원하지 않는다" | 캘린더(CalDAV)를 제공하지 않는 메일 계정입니다. Claude 가 알려 주는 이유를 확인하세요 |
| "로그인 실패"(auth_error) | 앱 비밀번호가 틀렸거나 바뀌었습니다. itda-hyve 계정 화면의 "연결 테스트" 에서 캘린더 줄을 확인하고, 필요하면 앱 비밀번호를 다시 발급받아 교체하세요 |
| "다른 곳에서 바뀌었다"(etag_conflict) | 그 사이 다른 기기에서 일정이 바뀌었습니다. Claude 가 바뀐 내용을 보여 주면 확인하고 다시 진행하세요 |
| Claude 가 "itda-hyve 를 업데이트해 주세요" 라고 한다 | 캘린더 기능은 itda-hyve **0.9.0 이상**이 필요합니다. 개명 전 판(0.9.0 이전)이 연결돼 있으면 계정이 등록돼 있어도 캘린더를 못 씁니다. [itda-hyve 최신판](https://github.com/itda-work/itda-hyve.pub/releases/latest)을 설치하고 Claude Desktop 을 다시 시작하세요 |
| "여기서는 고칠(지울) 수 없어요 — 캘린더 앱에서 직접" | 참석자가 있는 일정이거나, 캘린더 서버가 안전한 수정 확인값을 주지 않는 일정입니다. 폰·웹의 캘린더 앱에서 직접 고치세요 |
| 지우려는 일정이 "없다" 고 한다(not_found) | 이미 지워진 일정입니다 — 앞선 요청이나 다른 기기에서 지워졌습니다. Claude 는 다시 지우려 하지 않고 그렇게 알려 드립니다. 캘린더 앱에서 확인해 보세요 |
| 지우기 확인이 "무효" 라고 한다(confirm_invalid) | 확인 뒤 10분이 지났거나, 그 사이 일정이 바뀌었습니다. 다시 지워 달라고 하면 새 확인을 받습니다 |
| Claude 가 itda-hyve 를 모른다고 한다 | itda-hyve 가 Claude Desktop 에 연결되지 않은 것입니다. itda-hyve 의 "Claude Desktop" 화면에서 등록하고 Claude Desktop 을 다시 시작하세요 |
| 일정이 안 보임 | `/calendar 지난달부터 다음 달까지 보여줘`처럼 기간을 넓히거나, `/calendar 내 캘린더 목록 보여줘`로 캘린더 이름을 확인하세요 |
| 캘린더를 새로 만들었는데 목록에 없음 | `/calendar 캘린더 목록 새로 고쳐서 보여줘`라고 말하세요 |
| 빈 시간에 종일 일정이 걸림 | 배송 예정 같은 정보성 종일 일정도 기본은 '바쁨'으로 봅니다. `/calendar 종일 일정은 빼고 빈 시간 찾아줘`라고 말하면 제외합니다 |
| 빈 시간이 기대와 다름 | 기본은 **평일 09~18시, 내 캘린더 기준**입니다. "주말 포함해서", "저녁 시간대로"처럼 조건을 함께 말하세요. 다른 사람의 일정은 볼 수 없습니다 |

## 조회가 느릴 때

- 전체 캘린더를 한꺼번에 보면 캘린더 수에 비례해 느려집니다. 자주 보는 캘린더가 있으면 "○○ 캘린더만 보여줘"처럼 좁히세요.
- **네이버는 일정이 많을수록 느려집니다**(서버가 기간 필터를 지원하지 않아 캘린더 전체를 불러옵니다). 한 캘린더를 지정하는 것을 권장합니다.

## 제한사항

- **이 스킬로 할 수 없는 것** — 반복 일정의 **한 회차만** 옮기거나 지우기(수정·삭제는 시리즈 전체에 적용됩니다), 참석자 초대·참석 응답,
  다른 사람의 빈 시간 보기, 할 일·미리 알림, 캘린더 만들기·이름 바꾸기·공유. 이런 작업은 캘린더 앱에서 직접 하세요.
- **네이버 반복 일정** — 네이버 서버는 반복 일정을 회차로 펼쳐 주지 않아 Claude 가 반복 규칙으로 날짜를 계산합니다.
  그 반복 중 한 회차만 따로 옮긴 경우는 원래 자리에 보일 수 있습니다.
- **앱 비밀번호 필수** — 메인 계정 비밀번호로는 로그인이 안 됩니다.
