**매일 쓰는 업무 도구 스킬팩** — 메일·일정·아침 브리핑·환율·날씨. 메일·캘린더 계정과 API 키는 사용자 PC 의
itda-hyve 에 등록하고, 스킬은 itda-hyve 도구로만 요청합니다(계정 비밀번호를 대화로 받지 않습니다).

## 스킬

| 스킬 | 하는 일 |
|------|---------|
| `email` | itda-hyve 에 등록한 메일 계정으로 메일을 찾고 읽고 보낸다(첨부 읽기·회신 초안 포함) |
| `calendar` | itda-hyve 에 등록한 캘린더에서 일정을 조회·추가·수정·삭제하고 빈 시간을 찾는다 |
| `morning-brief` | 오늘 일정·관련 메일·미회신 메일을 모아 아침 브리핑 HTML 한 장을 그린다 |
| `exchange-rate` | 원화 기준 일별·월 평균 매매기준율을 조회한다 |
| `weather-here` | 현재 위치 또는 지정 지역의 날씨를 조회한다 |
